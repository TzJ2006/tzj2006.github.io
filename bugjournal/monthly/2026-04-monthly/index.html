Recurring Issues#

1. Linux FloatBall geometry/position bug fails to converge across multiple iterations (occurred 5 times)#

Dates: 2026-04-01, 2026-04-02, 2026-04-03, 2026-04-04, 2026-04-05 Root Cause: The root cause was an architectural platform constraint, not a calculation bug: the Linux WM, GTK, and WebKitGTK geometry systems each operate independently and asynchronously; any solution based on dynamic resizing produces inconsistency across the three layers. Earlier fixes (anchor calculation, last_rect state, GTK resizable timing) patched symptoms without eliminating the resize behavior itself. It wasn’t until day 5 that the team recognized “fixed window size + GDK Input Shape” as the definitive solution. Status: ✅ Resolved

2. AI first-round fixes miss low-level root causes, focusing on frontend/algorithm layer while ignoring OS/WM layer (occurred 4 times)#

Dates: 2026-04-01, 2026-04-02, 2026-04-04, 2026-04-05 Root Cause: Without a runtime validation environment, AI tends to infer behavior from code logic, looking for root causes first at the application layer (frontend coordinate transforms, animation timing). Low-level platform behavior (GTK bottom-up negotiation, WM clamping, WebKitGTK transparent buffer) can only be discovered through empirical logging. Each instance required the user to provide backend.log or real test feedback to trigger the correct fix path. Status: 🔄 Ongoing

3. conda activate fails in non-interactive shell environments (occurred 3 times)#

Dates: 2026-04-01, 2026-04-02, 2026-04-06 Root Cause: conda activate only modifies PATH in interactive shells; subprocesses (SLURM jobs, Claude Code background bash, CI environments) do not inherit the activated state. The standard pattern should be conda run -n ENV python instead of activate && python. Status: 🔧 Workaround available

4. Cross-platform Rust/GTK API behavior deviates from expectations, introducing new platform-specific issues (occurred 4 times)#

Dates: 2026-04-02, 2026-04-03, 2026-04-04, 2026-04-05 Root Cause: Several GTK/Tauri APIs have implicit constraints on Linux: resizable(false) also blocks programmatic resizing; with_webview() is dispatched asynchronously (subsequent APIs are queued before the callback executes); GTK gravity is not supported by all WMs; GDK input shape intercepts at the X11 layer before setPointerCapture. These framework internals are not clearly documented in official docs — they require empirical testing or reading GTK source to discover. Status: ✅ Resolved

5. Output overwriting and timeout design issues in large distributed experiments (occurred 3 times)#

Dates: 2026-04-01, 2026-04-03, 2026-04-06 Root Cause: Compute time for the HD dataset (17,502 spots) is severely underestimated by linear extrapolation from DLPFC (~3,900 spots); multiple experiments sharing a single output file (summary.csv) causes later results to overwrite earlier ones; the pipeline’s skip_completed mechanism cannot detect files that exist but contain invalid content. Fundamentally, the experiment pipeline lacks per-pair output directories and idempotency protection. Status: 🔧 Workaround available

Selected Learnings This Month#

Architecture#

  • Correct architecture for transparent borderless Tauri/WebKitGTK floating windows on Linux: fixed large-size native window + pure CSS expand/collapse inside — do not rely on frequently resizing the outer window. WM, GTK, and WebView content area sizes/positions do not synchronize automatically; dynamic resizing is the root cause of all positioning bugs. GDK input_shape_combine_region is the correct mechanism for controlling click-through, intercepting at the X11 layer before setPointerCapture; during drag operations, the Rust side must temporarily expand to the full window. (Source: 2026-04-04, 2026-04-05)
  • GTK window size control mechanism: GTK bottom-up negotiation takes max(window_requested, widget_natural_size); WebKitGTK natural size ≈ 200×200; Tauri’s set_size/set_min_size have no effect on WebKitGTK windows — must call widget.set_size_request() inside a with_webview() callback to break through; with_webview() is asynchronously dispatched, subsequent Tauri APIs queue before the callback executes (FIFO); set_resizable(false) locks the size set in the callback; WebKitGTK scrollbars are part of the GTK widget layer and must be disabled with set_policy(Never, Never), not CSS. (Source: 2026-04-04)
  • The Wayland protocol prohibits clients from setting absolute window positions; any set_position() retry strategy is ineffective. Correct solution: detect WAYLAND_DISPLAY and force GDK_BACKEND=x11 to fall back to XWayland. Modern Linux desktops (Ubuntu 22.04+) default to Wayland; cross-platform window tracking must use GNOME Introspect D-Bus (org.gnome.Shell.Introspect.GetWindows()) as the primary path, with xdotool/xprop only as XWayland fallback. (Source: 2026-04-02, 2026-04-04)
  • Radical simplification (swapping out the engine) is often more effective than incremental patching: Thin Adapter + MCP Server + Skills three-layer pattern replacing proprietary routing logic results in far more code deleted than added (-6,061 vs. +3,238 lines); in multi-CLI system design, convention files (CLAUDE.md/AGENTS.md/GEMINI.md) are simpler and more reliable than runtime injection; a unified history ring buffer is more reliable than adapting to each CLI’s session mechanism. (Source: 2026-04-04)
  • Hugo site deployment has three independent dependencies that must all be in place simultaneously (hugo binary, theme repository, deployment git repository); any one missing causes failure at a different stage. bash set -e scripts must include directory existence checks before find operations on optional directories; parallel background task (& + PID tracking) code must align precisely with if/else control flow boundaries — shared code placed inside branches introduces duplicate PID tracking and file replacement omission bugs. (Source: 2026-04-07)

Domain Knowledge#

  • Core findings in multimodal spatial transcriptomics: (1) High-quality embeddings themselves matter more than clustering method choice (STAIG+mclust 0.546 > STAIG+Leiden 0.513; Leiden helps weak embeddings significantly +29% but adds little to strong embeddings); (2) Optimal clustering strategy ≠ optimal retrieval strategy — STAIG spatial graph contrastive learning is best for global clustering, but strong spatial homogenization causes 96% of boundary retrieval to focus on the same domain; Attention fusion is more balanced for boundary microenvironments; (3) Data scale is a critical variable for method selection: AdaLN completely fails at 17,502 spots (ARI ≈ 0.003) but works at ~3,900 spots. (Source: 2026-04-01, 2026-04-03, 2026-04-06)
  • NeurIPS D&B Track submission strategy: “Domain correctors” (triggering evaluation paradigm shifts by quantifying specific deficiencies in existing benchmarks) are accepted more readily than “new method proposers”; reviewers value most: multi-dimensional evaluation, fair baseline comparisons, human validation mechanisms (κ ≥ 0.68), and counter-intuitive negative findings; symbolic verification closed loops (SPARQL/SQL execution comparison + N automatic repairs) can improve data accuracy from 57% to 96%+; counterfactual entity replacement can eliminate lexical overlap bias. (Source: 2026-04-04)

Tools#

  • Complete MCP configuration for Claude CLI -p (session-less) mode requires two steps: (1) –mcp-config to explicitly load project-level tools; (2) –permission-mode bypassPermissions to bypass permission confirmations that cannot be completed in non-interactive mode. The –allowedTools wildcard is unreliable due to a race condition with MCP server initialization. bypassPermissions is the correct standard mode for backend service calls. (Source: 2026-04-05)
  • Best practices for ccplan + Critic subagent adversarial review: run divergent exploration (6 approaches) + adversarial review + feasibility probing before planning any complex feature. This month the Critic phase collectively surfaced Wayland compatibility, lark-oapi thread blocking, non-singleton ThoughtStore, and 4 hidden code dependencies — each of which would have caused complete feature failure in production if missed. ECL documents structurally persist design decisions and are a critical engineering practice for cross-session complex feature development. (Source: 2026-04-04, 2026-04-05)
  • conda run -n ENV python is the standard way to run Python scripts in non-interactive shells; conda activate only modifies interactive shell PATH and is not inherited by SLURM jobs, background bash, or CI environments. When background process output is empty, first verify the process is running with ps aux rather than resubmitting immediately (avoids resource waste and result overwriting). (Source: 2026-04-01, 2026-04-06)
  • lark-oapi WebSocket correct architecture: Client.start() is blocking and must run in a dedicated daemon thread bridged with asyncio.run_coroutine_threadsafe(); when wrapping stdlib with structlog, extra={} fields require an explicit ExtraAdder() processor to appear in output — otherwise silently dropped without error; Google Calendar OAuth should validate with events.list(calendarId=‘primary’) rather than calendarList.list(). (Source: 2026-04-04, 2026-04-05)

Debugging#

  • Runtime logs are the primary debugging tool for low-level systems, superior to code reasoning: when dealing with GTK/WM/OS layers, empirical data from backend.log (e.g., the systemic pattern that +305px = expanded width) can directly identify architectural root causes; after multiple failed fixes, proactively analyze logs for patterns rather than continuing to try new approaches. When debugging nested process CLI tools, record the actual command-line arguments being passed and isolate variables one at a time — more efficient than guessing parameter behavior. (Source: 2026-04-04, 2026-04-05)
  • Rust production code safety patterns: (1) assert!()/unwrap() on paths accepting external input are time bombs — replace uniformly with Result propagation; (2) Holding locks across async await boundaries is a hidden performance/deadlock risk — clone needed data before await to release the lock early; (3) Python awaiting a synchronous method produces TypeError that, if swallowed by except Exception, causes silent feature degradation and is extremely difficult to debug; (4) “Feature has implemented parameter interface” ≠ “parameter is actually being passed” — always verify at the call site. (Source: 2026-04-02, 2026-04-04)
