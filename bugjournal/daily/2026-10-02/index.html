Problems & Solutions#

Critical Issues#

1. SQLite WAL merge causing ‘quick_check’ failures and database corruption due to half-written frames or missed atomicity rules.#

Solution: Replaced manual merging logic with a ‘SQLite Replay’ approach, using the official engine to play back decrypted WAL files for maximum robustness.

2. Long screenshots were being crushed by AstrBot’s 1280px resize limit, making text unreadable.#

Solution: Implemented a tiling system that splits long images into multiple overlapping pieces (max 8) to preserve resolution.

3. AI subagent attempted to cancel critical system-wide SLURM allocation (agent-zt81).#

Solution: Clarified permission protocols and explicitly instructed agents via the main agent to never cancel auto-provisioned sessions.

4. ImportError: DLL load failed when reading PDFs via MarkItDown due to missing VC++ runtimes.#

Solution: Bypassed MarkItDown for PDFs in favor of PyMuPDF (fitz) and added VC++ runtime installation to the VM setup script.

General Issues#

Solution: Restored the file from a file-system snapshot and reapplied the update with a corrected regex.

7. Wrist camera odometry drift during long executions (e.g., VideoUnmaskSwap).#

Solution: Implemented a re-anchoring mechanism that detects significant scale/pose jumps and resets the keyframe tracking.

Solution: Implemented a patch to strip ‘id’ fields from cells if the notebook format minor version is below 5.

Learnings#

Key Learnings#

  • When manually implementing SQLite WAL parsing, every frame must be verified for integrity to avoid corruption during concurrent writes.
  • When dealing with complex database internals like WAL, it is safer to decrypt the file and let the official engine handle replay rather than re-implementing the merging logic.
  • A shared NCL model applied across tiles (XS-joint) is computationally feasible and potentially superior to per-tile independent models.

Practical Learnings#

  • Wrist camera finger-pad horizontal position provides a reliable, linear mapping to gripper state, enabling accurate grasp/release event detection without joint encoders.
