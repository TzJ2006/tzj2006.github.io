Human vs AI Approaches#

Strategic Level#

Gradient strategy selection in pi05 experiment design#

Role Approach
Human Directly chose scheme A (all stop_gradient), reasoning that it is ‘safest, does not affect action prediction, and can be adjusted later’ — reflects a conservative initial experimental approach
AI AI proposed 3 schemes (A: full blocking, B: full backprop, C: hybrid), analyzed trade-offs of each scheme, preferred A but emphasized the special nature of special tokens

Difference Analysis: Humans make quick decisions based on engineering experience; AI tends to list options and trade-offs explicitly, yet humans’ concise decision-making strategy (conservative first, then iteration) is reasonable

Naming and organization of experiment configurations#

Role Approach
Human Required ‘config switches for easier experiment start’, highlighting emphasis on experimental engineering efficiency
AI Designed a unified ProgressConfig class and 4 independent naming configurations (exp1~4), allowing direct selection via tyro CLI

Difference Analysis: Humans focus on practicality and convenience; AI concretizes it into config class design and CLI interface, both aiming at ’easy experiment switching’

AI Limitations#

Critical Limitations#

  • AI did not proactively anticipate data pipeline issues — After model modification, should immediately check if data loading supports new fields, rather than waiting for user errors
  • AI did not run actual training smoke tests during pi05 modifications, only tested import of config classes, resulting in missing dependencies in data conversion script

Learnings#

Key Learnings#

  • Integrity checks for complex model experiments should cover model code, configuration, data pipeline, and training scripts, not just model code validation
  • Using stop_gradient in JAX/Flax for auxiliary tasks is a common multi-task learning pattern, allowing utilization of features while avoiding interference with the main task
  • Special token mechanism requires 3 steps: tokenizer registration of token IDs, model extension of embedding layers, and prompt concatenation during data loading
