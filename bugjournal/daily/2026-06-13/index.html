Issues and Solutions#

Key Issues#

1. TokenMonitor high CPU: Backend loop statistics process 14,769 files every 2 seconds, and even adding content (non-structured information) causes cache invalidation; Cursor/SSH data is missing during export. Solution: Refactored parser.rs to distinguish “directory change” (full re-scan) from “only content change” (incremental update). Added clear SSH refresh operation and accepted local:cursor source key to fix export logic.#

Key Insight: Cache invalidation logic must be aware of the detected change type; ensuring symmetry between local and remote refresh operations ensures time-point snapshots like exported files remain up-to-date.

2. Research module: LLM timeout causes the entire process to crash because call_llm_raw can only capture RuntimeError, while subprocess.TimeoutExpired leaks.#

Solution: Fixed common/llm.py to uniformly capture all child processes and SDK exceptions, ensuring failure return value instead of process crash when timeout occurs.

Key Insight: Infrastructure-level exception contracts must be consistent across all backends to prevent partial failures from causing system outage.

3. Windows PC: Despite fixing fatal crashes, frequent PCIe correctable errors (WHEA Event 17) occur; Xcode build failures also stem from environment mismatch.#

Solution: Wrote a decoder script to directly parse WHEA XML; all errors are benign noise caused by monitoring software’s “unsupported request” warnings for GPU configuration space. For Xcode, used swiftc -typecheck as a fallback before the user fixes the IDE plugin environment.

Key Insight: PCIe correctable errors marked as URI/ANFE are usually only benign noise caused by software; when higher-level tools fail due to environment status, lower-level language compilers can sometimes serve as a reliable fallback for verification.

General Issues#

4. macOS Gatekeeper reports “application corrupted” (unsigned build) when downloading .dmg files from GitHub Actions.#

Solution: Clarified that this only affects forks/unofficial builds. Provided xattr -cr command for users and updated README.md to adjust expectations.

Key Insight: CI pipelines usually rely on conditional signatures based on confidential information; it is crucial to distinguish official (signed) and user-generated (unSigned) outputs in documentation.

5. Python json.dumps changed the format/sorting method of Xcode Localizable.xcstrings, causing a large git diff.#

Solution: Wrote custom Python script to retain the original key ordering at HEAD and match Xcode-specific delimiter/indentation style, significantly reducing diff size.

Key Insight: Always respect old serialization formats. In Python 3.7+, dictionary key order is preserved, but explicit sorting or re-serialization may change internal format rules for proprietary file types.

Lessons Learned#

Key Experiences#

  • When diagnosing CPU hotspots of file-based observers, check if cache invalidation is too “widespread” (for example, clearing the minimum/maximum cache only when content is appended, as it cannot be changed mathematically).
  • Windows WHEA event 17 “corruptible errors” on high-end GPUs are usually caused by monitoring tools detecting unsupported PCIe configuration registers, rather than physical degradation.
  • In TokenMonitor, archive_completed_hours is idempotent and safe and reliable. This allows safely expanding archive sources (such as Cursor) without worrying about duplicate counting, provided the source key is valid.

Practical Experiences#

  • Xcode’s xcstrings format uses specific delimiters (: ) and non-alphabetical ordering (historical insertion order). Maintaining this order is crucial for keeping clean diffs.
