Learnings#

Key Learnings#

  • When handling multi-channel systems, authentication must differentiate between human users and automated agents for scoped access.
  • Project restructuring is safer when using a read-only ‘Scout-and-Design’ workflow before moving files.
  • Reliable robot learning must distinguish between ‘arbitrary starting state’ and ‘state following an execution error’.
  • Robust error definitions require distinguishing between trivial physical changes and meaningful task state regressions.
  • When integrating external APIs into a reactive bot, strict identity verification (using wxid) is essential for security.
  • For personal Pro accounts, standard APIs might return null for thread-specific data, requiring local CLI probing.
  • GPU kernel autotuning can introduce subtle numerical differences that mimic code regressions.

Practical Learnings#

  • The TMPDIR must be explicitly set to a directory on /home to avoid filling the / partition during QuantSim ONNX exports.
  • Hyper-V ‘Enhanced Session’ is essentially RDP (locks on close); ‘Basic Session’ keeps the desktop running.
