Problems & Solutions#

Critical Issues#

1. VM cannot access local vision models due to missing ‘model_access’ package and lack of shared GPU lease registry.#

Solution: Modified ‘model_access’ to track ‘host’ names in leases and used directory junctions to share the lease JSON file between host and VM.

2. WeChat 4.x image right-click menu lacks the ‘Add to Stickers’ option, breaking the initial automation logic.#

Solution: Rewrote the addition script to use the ‘Emoji Panel -> Custom Stickers -> +’ workflow instead of the context menu.

General Issues#

3. The evaluation script automatically skips episodes marked as ’error’ in the log, preventing retries.#

Solution: Analyzed the eval.py skip logic and implemented a way to launch a separate run to target only the errored episode without affecting the main results.

4. The remote connection to the LLM interface via the SSH tunnel was unstable.#

Solution: Monitored the tunnel status and verified automatic reconnection once the proxy became reachable.

5. Episode 6 of RouteStick failed due to a network ‘Connection reset by peer’ error.#

Solution: Identified it as an infrastructure issue rather than a policy failure and executed a targeted rerun for that specific episode.

6. PermissionError when running automation scripts from System32 directory due to uiautomation attempting to write logs.#

Solution: Modified scripts to explicitly change the current working directory to the TEMP folder upon startup.
