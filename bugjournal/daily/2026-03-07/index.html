Issues and Solutions#

Key Issues#

1. Despite good training performance, the BC-RNN metric cascade is almost completely broken; VLA evaluation scripts fail due to WebSocket timeout during JIT compilation. Solution: Identified missing field mapping, static YAML fallback mechanism, and observation key mismatch issues (object does not match the original architecture); fixed the collector/environment modules, aligned robomimic API signatures, added ping_timeout weights in the JIT phase, and validated via unit tests/regression suites, restoring RP to 0.800.#

Key Insight: The integrity of the evaluation metric chain is crucial; silent observation/key mismatch or static configuration override destroy the baseline, preventing strategic conclusions.

2. LLaVA/Phoenix training severely overestimates duration (13.5 days) due to ZeRO-3 communication overhead, unverified dataset size (160K→1M actual entries), and campus agent bandwidth blocking.#

Solution: Downgraded to ZeRO-2 for better balance between single/dual-card memory, reduced iteration counts, adjusted batch size based on hardware, used local safetensors conversion and vocabulary alignment to bypass agents, and preloaded HDF5 into CPU RAM to avoid I/O starvation.

Key Insight: Training process optimization requires balancing computational cost and convergence thresholds; clear dataset length verification must occur before iterative computation, and local format conversion can reliably bypass restrictive network tunnels.

3. macOS sandbox blocks WKWebView network requests; .desktopWindow level intercepts all input events; the scroll bar appears transparent due to drawsBackground=false; the screen protector overlay shows a gray halo.#

Solution: Added network.client permissions, restored window level to interactive .normal, retained ignoresMouseEvents=false, injected Chrome User-Agent string, hidden text via CALayer instead of snapshots, and removed conflicting CSS/rendering masks.

Key Insight: Native operating system synthesis rules strictly override Web/CSS layers; interactive overlay requires higher levels than system-defined input mask boundaries, and clear permissions are essential for sandbox networks.

4. CalendarPro static keyword routing misclassifies prompt words that depend on context (“ok”, “time”); BackgroundCoordinator fails silently; insufficient test coverage hides integration faults.#

Solution: Implemented dual-verification dynamic routing based on session state signals, replaced silent except Exception: pass blocks with structured logs, added clear startup health check hooks, and expanded tests via parallel sub-agents (196→360+ cases).

Key Insight: Dynamic dialogue processes require state-driven classification rather than static rules; without clear lifecycle management and observability, completion does not equate to success.

5. MIHD visual encoder embedding vectors fail checkpoint loading due to tissue_positions X/Y column inversion (4th/5th column swap) and use_fast_transformer attributes never persisted, resulting in ARI close to zero.#

Solution: Verified coordinate swap via array step analysis, forced array_row/col mapping correction, cache cleanup, reallocated missing attributes in __init__, and triggered full embedding reconstruction in DLPFC region.

Key Insight: Spatial/biological data pipelines contain potential geometric transformations requiring statistical verification; dynamic conditions must be explicitly persisted to prevent silent weight damage during framework upgrades or configuration changes.

Lessons Learned#

Key Experiences#

  • Before any comparative analysis, a chain of evaluation metrics audit and verification of physical/simulation results must be conducted first; zero success rate usually stems from observation/key parameter mismatch or state path corruption, not model collapse.
  • For VLA workflows, DeepSpeed ZeRO-2 is more efficient than ZeRO-3 for single-card/multi-card expansion; verifying dataset size (expansion per time step and unique sample) and local resource conversion are key prerequisites to prevent a surge in training overhead.
  • Phase-based architecture specifications with clear gates can avoid circular dependencies and ensure token budget consistency with system state transitions; native OS synthesis/input rules strictly cover the Web/CSS layer, requiring higher levels to support interactive overlay layers.
  • Dynamic context signals are crucial for intent classification success; CLI/automation pipelines require atomic, idempotent batch processing and precise regular expression/config dependency mapping to prevent hidden runtime failures or state contamination in distributed environments.
