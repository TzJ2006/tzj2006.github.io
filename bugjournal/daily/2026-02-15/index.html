Issues and Solutions#

Key Issues#

1. MuJoCo’s high-gain OSC controllers compensate for injected force by using demonstration actions to cover trajectories, resulting in complete lack of motion errors in visual videos despite normal backend logs.#

Solution: Divide post-error deployment into three independent stages: neutral force application, weak stability window using specialized parameters, and demonstration recovery. During injection, explicitly switch the action source to neutral vectors to disable motion tracking feedback loops.

Key insight: Robot controllers with high gain ratios immediately cancel external forces during active tracking; to completely eliminate error performance, control loops must be isolated through non-tracking phases.

2. Sudden interruptions or Ctrl+C crashes during Gadget CLI file writing cause partial JSON files, leading to downstream parsing failures and damaged daily report status.#

Solution: Implemented _atomic_write, used tempfile.mkstemp to safely process before output draft, and then immediately renamed it via os.replace. A defensive fallback mechanism allows graceful handling of partial writes without leaving corrupted data on disk.

Key insight: Atomic file system operations are the industry standard for崩溃 resilience in Python pipelines; tempfiles + renaming are more reliable than complex locking mechanisms to prevent partial state damage.

3. The automatic benchmark scheduler cannot properly allocate heterogeneous workloads, causing heavy neural components (such as Q-Former) to fail due to CUDA OOM, leading to neglect of lightweight baseline evaluations and parallel scGPT runtime crashes.#

Solution: Dynamically reconfigured the pipeline, split heavy Q-Former batches, and forced epoch reduction to 50 to accelerate iteration without sacrificing quality consistency. Rearranged experiment queues based on resource profiles rather than static order, and enforced memory partitioning.

Key insight: Dynamic scheduling is significantly better than static order execution in multi-device environments; decoupling pipeline evaluation stages prevents severe resource starvation and reduces total benchmark completion time on limited HPC nodes.

4. The Gadget export pipeline re-summarized merged operations, causing AI API duplicate consumption, token waste, and unnecessary latency.#

Solution: Inserted _merged_devices tracking arrays into the local export JSON. The merged/export process now checks these local source markers before any cloud LLM call, ensuring strict idempotence of multi-device aggregation.

Key insight: Local state protection at data input points is an important cost optimization strategy for distributed pipelines and prevents duplicate cloud interactions.

Solution: Immediately conduct OAuth scope audits and redirect API requests to calendar.events permissions consistent with the granted settings().get(), and implement direct configuration fallback mechanisms to eliminate duplicate failure logs.
