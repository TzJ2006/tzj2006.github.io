Problems & Solutions#

Critical Issues#

1. pi0.5 Libero goal suite reported 0% success rate (contradicting reported benchmarks).#

Solution: Ran unquantized (float) baseline locally, which achieved 100% success, proving the issue is related to quantization or environment configurations rather than the evaluation pipeline.

2. 4-bit activation (W4A4) performed significantly worse/slower than FP16 on NPU.#

Solution: Used a minimal probe to isolate the cause: the NPU lacks a native INT4 activation kernel, causing high overhead from tensor upscaling/expansion.

Key Insight: 4-bit activation is a performance trap on this hardware; weight bitwidth saves bandwidth, but activation bitwidth without native kernels only adds unpacking overhead.

3. AI Hub deprecated the ‘qnn_context_binary’ target runtime, breaking automation.#

Solution: Modified ‘aihub_submit.py’ to explicitly pass ‘–target_runtime qnn_dlc’ and updated all related documentation/graphs (I-029) and RESULTS.md.

4. AI Hub’s ‘peak_memory’ field reported discrepancies compared to expected model footprint.#

Solution: Performed a comparison between context-binary (uses mmap, zero weight footprint reported) and DLC (requires explicit allocation), clarifying the measurement difference.

5. Lack of Out-of-Distribution (OOD) data for direct error recovery research.#

Solution: Pivoted research focus to the ‘interface’ problem: how high-level judgments communicate to low-level policies via visual prompts.

Key Insight: The research bottleneck was the communication channel between high-level reasoning and low-level execution.

6. Evaluation script leaks ~25GB of GPU memory during pi0.5 runs.#

Solution: Identified that ‘conda run’ fails to forward signals to the policy server; planned to adopt the collaborator’s PID tracking fix.

General Issues#

7. System becomes unresponsive due to high Vitest concurrency and WeChat timer thrashing.#

8. Confusion between CUDA device indices and nvidia-smi indices.#

Solution: Advised using CUDA_DEVICE_ORDER=PCI_BUS_ID to align indices.

Learnings#

Key Learnings#

  • Weight bitwidth on this NPU is a linear bandwidth-saving mechanism, but activation bitwidth only provides benefits if high-bitwidth ‘islands’ (like softmax) are eliminated.
  • The ‘goal’ suite in Libero (e.g., pulling a handle) is highly sensitive to quantization errors in the action head, unlike simple pick-and-place tasks.
  • Visual prompts serve as an effective communication interface between high-level VLM reasoning and low-level VLA execution.
  • Companion guards (D16/D17) can prevent productive work if the file structure is not properly registered in the idea graph.
