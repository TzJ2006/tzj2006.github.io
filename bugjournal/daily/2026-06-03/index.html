Key Issues#

1. Approximately 302MB of accidentally committed build files damaged repository health; fully rewriting history might disrupt upstream synchronization.#

Solution: Identified specific违规 commits, only modified the ancestor commits, successfully reduced repository size, while maintaining a 0-behind status with upstream.

Key insight: When cleaning out forks, changing shared history alters ancestor SHAs; selective modification is more helpful for maintaining upstream relationships than broad filtering tools.

2. The “app is corrupted” error on macOS and potential duplicate instance conflicts were initially mistaken for port exhaustion or signature issues.#

Solution: Clarified that Tauri applications in production environments may not listen to ports, implemented synchronization and pre-event loop loop port locking with native dialogs, ensuring exclusive access and handling startup logic effectively.

Key insight: Cross-platform single-instance checks must be independent of the application event loop, considering both process existence and port occupancy for comprehensive verification.

3. aidev install failed idempotency checks due to inconsistent path separators (backslash vs slash) and text differences in markers across platforms.#

Solution: Implemented fuzzy matching for markers and normalized path processing before comparison, adding pre-flight verification steps to ensure consistent state detection.

Key insight: Cross-platform CLI tools must standardize separators and check target states, not just file existence, to ensure true idempotency.

4. MIHD Slurm jobs fell into PD state; TokenMonitor showed blank screen due to isolated Vite port; QueST scripts produced UnboundLocalError.#

Solution: Resolved GPU scheduling starvation by switching device types, cleaned up zombie processes to establish normal port binding, and fixed variable scope issues in benchmark scripts.

Key insight: In HPC, specific hardware constraints often hinder jobs more than partition priorities; if zombie processes persist after a development server crash, Tauri’s strict port mode will silently fail.

Lessons Learned#

Key Lessons#

  • When cleaning up large amounts of accidental commits in forked repositories, verify the difference between behind/ahead state and upstream versions before and after operations; modifying only the root commit preserves the integrity of ancestor versions.
