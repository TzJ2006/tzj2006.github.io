Issues and Solutions#

Key Issues#

1. Rigidity of E2E training and mismatch between adaptive edge discard mechanism lead to performance decline across modalities#

Solution: Replace hardcoded gene_encoder constraints with explicit preprocessing routes (automatic/standard/cropped/no) and adjust the edge weight direction to enforce cross-domain penalty gradients.

Key Insight: A combination of flexible input embedding and precise discard masks is essential to ensure alignment rather than intra-domain similarity capture.

2. Incompatibility between LeRobot-HuggingFace dataset library and parquet metadata TypeError#

Solution: Lock the huggingface/datasets dependency at version 4.0 or lower to restore compatibility with LeRobot v0.1.0 tensor stack.

Key Insight: Changes in the core database API silently destroy pattern validation; strict environment locking during framework migration is necessary.

3. Numerical overflow in dense self-supervised similarity matrix leads to training divergence#

Solution: Apply L2 normalization and combine with LogSumExp stabilization to force float64 usage to prevent exponential saturation in softmax operations.

Key Insight: Float32 cosine similarity matrices saturate rapidly at high temperatures; mathematical stabilization is required before gradient descent initialization.

4. Cluster resource deadlock, EGL/CUDA mapping mismatch, and hard dependency blocking#

Solution: Switch from SSH direct execution to standard srun/sbatch queues, align MuJoCo physical device IDs with CUDA virtual environments, and implement dynamic fallback routing for network downloads.

Key Insight: The hardware abstraction layer must be manually synchronized; enforcing the standard scheduler interface is more reliable than strategy adjustments to resolve permission deadlock issues.

General Issues#

5. Base model VLA OOM limit, port binding conflicts, and baseline delay calculation errors#

Solution: Reduce batch size, allocate larger GPU levels, perform pre-start port scanning, and adjust evaluation pacing based on empirical health inference speed.

Key Insight: Differences in base model success across scenarios determine actual throughput; dynamic resource allocation and real-time latency analysis must replace static estimates.
