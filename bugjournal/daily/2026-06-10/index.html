Issues and Solutions#

Key Issues#

1. Mismatch of key intent: The evaluation code implemented the “EVALUATION.md” paper specification (CSR-RSR gap, single seed), which contradicts the authoritative “Panorama” summary (0–1 continuous recovery progress, multiple seeds), threatening experimental validity.#

Solution: Use multi-agent verification techniques to establish a complete record of intent and code, proving that “Panorama” is the true source; abandon the 500 steps/gap metric and replan evaluation to match SR + Bootstrap CI + RP.

Key insight: Technical documents (paper specifications) are often inconsistent with project high-level strategies; always verify code intent based on “Panorama” or execution summary first. Dead code in the framework layer should not be assumed to be active.

2. Failed results of Research Gadget LLM (timeout/rate limit) are permanently cached without TTL, causing subsequent runs to immediately return zero scores for all papers due to the same cache key.#

Solution: Found through workflow audit; the fix is to add a time-to-live (TTL) or unique request hash key to the cache entries in evaluate.py and insight.py to handle failed LLM responses.

Key insight: If the failed state and the successful state are identical in the cache without an expiration time, temporary API errors may lead to continuous data pollution. It is crucial to distinguish “temporary failure” and “permanent state” in the caching system.

3. Submitted files such as CLAUDE.md and settings.json expose absolute local paths (e.g., D:\GitHub\ai-companion), posing a risk of private path leakage.#

Solution: Implement three-layer fix: immediately use git rm –cached to delete existing exposed paths, update .gitignore to prevent future generation, and design installation programs with enhanced features to distinguish public and private visibility.

Key insight: Absolute paths in configuration files are essentially non-portable; treating them as “temporary” rather than “permanent” assets requires strict .gitignore implementation or environment variable injection.

General Issues#

4. TokenMonitor displays new Anthropic models (such as Fable 5) as “unknown” without a token.#

Solution: Found that src-tauri/src/usage/pricing.rs lacks entries for specific new model IDs. The fix is to add these IDs to ModelFamily and update get_rates().

Key insight: Hard-coded pricing tables need strict maintenance to keep up with vendor releases; the fallback logic usually hides missing data points rather than indicating a need for updates.

Lessons Learned#

Key Experiences#

  • When project specifications conflict between academic papers and internal documents, internal documents (especially ‘Panorama’ or ‘Master Guide’ files) should be regarded as authoritative sources for implementation details. Do not assume that dead code remains active.
  • Absolute paths used in generated configuration files must be strictly excluded from the public repository; installation programs should detect repository visibility (public/private) and dynamically adjust inclusion strategies to prevent machine-specific local path leakage.
  • In embodied AI research, ‘JEPA’ and ‘World Models’ are being integrated; especially using visual action tokens (such as iMaC) and hierarchical memory gates (HiMem-WAM) for long-term control appears to be cutting-edge technology.
  • In the caching system, distinguishing “temporary failure” and “permanent state” is crucial. Caching JSON parsing errors or API timeouts without a TTL setting will damage data integrity within the remaining cache time.
