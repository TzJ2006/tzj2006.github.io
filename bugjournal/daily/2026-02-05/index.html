Issues and Solutions#

Key Issues#

1. Unstable low cluster accuracy (ARI 0.09–0.35) deviated significantly from baseline expectations due to implementation flaws.#

Solution: Aligned with the official STAIG benchmark, corrected key deviations in dropout masks, edge weight normalization, feature cropping, and temperature reduction.

Key Insight: The mathematical accuracy of probability normalization determines cross-domain information flow; minor reversals can disrupt multi-modal convergence stability.

2. Flexible end-to-end fusion was hindered by rigid CLI constraints and fatal routing errors due to missing dynamic parameter handling.#

Solution: Updated argparse options, injected **kwargs into core functions, and modified validation logic to handle raw and pre-encoded potential spaces flexibly.

Key Insight: Dynamic configuration transfer is crucial for separating gene encoding from fusion strategies, enabling flexible multi-modal experiments.

AI Limitations#

Key Limitations#

  • Initially relied too heavily on standard deep learning default settings, leading to rigid single-modal assumptions and neglect of critical deterministic GPU settings (CuBLAS/cuDNN), resulting in non-reproducible inference. Lessons Learned#

Key Experiences#

  • Before debugging a custom framework, architecture and hyperparameters must be strictly aligned with the original academic library, as minor mathematical deviations can severely disrupt multi-modal convergence. Dynamic configuration transfer (such as **kwargs) and modular encoder support are key prerequisites for stable end-to-end fusion pipelines.
