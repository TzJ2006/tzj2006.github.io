Issues and Solutions#

Key Issues#

1. SSH default CWD mismatch during remote execution, combined with backward-compatible symbolic links caused Python path resolution failures, leading to duplicate import failures and silent script errors.#

Solution: Abandoned relative traversal methods and replaced them with hard-coding the absolute project root directory via environment variables sys.path.] Exposed key test files manually, recalculated parent traversal depth, and directly fixed cross-project dependency connections.

Key Insight: Direct file path resolution eliminated dangerous symbolic link indirectness; remote execution requires clear state management, and hard-coding sys.path after refactoring is crucial for maintaining a predictable evaluation tree.

2. Pipeline design enforced sequential validation, reducing computational utilization; MuJoCo/EGL device mismatch caused background Slurm job freezes; simple synthetic pulse injection failed to trigger physical failures.#

Solution: Shifted to parallel visual extraction via direct database queries, strictly aligned CUDA_VISIBLE_DEVICES and MUJOCO_EGL_DEVICE_ID in SRun commands, and adapted to use real-world error datasets instead of fragile synthetic triggering mechanisms.

Key Insight: Overlapping generation and validation optimized cluster throughput; simulation rendering context must physically match device IDs, and using existing error datasets is usually better than unstable programmatic injections.

3. Concurrent background agents and SRun tracking experienced partial write, Makefiles, and other overlapping dependency conflicts, as well as lost trajectory arrays during serialization.#

Solution: Coordinated phased transition from manual to agent-based handling to prevent locking conflicts, added explicit blocking calls to track jobs, and modified the I/O layer to preserve action sequences and trigger steps rather than relying solely on static snapshots.

Key Insight: Strategic scope control prevents conflicts during parallel refactoring; capturing rich process state during generation is more efficient than post-database reconstruction.
