Issues and Solutions#

Key Issues#

1. VLA model continues to fail during specific task phases (inaccurate pressing in click tasks,抓取/placement failures in operational tasks)#

Solution: Designed a gripper state filtering technique based on distance heuristic algorithm to annotate binary “critical region” tags during data collection, thereby supporting the training of the cls token classifier

Key insight: By training a binary classifier, high-risk areas requiring special attention can be predicted, addressing systematic VLA failures during task critical phases

2. All critical_region tags become 0 after data collection, indicating the threshold (0.10 m) is too conservative#

Solution: Added the get_ee_target_distances() method, recording the original EE-to-target distances for all tasks, thereby enabling empirical threshold adjustment

Key insight: When designing machine learning data annotation heuristic algorithms, original features should be recorded first before determining tag thresholds

General Issues#

3. SAPIEN renderer encounters “RuntimeError: failed to find a rendering device” error in headless environment#

Solution: Added three Vulkan/EGL environment variables (VK_ICD_FILENAMES, __EGL_VENDOR_LIBRARY_FILENAMES, LD_LIBRARY_PATH) to collect_data.sh, pointing to the nvidia_libs directory

Key insight: Headless GPU servers require explicit Vulkan ICD and EGL supplier configuration to find NVIDIA rendering drivers, even if nvidia-smi works properly

4. “No such file or directory” error occurs when running visual scripts from a remote shell#

Solution: Changed the relative paths of the project root and Python script to absolute paths, ensuring the working directory is correctly set before execution

Key insight: SSH does not inherit the working directory; “cd /absolute_path&& command” or providing absolute paths for all files is required

Main Achievements#

  • For VLA training in operational tasks, distance-based heuristic algorithms and gripper state filtering can be used to systematically address failure patterns during critical task phases (pressing, grasping, placement)
  • arXiv API supports author queries via “au:author name” syntax, which can be combined with keyword filters using AND/OR operators and sorted by relevance for author search
  • When designing machine learning data collection heuristic algorithms, observability should be achieved before adopting threshold-based labels. Empirical adjustments require understanding the actual data distribution
  • research_scout.py now supports three different search modes with distinct caching strategies: keywords/categories (sorted by date, filtered by review time), conferences (sorted by relevance, filtered by comments), and authors (sorted by relevance, no post-filtering)

Practical Achievements#
