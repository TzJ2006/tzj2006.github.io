Issues and Solutions#

Key Issues#

1. Despite no major functional changes, benchmark ARI dropped from about 0.4+ to about 0.13.#

Solution: Identified incorrect conda environment execution and drifting default settings in STAIGTrainer.py; fallback to tau, num_epochs and edge weight methods (softmax_neglog -> softmax_log) to verify benchmark values.

Key Insight: In multimodal training comparisons, minor parameter drift (temperature scaling, iteration count) and environmental dependency mismatches severely disrupt convergence and clustering boundaries.

2. Previous workflow updates caused STAIG fusion failures by injecting original 3000-dimensional gene expression instead of precomputed 50-dimensional PCA embeddings.#

Solution: Removed raw_gene_expr’s bypass logic in run_benchmark_core.py; restored the correct low-dimensional embedding workflow to match the original STAIG training dynamics.

Key Insight: Hybrid models with internal GCN layers require strict input dimension alignment; bypassing precomputed embeddings for raw data fundamentally changes graph topology and destroys comparison targets.

3. GCNGeneEncoder of MIHD omits activation functions in the final layer, which does not conform to the original STAIG specification.#

Solution: Updated GCNGeneEncoder.forward() to apply activation functions by default on all layers; added configurable parameter apply_activation_to_last_layer=True to support older versions.

Key Insight: Applying nonlinear functions in the final projection layer of channel-expanded GCN significantly alters the feature space geometry; thus strict architectural replication is crucial for reproducibility.

Lessons Learned#

Key Experiences#

  • In multimodal fusion benchmarks, switching clustering backends (e.g., R’s mclust vs. Python’s kmeans) without considering algorithmic differences may artificially lower metric scores, even if the coding pipeline is functionally correct.
  • Configuration-based training loops heavily rely on explicit parameter inheritance; implicit discarding of yaml values during nested object initialization leads to hard-to-trace performance degradation unless strict diff audits are performed.
