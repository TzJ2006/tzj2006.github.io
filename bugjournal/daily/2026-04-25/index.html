Lessons Learned#

Key Experiences#

  • The hint cache dominated the Claude Code token economy: 277M cache reads and 4.5M output tokens (ratio of 61), with Opus 4.6 accounting for 76% of cache usage
  • TokenMonitor stores session logs as JSONL files in ~/.claude/projects/, including metadata for each round, including cache_read/cache_write fields

Practical Experience#

  • TIME_WAIT TCP connections (PID 0) indicate closed sockets waiting to be cleaned up, not active port conflicts; they are automatically released in about 30 seconds
