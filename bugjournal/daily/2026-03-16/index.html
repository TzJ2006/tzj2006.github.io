Issues and Solutions#

Key Issues#

1. Independent PCA/STAIG training for each part produces incomparable embedding spaces, leading to failed cross-part retrieval (hit rate 14–29%)#

Solution: Use base models (scGPT gene FM, UNI2 visual FM) where all parts apply the same pre-trained weights, resulting in naturally comparable embeddings. The accuracy of scGPT is 100%, with an average SL@50 of 0.416

Key insight: Zero-shot cross-part retrieval requires a shared embedding space; joint PCA/Procrustes/joint training requires data from both parts, thus violating zero-shot constraints. Only pre-trained base models can provide true zero-shot capabilities. Users immediately realized this constraint, avoiding wasted time on unfeasible solutions

2. Failed handling of name ambiguity in scholar database — Researchers with identical names were merged into the same profile, and their paper lists covered 5–6 unrelated fields (affecting approximately 30% of analysis subjects)#

Solution: A clear warning mechanism was added to the trajectory_summary field, indicating inconsistent h-index/references and field consistency issues; it is recommended to cluster papers before analysis based on semantic similarity, institutional affiliation, and author networks

Key insight: Name conflicts are a systemic issue requiring multi-signaling approaches: h-index and field consistency, citation time distribution, institutional metadata, and author network analysis. A single data source (Semantic Scholar) is insufficient for reliable ambiguity handling

3. During env.reset(), the coffee machine model appears broken in simulations (lid floating, base offset), but shows correct assembly in HDF5 playback#

Solution: Tracing the MimicGen commit 398af01b revealed the missing position_relative_to_corner coordinate transformation. Two code blocks were restored: instance property storage with assertions and coordinate transformation in append_object(), converting corner relative positions to center relative positions

Key insight: The error was masked because set_sim_state_flat() covered the XML body position; only envReset() (generating a new initial state from XML) exposed the incorrect placement. This explains the 3-month delay despite daily use

4. Collecting 6 tasks × 29 subtype types of error recovery demonstrations requires 1,740 samples (174×10), which is very costly#

Solution: The 29 subtypes were divided into 5 recovery behavior groups based on motion primitives; 5–10 demonstrations per task and each RBG; MimicGen/IntervenGen enhancement techniques were used to generate over 100 samples for each subtype

Key insight: Recovery actions share common structures across different error types; trajectory segmentation + object/pose randomization enhancement can expand 10 source demonstrations to over 100 training samples while maintaining recovery skills

5. After 4 rounds of environment fixes using –api anthropic backend, the analysis器 shows the error “Please set ANTHROPIC_API_KEY”#

Solution: Users were explicitly instructed to switch to –api Claude_cli backend, which calls the local ‘claude –print’ command instead of cloud API

Key insight: AI spent 4 rounds fixing environment variables, conda paths, and module installation, assuming –api anthropic was correct; no questioning of the backend choice occurred until user intervention. The authentication failure pattern should have triggered questioning of the root cause earlier

6. Recall rate of LLM award recognition is almost zero — Due to a conservative “only marking specific cases” strategy, 12 out of 13 queries returned empty results#

Solution: Current methods prioritize precision over recall; LLMs can correctly reject awards but cannot access latest conference records; humans accepted this trade-off

Key insight: Award metadata is rarely present in training data and varies greatly (new conferences every year); reliable award detection requires integration with real-time APIs (OpenReview, DBLP) rather than relying solely on LLM generation

7. discover_homepage_urls() function still calls LLM when S2 homepage already exists, wasting API costs#

Solution: A early return logic was added: directly skipping the LLM call stage when S2 homepage is available

Key insight: LLM calls are expensive operations; they should only be used as a fallback after all deterministic data sources (S2 API, homepage fields) fail, not unconditionally

8. JSON format instability during Chinese analysis generation — 6 outputs (20%) require manual fixing via specialized prompts#

Solution: A two-stage approach was implemented: (1) generate analysis; (2) if parsing fails, use JSON repair prompts; humans need to strictly follow the pattern to ensure correct key names

Key insight: Chinese nested JSON is at the edge of Claude format stability; adding explicit pattern validation prompts with example structures can significantly improve compliance. English JSON is more reliable

9. DiskCache._path_for() performs mkdir operations every time a read operation occurs, causing unnecessary file system calls in hot pathsSolution: Move the mkdir logic to the put() method (only for writing paths); assume the directory exists or the file does not exist when reading the path.#

Key Insight: The golden rule of hot-path optimization is: assume resources exist when reading the path, and create resources when writing the path. This applies to all persistence layers such as file systems, databases, and caches.

Limitations of Artificial Intelligence#

Key Limitations#

  • The knowledge in conference awards is severely outdated and incomplete — capable of reliably recalling major awards from 2–3 years ago (such as NeurIPS/CVPR best papers), but there is almost no record for mid-level conferences, seminars, or recent (2024 and later) honors. Conservatively refusing to guess is correct, but it limits practicality. The recall rate for award IDs is approximately 0% (12/13 queries return nothing).
  • When proposing joint PCA and Procrustes alignment, the zero-sample constraint was not considered; these methods require simultaneous access to data from both datasets, violating deployment requirements. Only under explicit user guidance was the issue corrected.
  • Without external signals, ambiguity among researchers with the same name cannot be eliminated — lacking an institutional knowledge graph or time consistency checks; unless the field inconsistencies are very severe, merged data from upstream databases are accepted blindly. This affects approximately 30% of analyzed researchers.
  • It took 4 rounds to fix conda/environment/path issues (using claude_cli instead of the anthropic API) before the user explicitly required it. Similar repeated failures should trigger earlier root cause investigation.
  • Generation of Chinese nested JSON is unstable — the failure rate is 20% (6 out of 30 outputs have issues), requiring repair; errors appear as unclosed strings, unescaped quotes in Chinese text, and truncated structures. English JSON is more reliable.
  • When the user says “implement the following plan,” trying to enter the plan mode incorrectly interprets the detailed plan text as a trigger for the plan workflow rather than a direct execution specification. The user has to explicitly reject and clarify the intent.

Lessons Learned#

Key Experience — Key Advantage of Base Models in Cross-sample Tasks: Shared embedding space is provided without joint training; pre-trained weights ensure comparability across different inputs. Zero-sample cross-sample retrieval inherently requires this feature — any optimization for a single sample cannot replace it.#

  • Name ambiguity is the top data-quality issue in automatic scholar profiling — affecting approximately 30% of analyzed subjects. A multi-signal approach is needed: h-index and domain consistency, citation time distribution, institutional metadata, and co-author network analysis. A single data source is insufficient.
  • A three-layer strategy for restoring demonstration data augmentation: scene configuration (using different error scenarios as initial states), cross-degree (via rotation perturbations from D0 to D1/D2), and cross-type (cross-enhancement within RBG). Combining MimicGen trajectory segmentation techniques can reduce data requirements by 81% (from 1,740 demonstrations to 329 demonstrations).
  • Coordinate conversion errors in composite model systems can be masked by a state playback mechanism — this mechanism covers the positions defined in XML, and only becomes apparent at new initialization. This explains long-standing errors that are difficult to detect during demonstration playback.
  • The counterfactual reasoning framework “why it didn’t happen earlier” reveals the time dependence between technical prerequisites, data availability, and theoretical foundations. Academic achievements depend highly on the match between “technical stack maturity” and “time window” — not just individual talent.
  • User preference for a workflow is using the claude_cli backend locally (./claude --print), rather than a cloud API with keys. This preference must be remembered when calling tools or conducting research in the future. Repeated authentication failures should trigger doubt about the backend assumptions.
  • Award recognition based on LLMs has a basic recall rate limit without real-time API integration — training data cannot keep up with the update speed of conference papers. A hybrid approach is needed: (1) LLM screening candidates; (2) verification via DBLP/OpenReview API; (3) manual resolution of conflicts.
  • Paradigm shift in the robotics field between 2016–2023: deep imitation learning (2016–2019) → large-scale cross embodiment datasets (2020–2022) → visual-language-action base models (after 2023). Each phase lasted only 2–3 years; researchers who adjusted during the transition achieved disproportionate impact.
  • The golden rule of hot-path optimization: assume resources exist when reading the path, and create resources when writing the path. DiskCache mkdir moves mkdir from a frequent call in reading operations (./path_for) to a rarely called put() in writing operations, improving efficiency by 10 times. This rule applies to all persistence layers such as file systems, databases, and caches.
  • Background Bash tasks in Claude code do not inherit conda init; ‘conda run -n ENV’ or an absolute Python executable path (${CONDA_PREFIX}/bin/python) must be used. Direct activation of conda in a non-interactive shell causes CondaError errors.
  • Structured output validation should be separated from the generation process in architecture — a two-stage “generate then fix” pattern is more suitable for complex nested patterns than a single perfect output; this makes an unknowable validation layer possible.
  • Recovery behavior group abstraction: classify 29 error subtypes based on required motion primitives (re-pull, retrieval, withdrawal, redirection, rearrangement) rather than by error type.
