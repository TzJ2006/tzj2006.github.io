Learnings#

Key Learnings#

  • Pursuing hyperparameter tuning when architectural loss function convergence contradicts target metrics reliably masks fundamental encoding flaws; constraint validation must strictly mirror optimization objectives.
  • macOS ML workloads fundamentally require native hardware-backed frameworks (MLX/CoreML) over CUDA-dependent cross-platform ports to achieve real-time latency and proper GPU utilization.
  • Context persistence across fragmented coding sessions and multi-agent tools is best solved at the toolchain level using lifecycle-aware hooks and phase orchestrators rather than manual triggers or sequential CLI calls.
  • Configuration files edited via rich-text terminals are highly prone to invisible escape code corruption and static docs rapidly decay in fast-paced development. Always lint raw JSON/YAML post-edit and establish ground truth via live filesystem enumeration.
