Issues and Solutions#

Key Issues#

1. ECL Validation Relies on ‘test -f’ to Check 12 Functions, Despite Over 480 Existing Tests, Unable to Guarantee Code Functionality#

Solution: Replace all file existence checks in ECL YAML with specific pytest commands to match actual code implementation.

Key Insight: File existence does not equal functional correctness; the validation mechanism must execute the code path, not just check file content.

2. Users Are Confused About Whether “Claude Platform on AWS” via Marketplace Meets Standard AWS Activate Credit#

Solution: In-depth study of AWS Activate terms revealed that only Bedrock third-party models have specific exceptions. It was clarified that Marketplace SKUs are generally not counted toward credit.

Key Insight: Cloud billing details often depend on specific legal definitions in the credit agreement; manual verification is required before scaling up usage.

General Issues#

3. Test Suite Execution Fails Immediately Due to ‘ModuleNotFoundError’ Occurring with structlog and fastmcp. Additionally, Disk State Leakage Occurs During Session Tests Between Runs.#

Solution: Install missing dependencies via conda. Refactor tests using tmp_path fixtures to strictly isolate temporary database/filesystem states.

Key Insight: Integrated tests with persistent storage require strict isolation policies (such as temporary directories) to prevent race conditions and data leakage between test cases.
