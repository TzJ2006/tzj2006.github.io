Critical Issues#

1. W4A4 fails the ‘open the middle drawer’ task (0/50 success rate) due to task confusion.#

Solution: Identified 4-bit quantization noise in 17-35 MLP-side RMSNorm outputs. Applied per-tensor optimal clipping to these specific tensors to restore success rate to 98%, maintaining uniform A4 bitwidth for hardware compatibility.

Key Insight: The error is driven by wide dynamic ranges in RMSNorm outputs where min-max quantization wastes resolution; optimal clipping re-centers the 16 levels on the distribution mass.

2. Potential violation of academic integrity if AI generates full solutions or misses hidden instructions.#

Solution: AI proactively refused full solution generation by identifying policy restrictions; performed a programmatic scan for 1pt font text to verify PDF security.

3. Gemini outputs redundant ‘rings’ or ‘phantom’ badges (counting before occurrence) in memory tasks.#

Solution: Implemented a ‘v4’ minimalist prompt with strict temporal instructions and developed a hierarchical scoring script to segregate error types.

Key Insight: Reducing cognitive load by removing ‘action planning’ instructions allows the model to focus purely on ‘state perception’.

4. The ‘memory’ mechanism can propagate or ’lock in’ incorrect initial choices.#

Solution: Modified the prompt to emphasize that memory is a guide, not ground truth, explicitly allowing the model to ‘correct earlier mistakes’ based on new visual evidence.

Learnings#

Key Learnings#

  • In quantization, ’error’ can be decision failure (wrong task) or precision failure (wrong motion); they must be measured separately.
  • Instructors may use 1pt font ‘invisible’ text to communicate policies or warnings to AI agents.
  • Stability (preventing flickering) and Accuracy (correcting mistakes) are in direct tension when using chained memory; ‘don’t change it’ rules improve stability but kill correction.
  • Error scoring must be granular; a 0% success rate is misleading if it is actually 100% localization accuracy masked by redundant marking errors.
  • Passing raw coordinates in memory facilitates ‘stale’ pointing; models must be explicitly told to ’re-locate’ even if the target is the same.
  • The ’error threshold’ for task switching (e.g., Middle vs Top drawer) is approximately 1.0-1.5cm; reducing quantization noise below this is critical.
