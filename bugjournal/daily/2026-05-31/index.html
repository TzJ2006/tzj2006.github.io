Issues and Solutions#

Key Issues#

1. Claude Code refuses to change providers due to environment variable conflicts (CLAUDE_CODE_USE_BEDROCK=1 still exists in session history) and missing CLAUDE_CODE_USE_ANTHROPIC_AWS flag.#

Solution: Identified specific variable conflicts through environment checks, removed Bedrock overrides, added the AWS platform flag to settings.json, and forced a restart via validation script.

Key insight: Environment variables in persistent shell configurations can override JSON configuration files; sessions must be explicitly cleared for configuration changes to take effect immediately.

General Issues#

2. Git ignores resume PDF/DOCX files during deployment because they fall under the wildcard rule range in .gitignore (website/static/pdfs/).#

Solution: Modified .gitignore to exclude that directory, but used a negative pattern (!filename) to explicitly allow specific resume files, then rebuilt and submitted.

Key insight: Git’s ignore rules apply recursively; unless a wildcard (*) is used in the ignore rule, directory-level ignores cannot override file-level negatives.

3. Incorrect working directory context when calling from parent directory caused the deployment script update.ps1 to fail, leading to a config.yml path parsing error.#

Solution: Encapsulated execution in a PowerShell command, explicitly set the location as the root directory of the specific website project before invoking the script.

Key insight: Shell scripts that rely on relative paths are very fragile; context must be explicitly set when coordinating execution from different directories.
