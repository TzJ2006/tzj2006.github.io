Problems & Solutions#

Critical Issues#

1. macOS non-sandbox applications cannot persist file access permissions, and old videos in historical records report Operation not permitted error#

Solution: Enable App Sandbox permissions (com.apple.security.app-sandbox and files.user-selected.read-write), fix ensureFileAccess to add non-scoped bookmark fallback parsing, add NSOpenPanel reauthorization mechanism to showVideo/showImage

Key Insight: The macOS TCC mechanism requires App Sandbox to create security-scoped bookmarks. Non-scoped bookmarks only parse URLs but do not grant access permissions, causing old files to fail to open. A combination of sandbox + downgrade path is required

2. torch 2.7.1 and torchvision 0.21.0 ABI incompatibility causes torchvision::nms operator registration failure#

Solution: Upgrade torchvision to 0.22.1+cu126 to match torch 2.7.1 version

Key Insight: Custom operators in torchvision are linked to torch’s C++ API during compilation, and version mismatch leads to operator registration interface failure. torchvision 0.21.0 corresponds to torch 2.6.x and cannot be used with torch 2.7.x

3. Pre-compiled .so file of curobo is incompatible with current PyTorch ABI, and JIT compilation cannot find CUDA_runtime.h#

Solution: Remove old.so file, install ninja compiler tool, set CUDA_HOME=/path/to/conda/env and CPATH=/path/to/targets/x86_64-linux/include, recompile via pip install -e .

Key Insight: C++ extensions require recompilation after PyTorch version upgrade. The nvidia package installed via conda in the environment places CUDA headers in non-standard paths (targets/x86_64-linux/include/), and environment variables need to be correctly configured for JIT compilation to find them

General Issues#

4. GPU monitoring tool output width is too large and processes are displayed repeatedly, making it difficult to read#

Solution: Limit output to 80 columns, aggregate GPU lists by process, filter noise sub-processes such as multiprocessing workers

Key Insight: The original implementation grouped by GPU caused a multi-card process to appear repeatedly across multiple GPUs. Aggregation by process and display of all used card numbers in the GPU column are needed

AI Limitations#

General Limitations#

  • Failed to actively explain technical background (macOS TCC/sandbox mechanisms), requiring human follow-up to provide complete context. AI should actively explain ‘why’ when proposing solutions
  • Misunderstood GPU monitoring requirements, simplified the many-to-many relationship to one-to-many aggregation, leading to information loss. Inaccurate understanding of visualization needs for complex data relationships
  • When analyzing checkpoint path issues, started overly detailed code analysis (continuous Read operations) without first confirming the problem scope with the user. High-level parameter mapping logic should be understood first

Learnings#

Key Learnings#

  • macOS TCC permission mechanism: Non-sandbox applications cannot create security-scoped bookmarks; only non-scoped bookmarks (only parsing URLs without access permission) can be created, causing historical file access to fail after app restart. App Sandbox must be enabled to persist file access permissions
  • PyTorch C++ extension ABI compatibility: Custom operators in torchvision (such as torchvision::nms) are linked to torch’s C++ API during compilation, and versions must match exactly (torchvision 0.21→torch 2.6, torchvision 0.22→torch 2.7). Version mismatch causes operator registration failure
  • Conda environment CUDA toolchain configuration: The nvidia package installed via pip places CUDA headers in targets/x86_64-linux/include/ instead of standard include/ paths. JIT compilation of C++ extensions requires setting CUDA_HOME to point to the conda env and CPATH to include the targets path
  • Defensive programming principle: A combination of sandbox + reauthorization is more robust than a single solution. Sandbox addresses the root cause (persistent permissions), NSOpenPanel provides a downgrade path (temporary authorization), and the combination ensures users can always access files
