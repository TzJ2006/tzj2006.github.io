Issues & Solutions#

Key Issues#

1. Historical media items cannot be opened due to missing sandbox permissions and expired TCC long-term access rights, resulting in “operation not allowed” errors.#

Solution: Enable com.apple.security.app-sandbox in permissions, update ensureFileAccess to use non-limited bookmark parsing, and add an automatic NSOpenPanel prompt to reauthorize when denied.

Key insight: Without active sandbox, security-limited bookmarks cannot be silently created; a hybrid approach combining explicit sandbox activation and interactive reauthorization is required for long-term file access stability.

2. Runtime crashes occurred during evaluation due to torchvision::nms operator registration failures caused by PyTorch version fluctuations.#

Solution: Verify environment versions, upgrade torchvision from 0.21.0 to 0.22.1+cu126 via the official PyTorch index, confirm native operators are available, and then rerun the evaluation process.

Key insight: Minor version differences in the PyTorch ecosystem can cause severe C-ABI conflicts during module initialization; stable inference training cycles must match exact release versions.

3. Curobo JIT compilation failed due to missing cuda_runtime.h and undefined symbols, caused by non-standard conda/pip CUDA path isolation issues.#

Solution: Locate the CUDA runtime header in the nvidia package installed via pip, explicitly configure CPATH and CUDA_HOME environment variables, remove outdated .so files, and rebuild the extension via editable pip installation.

Key insight: Using mixed conda and pip environments blurs standard toolkit paths; native extensions require explicit include directory mapping, rather than relying on default system symbolic links or build isolation.
