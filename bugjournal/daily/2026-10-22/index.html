General Limitations#

  • Encountered frequent API rate limits (HTTP 429/403) on academic search engines, preventing complete real-time automated retrieval.

Learnings#

Key Learnings#

  • Accurate academic auditing requires distinguishing between preprint release dates, DOI registration, and formal publication dates to avoid data contamination.
  • To defend a research contribution against ‘simple combination’ critiques, it is essential to document specific, code-level mechanistic differences.
  • System architecture for variable billing must decouple usage-grouping keys from cost-lookup keys to support different service tiers.
  • A multi-layered verification strategy (Crossref $\rightarrow$ arXiv $\rightarrow$ Official Sites) is essential to overcome rate limits in large-scale academic audits.
