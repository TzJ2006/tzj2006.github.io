Problems & Solutions#

Critical Issues#

1. Cross-platform floating-point divergence causes Mac-recorded demonstrations to fail open-loop replay on Linux.#

Solution: Adopted the ‘recorded-state’ standard (X1=C) where validity is judged by the physical consistency of recorded steps rather than exact replay.

2. The π0.5 action expert’s forward method bypasses quantization because _quant_sim is only built lazily on first access, which doesn’t occur in the current loop.#

Solution: Identified the need to change the activation check to use the existence of the onnx bundle to ensure the quantized path is correctly triggered.

3. Initial research claims were statistically invalid or unsupported by sufficient data regarding the ‘Agent Harness’ advantage.#

Solution: Pivoted the narrative to focus on memory precision (Success Rate / Theoretical Ceiling) and repositioned the Agent as a supporting infrastructure tool rather than a primary innovation.

4. Directly merging Codex-Cockpit code failed due to React/Svelte and backend structure incompatibilities.#

Solution: Re-implemented specific logic (project usage, reset forecasting) within the native Svelte 5 and Rust architecture.

5. The right-click menu in WeChat 4.x lacks the ‘Add to Stickers’ option.#

Solution: Implemented an automation route via the Emoji Panel (Alt+E) and the ‘Custom Stickers’ tab.

6. Modules/gadget still importing code from parent workspace via sys.path hacks.#

Solution: Refactored to use an installable ‘model_access’ package and explicit CLI entry points.

7. PermissionError during concurrent lock-file initialization in ResourceBoard.#

Solution: Implemented atomic lock-file creation that avoids truncating files held by other processes.

8. NCL performance degradation due to effective rank collapse when using scGPT inputs.#

Solution: Noted as a critical finding; investigating if smoothing-heavy approaches or different reconstruction objectives can mitigate this.

Learnings#

Key Learnings#

  • Decoupling architectures requires strict policies on how resources (GPU/Models) are discovered and claimed across process boundaries, not just code changes.
  • Lazy initialization of quantization simulators can silently bypass quantization in evaluation pipelines if the specific property is never triggered.
  • Success rate alone is an insufficient metric for comparing harness methods; ‘Success Rate / Theoretical Ceiling’ is a much more robust measure of memory precision.
  • A multimodal framework’s strength lies in providing a ‘shared coordinate frame’ for cross-slide comparison, distinct from per-slide trained models.
  • Iterative refinement of data structures is essential when adding dimensions (project/session) to existing aggregation pipelines to avoid breaking stats.
