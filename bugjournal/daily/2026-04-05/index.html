Problems & Solutions#

Critical Issues#

1. Linux WM cannot atomically handle dynamic resize of transparent borderless windows, leading to systematic +305px/+113px position offsets, flickering probe/corrective mechanisms, and inconsistent cutting of WebView and native window sizes#

Solution: Fixed window size is set to expanded (152×56) and never resizes; GDK input_shape_combine_region is used to control click penetration: only the ball area (56×56) when collapsed, and the full window during expansion and dragging.

Key Insight: This is a platform architecture issue rather than a computational bug: Linux WM interprets the same rect request differently; eliminating resize is the only true solution, and local patches only shift symptoms.

2. Life-Copilot Discord Bot continuously replies “OAuth authentication required” for calendar queries, due to two overlapping issues: (1) claude -p does not load project-level MCP configuration; (2) MCP tool calls in non-interactive mode are silently denied permissions#

Solution: –mcp-config .claude/mcp_servers.json and –permission-mode bypassPermissions were added sequentially to the claude_adapter.py command; by directly running claude -p, the permission_denials field was used to locate the root cause.

Key Insight: The Claude CLI session-less mode and interactive mode MCP loading behaviors are different; the –allowedTools wildcard is unreliable in non-interactive mode due to competition with MCP server initialization; –permission-mode bypassPermissions is the correct mode for backend service calls.

3. Three platform-level details emerged after the first implementation of the fixed window solution: ball display flattening (window builder still uses 56×56 for creation), inability to expand (CSS does not apply data-direction), and dragging failure (input shape blocks X11 events after mouse leaves the ball area)#

Solution: (1) window builder uses expanded size and GTK geometry_hints to lock min=max; (2) CSS justify-content always takes effect based on data-direction; (3) a set_float_ball_dragging command was added, expanding the input shape to the full window during dragging and restoring it after completion.

Key Insight: WebKitGTK has a default minimum natural size constraint; X11 layer input shape event interception occurs earlier than setPointerCapture, so the area must be expanded synchronously on the Rust side.

General Issues#

4. When structlog wraps stdlib logging, the extra={} field silently disappears from JSON output#

Solution: A structlog.stdlib.ExtraAdder() was added to shared_processors, merging the extra field into structured output.

Key Insight: The extra parameter is not passed automatically when structlog wraps stdlib; ExtraAdder must be explicitly added, resulting in silent field loss without errors.

5. When users request a rollback of “current session changes,” the AI mistakenly uses git stash, nearly causing loss of historical work#

Solution: After git stash pop, three specific changes of this session were manually identified and undone precisely.

Key Insight: Git stash affects all uncommitted changes, making it unsuitable for scenarios where only current session changes are rolled back; git diff should be used first to clarify the change scope before individual undo.

Learnings#

Key Learnings#

  • Linux X11 WM lacks atomic guarantees for resize requests for transparent borderless windows; different WMs interpret the same coordinate with different semantics, leading to systematic offsets; eliminating resize (fixed window + GDK input shape) is the only reliable solution, and local patches only transfer symptoms
  • Complete MCP configuration in Claude CLI -p mode requires two steps: (1) explicitly pass –mcp-config to load project-level tools; (2) add –permission-mode bypassPermissions to bypass permission confirmation that cannot be completed under non-interactive mode; the wildcard in –allowedTools is unreliable due to competition with MCP server initialization in this mode, and bypassPermissions is the correct pattern for backend service calls
  • GDK input shape intercepts events at the X11 layer, and setPointerCapture cannot bypass it; in dragging scenarios, use set_float_ball_dragging command on the Rust side to temporarily expand input shape to the entire window; with cairo-rs 0.18 + gdk 0.18, input_shape_combine_region can be used directly in Tauri with_webview callbacks without adding complex dependencies
  • When debugging nested process CLI tools (main process → Claude CLI → MCP server), recording actual command-line parameters first and then isolating each parameter for verification is more efficient than guessing parameter behavior
  • The divergent exploration of ccplan skills (6 solutions) + anti-reviews + feasibility testing process can effectively transform complex platform architecture issues into executable plans; ECL documents provide cross-session context persistence, reducing repeated analysis costs

Practical Learnings#

  • When wrapping stdlib logging with structlog, the stdlib extra={} parameter must explicitly include ExtraAdder() processor to appear in output fields; otherwise, fields are silently lost without errors
