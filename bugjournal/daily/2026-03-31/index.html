Problems & Solutions#

Critical Issues#

1. Leiden clustering needs fair comparison with KMeans, but Leiden controls the number of clusters via the resolution parameter, making precise matching of n_clusters impossible.#

Solution: Implement binary search in cluster_with_leiden(): iterate and adjust resolution within [0.01, 10] until the number of clusters matches, up to 20 iterations.

Key Insight: The relationship between Leiden’s resolution and the number of clusters is monotonic; binary search can efficiently match the target number of clusters, enabling fair comparison with KMeans.

General Issues#

2. HD pipeline Vision Extraction fails: VisionExtractor uses the data_root/section_id path to locate images, but HD data are in crop_dir, causing failure in 11/13 experiments.#

Solution: Add crop_dir parameter to VisionExtractor.init; pass image_dir_override=crop_dir in extract(); use image_dir_override in _load_image_and_coords(); pass crop_dir when creating VisionExtractor in runner.py.

Key Insight: The image storage structures for DLPFC and HD data are completely different; the pipeline needs explicit distinction between the two dataset paths.

3. SLURM script uses source activate General, causing conda environment activation failure, and all Leiden experiments run on a GPU-free login node.#

Solution: Replace source activate in the SLURM script with eval $(conda shell.bash hook) && conda activate, and resubmit the job.

Key Insight: SLURM nodes in the DCC cluster need an explicit conda shell hook initialization; direct source activate is not sufficient.

4. Default logic error in run_pipeline.py: When the hd_global configuration segment exists, it automatically switches to the HD dataset, causing Leiden DLPFC experiments to run in HD mode.#

Solution: Change the default value of dataset to DLPFC, and switch only when –dataset HD is explicitly specified.

Key Insight: The presence of the hd_global segment in the configuration file should not affect the default dataset selection.

Learnings#

Key Learnings- Leiden clustering performs comparably to KMeans on HD data (pca_leiden ARI≈0.333 vs pca ARI≈0.288 on DLPFC), showing significant improvement for simple gene-only methods, but its benefits diminish for graph comparison methods like STAIG—STAIG’s advantage lies in the spatial graph structure, which is independent of clustering algorithms.#

  • Simple fusion strategies (concat/mean/element_wise_sum) on HD have lower ARI than single-modal PCA (0.19–0.20 vs 0.351), indicating that naive fusion may suffer from information dilution in large-scale HD data; attention and staig_fusion are exceptions (attention ARI=0.342).
  • On HD data (STHD Ground Truth, 3 clusters: Epithelium/Connective Tissue/Smooth Muscle), vision-only UNI2 achieves the highest NMI (0.387), but ARI is lower than PCA (0.344 vs 0.351)—NMI and ARI may not be consistent across different data, and both metrics should be reported together.
  • The HD section of MISO(Nat Methods) uses Visium HD colorectal cancer to show spatial expression of SPP1 (tumor-associated macrophages) and CEACAM6, which can serve as a reference framework for verification of MIHD Fig 4 marker genes.

Practical Learnings#

  • Matching the STHD annotation file (8um_squares_annotation.csv) with adata obs requires using r_big/c_big coordinates, achieving a 100% matching rate; after merging CE+Tumor, 3 meaningful clusters are obtained (Only 4 spots in Outside can be ignored).
