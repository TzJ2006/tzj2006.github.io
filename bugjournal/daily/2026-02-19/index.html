Issues and Solutions#

Key Issues#

1. How to prove that the error recovery benchmark can “generate scenarios” — Need evidence that data actually improves models as a contribution to papers.#

Solution: Design G4 phase (proof of dataset usefulness) as a four-step experiment: (1) Convert over 2000 scenarios into LeRobot format with state and image observations; (2) Fine-tune π0.5 using LoRA on A800, train for 2–4 hours on error scenarios; (3) Conduct stratified sampling evaluation on retained test samples; (4) Measure improvement (expected 15–30% SR gain, 10–20% RP gain, statistical significance analysis via bootstrap CI and Wilcoxon test). Key Insight: Benchmark usefulness requires closed-loop validation: error data → model training → measurable performance improvement on unseen errors. This is the core paper contribution beyond scenario generation infrastructure — namely “four-pillar validation,” which distinguishes publishable benchmarks from simple datasets.

2. UNI2 base model accuracy in DLPFC spatial clustering is only 0.11–0.16 (compared with 0.5+ for gene+image multimodal), and brown repeated regions appear uniformly in clustering results.#

Solution: Identified 5 root causes: (1) Differences in training data domains (more cancer data, fewer brain data); (2) Incompatible pre-training tasks (rough organizational classification vs fine-grained layer detection); (3) Subtle differences in DLPFC layers (cell density/size, not color/texture); (4) Redundancy of features and gene expression; (5) Lack of spatial context. Analysis shows UNI2 clustering is based on morphological similarity (vessels in all layers), not biological categories. Proposed 6 adaptation methods (STEGO, SCAN, BYOL, DINOv2-GAT, TTT-MAE, SFDA), ordered by solution order: domain-specific pre-training → adaptation during testing → feature optimization → task-specific fine-tuning. Added H&E reference panel in visualization to confirm hypothesis. Key Insight: Pure visual encoder clusters based on morphological features rather than biological functions — a typical fine-grained recognition problem common in computer vision (bird subspecies, rock types, cell morphology). Lower accuracy reflects structural grouping (similar objects) rather than functional grouping (biologically similar objects). General base models learn rough semantic information; for fine-grained tasks, domain-specific fine-tuning or feature optimization is needed.

3. Stage imbalance in error recovery benchmark dataset — 90% of scenarios belong to pre_reach/reach and transport/place stages, while transport/place stage is completely empty (0 scenarios).#

Solution: Adopt BC-RNN strategy as a key means to reach subsequent stages, reduce detector minimum step threshold from 100 to 5–50 to capture failure in lift/traffic stages. Use MimicGen to generate over 200 example variants to increase trajectory diversity and trigger opportunities for later stages. Key Insight: Stage coverage requires strategies with sufficient success rate to enter later stages (optimal timing for BC-RNN), while detector timing needs adjustment — random strategy fails too early (never reaches improvement point), Pi0 SR is 0% (never reaches mastery), only BC-RNN reaches transport/place stage during failures. This is a “reachability problem” determined by success rate distribution.

How to rigorously verify that the 24 error classification methods are principled, comprehensive, and non-duplicate, suitable for academic publicationSolution: Three-pillar validation: (1) Map the 8 categories to FMEA failure modes in ISO 15066/10218/IEC 61508 industrial safety standards to provide theoretical basis; (2) Prove integrity through a 6-stage × 3 families = 18 cell matrix to ensure no blind spots; (3) Use Cohen’s/Fleiss’ kappa for statistical validation (goal: κ > 0.6 within the same category, κ < 0.3 between categories) to verify type discrimination.#

Key Insight: Validation of academic classification methods requires theoretical basis (industry standards provide reasons based on FMEA) and empirical evidence (statistical independence tests prove no redundancy) — one cannot rely solely on intuition to confirm the 24 types.

If the VLA server crashes during operation, the M14 baseline evaluation (5448 cases, runtime 5–15 hours) may lose all progress.#

Solution: A recovery function is implemented in collector.py: it reads the existing episodes.jsonl file at startup, builds a set of completed tuples (scene ID, strategy name, seed), skips these tuples in a triple loop, and rebuilds the all_episodes dictionary to maintain accuracy of the summary. The –resume flag is added to 3_collect_data.py. Now with automatic recovery, the risk of crash is avoided.

Key Insight: For long-running data collection (>1 hour), appendable JSONL logs and recovery logic are crucial. The key lies in idempotency: reading back JSONL and rebuilding the summary dictionary ensures consistent final results, whether the operation is completed once or multiple attempts at recovery.

Users do not understand the concept of “recovery training data” in the second-phase plan, leading to obstacles in plan approval.#

Solution: Specific examples are provided, comparing normal demonstrations (reset → success) with recovery trajectories (error state → adjustment → success); it is explained that it teaches the model “how to correct errors,” rather than just “how to do things right from the start.” Users ultimately choose manual remote operation to obtain high-quality data, although this increases time costs.

Errors such as “client_loop: send disconnect: Bad file descriptor” and “tried to write to a nonexistent pipe” occur when connecting VS Code Remote-SSH to the HPC cluster.#

Solution: Windows OpenSSH does not support Unix domain sockets used by ControlMaster/ControlPath/ControlPersist. These three options are commented out in the ~/.ssh/config file, and expired socket files are removed from ~/.ssh/sockets/. The connection is immediately restored.

Lessons Learned#

Key Lesson – Pure visual encoders cluster based on morphological similarity rather than biological domain: UNI2 groups blood vessels in different layers because they look similar, which explains why spatial ARI based solely on vision is limited (0.11–0.23 vs 0.5+ multimodal). HEST-1k shows that the pathological base model performs significantly better than the ImageNet baseline model (Pearson’s r=0.414 for UNI2, r=0.326 for ResNet50), but there is no comprehensive vision-based spatial domain clustering benchmark — most papers only evaluate multimodal fusion effects without单独 evaluating visual encoder performance. Gene expression is needed to distinguish functional regions with similar visual appearance.- Error recovery benchmarks must prove their effectiveness through four dimensions: (1) Large-scale diverse data (2000+ scenarios); (2) Theoretical classification systems (FMEA/ISO standards); (3) Descriptions of baseline performance characteristics (4+ strategies); and (4) Demonstration of improvements in model training (15–30% SR gain). This distinguishes publishable benchmarks from toy datasets—the core contribution of the paper lies in closed-loop validation: error data → model training → measurable improvement.#

  • Cross-domain literature search is valuable for identifying solution patterns. The image-based clustering problem in spatial transcriptomics is almost identical to the following issues: (1) Fine-grained bird classification (subspecies differ only in beak shape/feather pattern); (2) Remote sensing techniques (ImageNet features are not applicable to satellite images); (3) Microscope techniques (material microstructures); (4) Geology (rock thin sections). All these fields tend to follow the same four-tier solution hierarchy: pre-training in the specific domain → adaptation during testing → feature refinement → task-specific fine-tuning. This indicates that failure patterns in deep learning are common across different fields.
  • Phase imbalance in error scenario generation stems from “reachability issues” caused by the success rate distribution—requiring 60–70% SR (the best point for BC-RNN) to reach later stages while still producing errors. Random strategies fail prematurely (never reaching the target), Pi0 has 0% SR (never reaching the target), and only BC-RNN can achieve transportation/placement functions despite generating errors. The solution requires BC-RNN + adjusted detector timing (minimum step threshold changed from 100 to 5–50) + MimicGen trajectory diversity (from 10 to 200 examples).
  • When users say “I need to know what/why/how,” they expect a workflow where they understand first and then act: explain the concept first → user decides the direction → then develop a detailed plan. Instead of developing the plan first and then explaining. Strategic planning issues (data collection methods, task scope) should be addressed before developing a detailed implementation plan, not after—this avoids rework. For complex multi-milestone projects, a document-driven development approach can ensure shared understanding and consistency before execution, which is crucial for research requiring advisory feedback loops.
  • The evaluation paradigm fundamentally changes the metrics: the same task (organizational type recognition) is evaluated as supervised classification (labeled, linearly separable via KNN test) and unsupervised clustering (unlabeled, natural clustering structure via ARI test). They measure various aspects of embedding quality—high KNN accuracy does not guarantee good ARI. This explains why the success of 9-class classification on CRC-100K cannot predict DLPFC spatial domain clustering performance.
  • BYOL (self-tuned latent) addresses the main weakness of SimCLR: it requires large batches and negative samples. BYOL adopts a teacher-student framework, combining EMA updates and a predictor head to prevent collapse, enabling it to handle small batches (256 vs 4096+), enhanced selection, and domain transfer. This explains why STAIG chose BYOL over SimCLR when selecting histological patches (patches that look similar in adjacent layers should not be treated separately as negative samples).
  • FMEA (Failure Mode and Effect Analysis) in industrial safety standards (ISO 15066 for collaborative robots, ISO 10218 for robot safety, IEC 61508 for functional safety) provide a strict theoretical basis for incorrect classification of robots—mapping 8 categories to standardized failure modes such as “loss of grip,” “uncontrolled release,” and “accidental contact.” Verification of academic classification standards requires theoretical basis (industry standards) and empirical evidence (Cohen’s/Fleiss’ kappa: κ>0.6 within the same category, κ<0.3 between categories).
  • VLA model landscape for error recovery: 8 models claim to have recovery capabilities, but only 2 are open source (RoboFAC, VLAC). FailSafe and VLA-SCT are the most suitable for integration (no training required, plug-in architecture, already verified on π0/OpenVLA). Recovery methods are divided into three categories: dual system (fast/slow), active (subtask backtracking), and reactive (supervisor-guided correction). MimicGen can expand 10 examples to more than 200 variants to increase trajectory diversity, requiring has_offscreen_renderer=True in VLA training.
  • The resume logic for long-term data collection must reconstruct the summary state from JSONL, rather than simply skipping episodes. A simple approach (just skipping completed episodes) will destroy the final summary statistics. The correct approach is: (1) Read JSONL at startup, (2) rebuild the all_episodes dictionary, (3) add completed tuples to the skip set, (4) continue collecting. This ensures idempotency: running A → collapse → recovery → B produces the same result as running A+B once.

Practical Experience#

  • Large file reading strategies: Use constraint parameters for initial exploration, then use target offset ranges or Grep for specific content; avoid reading the entire file unless necessary. For files exceeding 30k tokens, reading 400 lines per chunk works well. Document reconstruction with “complete retention” requirements needs verification: compute all checks before and after to ensure no information is lost.
  • Windows OpenSSH does not support Unix domain sockets (ControlMaster/ControlPath), leading to silent failures and hard-to-understand error messages (“wrong file descriptor,” “non-existent pipe”). The solution is not to switch the SSH client, but to disable connection reuse options. This reminds us that cross-platform compatibility issues often manifest as low-level errors, looking like bugs rather than functional unavailableness.
