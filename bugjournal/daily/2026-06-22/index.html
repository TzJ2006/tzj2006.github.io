Problems & Solutions#

Critical Issues#

1. Codex PostToolUse hooks failed due to schema mismatches with Claude hooks, specifically regarding tool names (apply_patch vs Edit/Write) and file path handling.#

Solution: Implemented a TypeScript adapter layer to normalize payloads; updated hook matchers; fixed Windows stdin BOM/TTY issues and removed stale config entries.

Key Insight: Different LLM clients use distinct internal schemas for tool execution hooks; a unified adapter layer is required for multi-agent support, with specific attention to OS-level input stream differences.

2. SlideshowController in Desktop Video suffered from observer leaks and security scope errors during rapid video switches.#

Solution: Added explicit observer removal logic, fixed security scope bookmark release timing, and patched parallel review script execution to use thunks instead of promises.

Key Insight: Event-driven UIs require rigorous lifecycle management for observers; asynchronous workflow scripts often fail silently if promise objects are passed directly to functions expecting deferred calls.

3. Ambiguity in spatial transcriptomics results regarding whether Foundation Models (scGPT/TEDDY) were superior to traditional baselines.#

Solution: Aggregated ARI metrics by section and generated fair comparisons with uniform encoders. Confirmed the ‘FM Paradox’: FMs excel at cross-sample retrieval but fail to improve single-slice clustering compared to raw HVG.

Key Insight: Base model embeddings have distinct strengths: superior for broad data understanding (retrieval) but inferior for local structural precision (clustering) compared to engineered baselines like HVG.

4. MuJoCo rendering fell back to CPU (llvmpipe) on Tianhe-2 compute-only nodes, blocking evaluation.#

Solution: Staged NVIDIA GL/EGL user-space libraries and configured glvnd vendor paths to enable GPU rendering in containers lacking full driver capabilities.

Key Insight: Compute containers often separate CUDA compute from OpenGL graphics; enabling GPU rendering requires manually staging userspace graphics libs if the host driver version supports it.

5. QueST training script crashed on small datasets due to hardcoded batch size assumptions for larger donor sets.#

Solution: Inspected source code, identified the hardcoded logic, and patched the export script to explicitly set batch_num for two-slide runs.

Key Insight: Public scientific models often contain implicit dataset scale assumptions; source inspection is necessary before integration to avoid runtime crashes with smaller subsets.

General Issues#

6. Claude Code automatic skill installation failed due to malformed symlink paths containing trailing placeholders.#

Solution: Corrected the bash loop in the symlink generation script to strip invalid suffixes, ensuring valid file links.

Key Insight: Automated script generation can introduce subtle string formatting bugs; manual verification of file integrity post-instantiation is critical.

7. Hugging Face model downloads stalled at 0 KB/s despite active progress indicators.#

Solution: Identified that HF_HOME directory misconfiguration caused token authentication bypass; fixed by exporting HF_TOKEN and verifying login status.

Key Insight: Custom home directories often alter credential lookup paths; explicit environment variable injection is required for authenticated downloads in non-standard environments.

Learnings#

Key Learnings#

  • Foundation Models (scGPT/TEDDY) excel in cross-sample niche retrieval but fail to improve single-slice clustering compared to raw HVG, a key finding for spatial transcriptomics analysis.
  • When supporting multiple LLM clients with hook systems, rely on official SDK documentation to validate tool_input structures, as they often diverge significantly in naming conventions and data formats.
  • Tianhe-2 A800 pods can run CUDA 12.8 wheels on a 535 driver (CUDA 12.2) via minor-version compatibility, confirmed by a successful Torch matmul test.
  • Containerized HPC environments often separate compute and graphics drivers; one can enable GPU rendering in a compute-only pod by stanching NVIDIA GL user-space libraries locally without root privileges.
  • Adversarial review scripts require robust error handling for async/await patterns in their own orchestration logic; failing to wrap async calls in thunks can lead to deceptive ‘success’ or silent failure reports.
  • QueST’s adversarial batch removal requires a minimum number of batches/donors to function correctly; running on only 2 slides from the same donor causes code crashes due to hardcoded shapes.
  • Semantic versioning strings require numerical comparison logic rather than lexicographical when handling major version shifts (e.g., 0.9 vs 0.19).

Practical Learnings#

  • Always use non-interactive flags (e.g., vitest run) for automated testing scripts to prevent hanging processes in CI/AI environments.
  • Clustering ARI metrics are highly sensitive to random seeds (mclust EM); results must be evaluated as distributions over multiple seeds, not single points.
