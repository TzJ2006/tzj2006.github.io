Problems & Solutions#

Critical Issues#

1. Potential proprioception leaks and non-visual window advancement in Gemini-driven memory tasks.#

Solution: Enabled ‘VISUAL_ONLY’ to strip state and ‘VISUAL_TRACK’ to advance windows based on VLM tip-detections rather than TCP/proprio data.

2. OmniJev PickHighlight reporting low recall and 2B model underperforming in temporal tasks (Swap/StopCube).#

Solution: Corrected metric frame population and shifted architecture to use code for temporal logic/identity while VLM handles per-frame perception.

3. W4A4 simulation showing 0% success rate while actual hardware maintains higher accuracy.#

Solution: Determined simulation is overly pessimistic due to aggressive 4-bit rounding on tensors that hardware actually processes in FP16.

4. Robotics pipeline errors including JSON serialization (np.bool_), uncropped image formats in BC-RNN, and human demo state mismatches.#

Solution: Identified serialization needs in ‘core.py’, required HWC image fixes in ‘policy_adapter.py’, and corrected ‘replay’ settings to ensure error-state restoration.

5. Vite processes remaining active on Windows after exiting the Tauri app via the system tray.#

Solution: Replaced a polling mechanism with an explicit POST-based notification sent from the Rust backend to a dedicated Vite plugin endpoint.

6. WeChat stickers being sent as images and false-positive database confirmation errors.#

Solution: Implemented UIA-based panel browsing for sticker similarity matching and disabled strict verification to handle WeChat write latency.

7. C2S NaNs occurring on specific GPU nodes and invalid matrix command arguments.#

Solution: Identified node-specific hardware issues (h36-6) and excluded them from templates; reconciled command arguments via subagent audit.

Learnings#

Key Learnings#

  • A lightweight 2B VLM is excellent for recognition but needs code-driven assistance for temporal reasoning and identity tracking.
  • On specific hardware, 4-bit simulations are unreliable for predicting accuracy due to hardware automatically using FP16 for certain ops.
  • Seeding all randomness (including env resets and Python’s hash()) is critical for robotics benchmark reproducibility.
  • Visual prompts (drawing memory into observation) significantly outperform text-based memory in path-related tasks.
  • In multi-process environments like Tauri/Vite, explicit exit signaling is more robust than ancestry/polling tracking on Windows.
