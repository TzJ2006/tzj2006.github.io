Issues and Solutions#

Key Issues#

1. AI Companion workflow suffers from portability issues due to absolute path injection. The parallel AI agent workflow encountered API rate limits (429 errors).#

Solution: A hybrid architecture was proposed: supplier-first tools are treated as relative paths, and the heavy load engine is externalized. Parallel LLM distribution was changed to a sequentially backend workflow subject to rate limits.

Key Insight: Absolute paths undermine portability; large-scale parallel LLMs require strict rate limits and real data provided manually to restore analytical quality in “phantom” projects.

2. The “pre-edition specification” protector conflicts with the existing ECL (DEC-004/001) regarding absolute path and self-authorization risks (BF-03).#

Solution: A threat model was analyzed: automated pre-edition protectors cannot rely on AI-generated states. A design was implemented where hooks prevent Claude editing, and git pre-commit anchors verify human intent.

Key Insight: Automated protectors must rely on immutable signals (git history) rather than internal flags to mitigate self-authorization attacks.

3. QueST jobs failed due to UnboundLocalError: ‘sections’ was used before assignment in benchmark_rm_ideal.py. HD Slurm jobs stalled for over 24 hours.#

Solution: Variable assignments were moved to the appropriate scope, and the job was rerun. The unavailable a6000 GPU was replaced with the available gc500Ada card via variant scripts.

Key Insight: Python variable scopes require strict sequential pre-assignment; if specific hardware types are strictly requested but unavailable, heterogeneous GPU partitions may cause deadlocks.

Learning Outcomes#

Key Learnings#

  • MIHD’s StaigFusionTrainer is mathematically equivalent to the original STAIG under default paths; differences arise from n_clusters source code, not architectural issues. Merging the pipelines of AI Companion with the portable installation methods of gadget can resolve core conflicts.
  • To make TypeScript CLI tools portable, reliance on supplier dependencies or npx-style parsing must be adopted. For large Python repositories, the /cconboard phased approach is highly effective, but if the work tree is dirty, pre-configured tests are required.
  • Self-authorization attacks (BF-03) exist for “pre-edition specification” gatekeeping; gatekeeping must depend on external states (git/ask) rather than internal flags. Heterogeneous GPU partitions require precise node status diagnosis to avoid queue backlog.
