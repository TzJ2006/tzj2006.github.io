Issues and Solutions#

Key Issues#

1. Desktop video: The failure rate of video/image recovery after application restart is 100%, with code 257 “operation not allowed” error.#

Solution: Four-step fix: 1) Add com.apple.security.files.bookmarks.app-scope permissions to the permission file (originally empty dictionary). 2) Add fallback in restoreFromBookmark: if withSecurityScope fails, try using options:[] to restore old non-security-range bookmarks, then save them as security-range bookmarks. 3) Track active URLs in activeSecurityScopedURLs dictionary and release them in the clear() function. 4) Automatically resolve bookmark issues before file I/O. Key insight: macOS sandbox bookmark system requires compile-time permission declarations and runtime URL.startAccessingSecurityScopedResource() lifecycle management. When the permission file is empty, bookmark creation reverts to non-security-range method, leading to failure during restoration with.withSecurityScope, resulting in code 257 error. Due to concurrent file handle competition, errorLog() never recorded errors, masking the root cause for months.

2. MIHD: STAIG two-stage fusion ignored gene encoder embeddings, making scGPT+UNI2+STAIG equivalent to PCA+UNI2+STAIG.#

Solution: Tracked in models/Fusion.py and pipeline/runner.py: staig_fusion uses staig_gene_feat (from cached original HVG matrix) instead of gene_emb parameters. This is an architectural issue, not a bug. This key finding was recorded in the weekly report as it affects the interpretation of all STAIG results. Key insight: Gene encoder (PCA/scGPT) outputs are used only by non-STAIG fusion methods. For graph-based fusion like STAIG, pre-trained spatial embeddings do not enter GCN node features. This explains why scGPT performs poorly: it aims to achieve cross-organizational generalization rather than maximizing variance within the dataset like PCA.

3. VLA evaluation: Although Pi0.5 reached 100% GPU utilization during training, GPU utilization was only low (about 10%) during evaluation, resulting in slower evaluation speed.#

General Issues#

5. When using srun on GPU nodes under heavy load, background tasks experience timeouts, and the command response time exceeds 60 seconds.#

Solution: The –overlap flag was added, and the timeout expectation was lowered. When nvitop is unavailable or too slow, it falls back to the simpler nvidia-smi. Accepting nodes with heavy load results in higher command latency. Key Insight: When GPU nodes are operating at full load, management commands executed via srun may experience significant delays; monitoring scripts should be designed to handle timeouts gracefully and use lightweight alternative commands.

6. MIHD: During the embedding process of scGPT (512 dimensions) and UNI2 (1536 dimensions), the mclust clustering program hangs indefinitely.#

Solution: In visualize_from_cache.py, the default mclust is replaced by kmeans via the –cluster_method flag. High-dimensional data makes the EM algorithm of mclust computationally difficult to implement. Key Insight: Gaussian mixture model clustering performs poorly after more than 100 dimensions. For basic model embedding (512d–1536d), kmeans or spectral methods must be used to achieve actual operation.

7. Desktop video log files contain over 1550 junk entries per session (updateClockLabels × 879, startScreensaverTimer × 671).#

Solution: Remove dlog from updateClockLabels (called once per second during screen saver). Move dlog in startScreensaverTimer after all early exit protections (only record actual scheduling timers). Remove dlog from idle timer callbacks. Key Insight: High-frequency dlog calls in timer callbacks generate large log files, masking real errors. Logging should be based on state transitions rather than periodic timing.

Lessons Learned#

Key Experience – Basic model embedding (scGPT 512d, UNI2 1536d) cannot replace dimensionality reduction in clustering tasks (PCA 50d). scGPT is designed for cross-dataset transfer, not variance handling within the same dataset. Architecture choice (only gene or multi-modal fusion) is more important than embedding quality: QFormer achieves 2× higher ARI improvement by learning gene visual alignment compared to using scGPT alone. STAIG graph-based fusion completely ignores the gene encoder output and directly uses the original HVG matrix.#

  • In VLA models, action chunking fundamentally changes GPU usage: Pi0.5 outputs a 50-step action sequence, so a 400-step evaluation experiment requires only about 8 inference calls (about 20 seconds GPU work) for a total of 200 seconds, resulting in a GPU utilization of about 10%. The bottleneck shifts from GPU computation to pipeline serialization (CPU preprocessing, WebSocket I/O, simulation steps). Batch evaluation using timer-based request collection can improve throughput.
  • macOS sandbox security scope bookmarks require both compile-time permission declarations (in .entitlements file) and runtime lifecycle management (startAccessingSecurityScopedResource/stop). If the permission file is empty, it defaults to non-security-scope bookmarks, leading to failure during restoration. When permissions are missing, the bookmark system provides no visible error feedback.
  • Log archaeology (reading complete log files) can reveal hidden patterns in code: “non-safety-scope-preserving bookmarks” appear 20 times across multiple sessions in Desktop Video, revealing missing permission information. Concurrent write errors (errorLog FileHandle competition) silently destroy diagnostic information. High-frequency timer logs (879 calls to updateClockLabels) mask real errors, so state-based logging should be used instead of count-based logging.
  • Slurm’s srun with –jobid flag can bypass SSH PAM restrictions via srun in the assigned job context, such as slurm_adopt, which is very important in clusters with strict node access controls. When GPU nodes operate at 100% utilization, management commands executed via srun may experience significant latency (over 60 seconds). Therefore, robust monitoring scripts should handle timeouts gracefully and use lightweight alternative commands (such as nvidia-smi instead of nvitop).
  • External dependency documents should serve operational purposes (structured list: path, size, purpose, reference), separate from conceptual documents (explatory guides). A clear file list with precise paths enables reproducibility and dependency auditing. For VLA benchmark projects, a comprehensive list includes 14 categories: configuration directories, logs, binary files, environment variables, Python packages, rclone paths, Git repositories, Ollama models, conda environments, datasets, checkpoints, startup programs, and troubleshooting guides.

Practical Experience#

  • SwiftUI’s .mask() + .ultraThinMaterial can achieve “glassmorphism text” effects on macOS 12.4 and later by masking the blur effect of the material within the text shape. The material automatically samples the content below it in the window view hierarchy (video player → material → masked text). The dual-layer method (material mask + gradient overlay) simulates the physical glass effect with refraction and mirror highlights.
  • Gaussian mixture model clustering (mclust) performs poorly after more than 100 dimensions. For basic model embedding (512d–1536d), kmeans or spectral methods must be used for actual operation. The EM algorithm of mclust becomes computationally difficult in high-dimensional data.
