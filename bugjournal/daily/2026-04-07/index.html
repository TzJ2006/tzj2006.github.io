Problems & Solutions#

Critical Issues#

1. Hugo was not installed, causing the script to terminate at Step 5 with ‘hugo: command not found’ (exit 127)#

Solution: The user installed Hugo extended v0.154.5 using the system package manager.

Key Insight: set -e directly converts any command failure into script termination. The absence of Hugo prevented the 7-step process from reaching critical build stages.

2. Themes/PaperMod/ and public/ directories were missing, preventing Hugo build and deployment.#

Solution: The user cloned the PaperMod theme and tzj2006.github.io deployment repository.

Key Insight: Hugo site deployment depends on three independent components (hugo binary, theme repository, deployment git repository). Any missing component causes silent or termination-style failures, and these prerequisites should be clearly stated in the documentation.

General Issues#

3. The static/videos directory was missing, causing a find error and set -e termination at Step 4.#

Solution: Added a directory existence check ([ -d “$DIR” ]) before the find command; the step is skipped if the directory does not exist.

Key Insight: Find operations on optional/empty directories must be protected in set -e scripts, otherwise normal “empty directory” scenarios can trigger unexpected script termination.

4. PIDs from HandBrakeCLI rollback branch were duplicated into pids and original files were not replaced after compression (output: .hb.mp4).#

Solution: Moved pids+=($!) and the echo statement into their respective if/else branches; added && mv after the HandBrakeCLI command.

Key Insight: The PID tracking logic for parallel background tasks must align precisely with the if/else control flow. Placing common code outside branches can lead to duplicate execution and silent data loss bugs.

5. git push failed due to missing GitHub authentication (could not read Username for ‘https://github.com’）’)#

Solution: The user configured SSH key or gh auth and re-run the script; the script passed completely.

Key Insight: HTTPS remote requires pre-configured credentials in a non-interactive shell. The deployment repository should use SSH remote to avoid environment differences.

Learnings#

Key Learnings#

  • Hugo site deployment requires three independent dependencies to be present simultaneously (hugo binary, theme repository, deployment git repository). Any missing one leads to failure at different stages; these prerequisites should be clearly listed in the project documentation.

Practical Learnings#

  • In bash set -e scripts, find operations on optional directories must include a directory existence check; otherwise, normal “directory not created” scenarios can trigger unexpected script termination.
  • The code for parallel background task PID tracking must align precisely with the if/else control flow. Placing common code outside branches can introduce duplicate PID tracking and silent file replacement bugs.
