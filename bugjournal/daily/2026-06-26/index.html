Problems & Solutions#

Critical Issues#

1. Extreme ARI discrepancy (worst ~0.01 vs best ~0.56) in clustering metrics due to inclusion of invalid configurations (k!=GT).#

Solution: Filtered sweep results to only include ‘hit_k=True’ configurations, correcting the statistical range and stabilizing variance metrics.

Key Insight: Strict adherence to hyperparameter constraints (like k=GT) is essential for valid statistical ranges in clustering evaluation; including invalid states artificially widens variance.

2. mclust ARI scores significantly lower than expected due to inadvertent PCA-50 application on low-dim embeddings.#

Solution: Corrected load_emb to default pca_dim=None, restoring true signal and showing mclust performance is comparable to Leiden when inputs are fair.

Key Insight: Implicit dimensionality reduction in helper functions can cause silent ARI degradation; input dimensions must strictly match the canonical pipeline.

3. Cosmos3-Nano grounding coordinates misaligned in rendered overlays due to image size mismatch (model expects 608x480, video provided 256x256).#

Solution: Identified the scale mismatch as the root cause; recommended coordinate normalization or input upscaling for future validations.

Key Insight: Multimodal models may hallucinate image dimensions if not explicitly provided; reliance on model-reported sizes without validation leads to rendering errors.

General Issues#

4. Automated git hooks committed generated encrypted HTML files, polluting repository history.#

Solution: Removed tracked files with git rm --cached, updated .gitignore, and amended commits to maintain a clean history.

Key Insight: Generated assets must be explicitly ignored in git to prevent bloat and accidental exposure of temporary configurations.

5. SSH login fails despite correct config; local public key not registered on remote server.#

Solution: Identified missing remote public key as the cause; task blocked pending admin intervention.

Key Insight: When key-based auth fails, verify the existence of the corresponding public key on the server side before altering local identities.

Learnings#

Key Learnings#

  • When aggregating clustering metrics, always filter out configurations failing structural constraints (k=GT) before calculating worst-case scenarios to prevent artificial variance inflation.
  • Cosmos3-Nano supports structured 2D/3D point localization but lacks pixel-perfect spatial precision at low resolutions without explicit image size context or upscaling.
  • When designing migration tools for heterogeneous codebases, defaulting to ‘dry-run’ outputting move manifests is critical as import rewriting across ecosystems is error-prone.

Practical Learnings#

  • StatiCrypt provides robust client-side AES-256 encryption for static sites on GitHub Pages, ensuring zero secret exposure while allowing public access.
  • Dynamic visual instructions for robotics require temporal context; static single-frame analysis is insufficient for trajectory generation validity.
