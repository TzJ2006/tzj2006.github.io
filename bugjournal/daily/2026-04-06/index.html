Problems & Solutions#

Critical Issues#

1. HD immune analysis revealed extremely sparse T cell marker expression (1278/17502 spots, mean 0.014), and TLS markers are even sparser (242 spots). The original argument that “multimodal outperforms single-modal capture of immune infiltration” does not hold.#

Solution: The narrative in R6 P3 was changed from “multimodal identification of immune infiltration boundaries” to “clustering–retrieval trade-off”: 96% of STAIG retrieval results are concentrated in the epithelium (excessive homogeneity), PCA gene expression is 3.8x more effective at capturing T cells than STAIG, and Attention fusion performs most evenly at the boundary (60/40 Epi/CT).

Key Insight: The optimal clustering strategy using frozen FM embedding (spatial contrast learning) differs from the optimal retrieval strategy (attention fusion), making this a more meaningful discovery than expected.

General Issues#

2. benchmark_rm_ideal.py writes results to the same summary.csv by default, so the results of each new pair overwrite those of the previous pair.#

Solution: A backup is created immediately with cp after each pair experiment (summary_151673_151674.csv, etc.). The result for 151673↔151669 was manually reconstructed using heredoc (overwritten by 151674 results).

Key Insight: Long-running batch experiments require per-pair output directories to be designed at the script level or aggregated after the pipeline completes.

3. conda activate produces no output in the background command, and the output files of three experiment processes (bgqoqyepm, etc.) are always 0 bytes.#

Solution: conda run -n General python ... was used instead of conda activate General && python ... to ensure proper background output writing.

Key Insight: The background bash environment for Claude Code does not inherit the shell’s activate state, and conda run must be used to ensure environment isolation.

4. The same experiment was started twice with two different processes (conda activate version + conda run version), wasting resources with 6 benchmark processes running simultaneously.#

Solution: The PID of the conda run process was found using ps aux, and the duplicate 3 processes were killed to keep the original conda activate version.

Key Insight: When background processes output nothing, it is necessary to confirm whether the process is actually running (ps aux) before re-submitting.

5. The query points (red stars) in the HD Niche Query visualization are hard to see visually and cannot be used for paper presentation.#

Solution: The script was fixed: the star markers were increased from markersize=20 to 26, a white outer ring of size=32 was added, all 4 panels were marked, and an arrow plus text label was added for the first panel.

Key Insight: Query spots in paper figures require multiple visual cues (color, size, outer ring, label), and a single red star is completely hidden against the heatmap background.

Learnings#

Key Learnings#

  • A fork exists between the optimal fusion strategies for clustering and retrieval: STAIG spatial contrast learning is most suitable for global domain clustering (Avg ARI 0.546), but its strong spatial homogeneity leads to excessive focus on the same domain during retrieval at the boundary (96% Epithelium), while Attention fusion (60/40 distribution) is more balanced for boundary microenvironment retrieval—this is a new core argument in R6.
  • Results of three new RM-IDEAL experiments: Layer 3 of the same donor cross-slice (151673↔151674) has a high Spearman ρ of 0.86, and same-label@50 reaches 100% for the same donor (151508↔151509); Layer 3 of cross-donor (151673↔151669) shows a negative correlation (ρ=-0.73), indicating systematic differences in the morphological structure of Layer 3 between different donors.
  • In HD colon cancer data, T cell markers (CD3D/CD3E, etc.) are extremely sparse (7.3% expressed), and the ability of PCA gene expression to detect T cell enrichment (3.8x) is higher than visual + gene fusion (STAIG 2.2x), indicating that T cell signaling is mainly driven by gene expression rather than tissue morphology.
  • Strategy at the beginning of Introduction: Directly presenting key numerical findings (ARI from 0.26 to 0.55) is more persuasive than general background introduction; corresponding Results section titles for each paragraph enhance structural consistency.
