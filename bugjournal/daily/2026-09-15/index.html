Solution: Implemented a custom cleanup() function in the shell trap using ‘fuser -k’ on the specific TCP port to reclaim memory.

2. Machine freezes and OOM errors during concurrent test execution and backbone quantization.#

Solution: Identified optimal worker counts via halving-search and implemented a Bash-based retry driver that monitors VRAM thresholds (35-42GB).

3. Complex semantic conflicts during collaborator repo merge regarding quantization logic.#

Solution: Prioritized the collaborator’s float-preservation approach for softmax/rotations to ensure precision integrity.

4. CUDA indexing was inconsistent with nvidia-smi, leading to incorrect GPU pinning.#

Solution: Exported CUDA_DEVICE_ORDER=PCI_BUS_ID in common.sh to force alignment with physical bus IDs.

5. Guardrail system blocked legitimate Read tools due to substring matching and prevented file writes via ‘unclaimed’ idea nodes.#

Solution: Identified need to distinguish MCP tools from native tools and used ‘companion new’ to claim specific idea nodes for file access.

6. Automated file uploading and clipboard access on Overleaf were blocked or unresponsive.#

Solution: Switched to a robust clipboard-based approach (pasting image data) and requested explicit user authorization for private source code.
