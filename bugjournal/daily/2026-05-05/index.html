    Key Issues#

    1. NVIDIA RTX 5090 generated 1010 WHEA PCIe AER Unsupported Request errors in 5 months, causing intermittent blue screens. The errors occur during idle periods and startup, not during GPU stress tests.#

    Solution: Identified that the root cause is the PCIe link state power management of the NVIDIA driver (downgrade from Gen5 to Gen1 during idle). During renegotiation, the GPU sends memory-mapped I/O requests before address space fully recovers, triggering UR. Fixed by setting NVIDIA control panel → Power mode → priority use of highest performance mode. Verification: no new errors occurred during operation after a 19-minute restart, only 2 startup errors (hardware initialization, unavoidable). Also resolved the 5-second HDMI audio latency issue (same reason: audio controller D3cold sleep).

    Key insight: Windows ASPM Off settings only affect the OS-level PCIe power policy; NVIDIA drivers and BIOS can still independently switch link states. The description “correcting errors” hides the severity—cumulative UR errors eventually damage driver status and trigger kernel error checks. Community research confirms this is a compatible issue for RTX 5090 + PCIe Gen5 across multiple motherboard manufacturers.

    2. Upstream maintainers are concerned that statusline rewriting and OAuth/Keychain removal may cause architectural conflicts affecting Codex/Cursor rate limiting.#

    Solution: Recorded that these conflicts have been resolved via merge commits f6e0982 and 4492d2f; Codex uses CLI scraping (not OAuth), and Cursor does not require a keystore prompt.

    Key insight: Incremental merge strategies with clear feature restoration merges can maintain downstream innovation while adopting upstream architectural changes.

    3. Codex point balances are displayed in USD ($2,116.02), causing user confusion.#

    Solution: Replaced formatUsdAmount() in UsageBars.svelte with Math.round().toLocaleString() + “credits” suffix, confirming the fix does not affect Cursor’s extra_usage, which correctly uses USD.

    Key insight: Multi-vendor systems require unit handling per vendor—Codex uses “points”, Cursor uses USD; it cannot be assumed all vendors use the same monetary format.

    4. The Rust test oauth_token_prefers_credentials_file_on_macos failed in CI, indicating “Claude credentials file unavailable (/var/folders/…/tmp/.claude/.credentials.json)”. The test wrote the file to tmp/.credentials.json, but the lookup path points to tmp/.claude/.credentials.json, indicating no use of the CLAUDE_CONFIG_DIR environment variable.#

    Solution: The root cause is that rate_limits/claude.rs and statusline/install.rs tests use different mutex locks (ENV_LOCK and env_lock()) to protect CLAUDE_CONFIG_DIR operations. Parallel test execution caused statusline tests to overwrite the environment variable values of Claude tests. Fixed by modifying tests to directly call read_token_from_credentials_file(), no longer relying on environment variable parsing and macOS keystore fallback complexity. Also fixed unused import ‘Local’ (reimported separately for test module) and dead code warnings in Claude_settings_file (changed #[cfg_attr(not(test), allow(dead_code))] to #[allow(dead_code)]).

    Key insight: Unsafe environment variable operations in parallel tests require a single global lock shared by all test modules—local module-level locks create false security. #[cfg(test)] imports may confuse rustc when reimporting the same item after using super::* in test submodules. cargo fmt requires #[cfg(test)] imports to be sorted after regular imports.

    Lessons Learned#

    Key Experiences#

    • “Unsupported request” in PCIe advanced error reports may be caused by NVIDIA drivers automatically managing PCIe Gen5↔Gen1 link state power management during idle periods. Windows powercfg ASPM settings (link state power management) only control operating system-level policies; GPU driver firmware and BIOS independently manage PCIe L-states. Known compatibility issues exist for RTX 5090 + PCIe Gen5, where UR errors occur when the GPU attempts to access memory-mapped address space during renegotiation. Community-verified fix: forcing “prioritize maximum performance” or locking the BIOS PCIe Gen4.
    • Multi-provider rate limiting systems require careful handling of unit conversion for each provider — assuming a unified currency format fails when providers use different units (Codex “points” vs. Cursor USD).
    • Branch maintenance strategy: gradually merge upstream architecture changes, with clear feature restoration commits; actively log conflicts to maintain upstream relationships.
    • Rust parallel test suite involves environment variable operations, requiring all test modules to share a global mutex — local locks in each module (static ENV_lock in module A, separate env_lock() in module B) cause race conditions when modifying the same environment variable simultaneously. The #[cfg(test) attribute in imports causes a “not used” warning if test submodules use “use super::*”, due to duplicate imports of the same item. cargo fmt requires conditional imports (#[cfg(test))) to be ordered after unconditional imports.
    • A two-layer deduplication mechanism (remote Python script + local HashSet) can effectively prevent duplicate records in distributed log aggregation systems when multiple devices append to shared storage.
