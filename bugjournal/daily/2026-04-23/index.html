Lessons Learned#

Key Experiences#

  • Cross-platform ML deployment requires clear backend strategy: faster-whisper (CTranslate2) for NVIDIA CUDA, mlx-whisper for Apple Neural Engine, with CPU fallback; a factory pattern with runtime detection provides clarity.
  • Singleton pattern is essential for heavy resources like ML models; repeated model loading may be the main factor for request latency in production systems.
  • YAGNI principle applies to architecture decisions: when Discord commands can directly call services, the REST API layer is unnecessary; scalability should be based on specific use cases, not assumptions.
  • Sub-proxy-driven development enables clear task isolation and parallel execution; 5 tasks completed in one session with independent submission and test validation.
  • Event-driven architecture (with EventBus and IDEA_CLUSTER_DETECTED) enables loose coupling of passive suggestion functionality; DreamingService can trigger idea optimization without relying on IdeaStore.
