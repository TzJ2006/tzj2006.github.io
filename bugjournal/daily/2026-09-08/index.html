Learnings#

Key Learnings#

  • In unordered sets (like game tiles), symmetric aggregation (Deep Sets) is significantly superior to one-hot encoding as it removes arbitrary ID dependency.
  • In high-resolution spatial tasks (Visium HD), the zero-shot advantages of foundation models observed in small crops tend to diminish when scaled to full-slide tiling.
  • Cross-section niche retrieval requires consistent coordinate meanings across slices to avoid spurious results.
  • Behavior Cloning (BC) is a powerful pre-training tool but can create ’exploration dead-ends’ if the policy becomes too peaked; temperature smoothing or entropy adjustment is essential.
  • Feature engineering quality (removing ID dependence, adding action-effect states) is a more effective lever for discrete planning problems than simply increasing model parameter count.
