Problems & Solutions#

Critical Issues#

1. MIHD cross-slice retrieval is almost completely failed (10 out of 14 query directions have SL@50=0)#

Solution: Diagnosis confirmed that PCA/STAIG process each slice independently, resulting in an uncomparable embedding space; the solution is to directly use scGPT embedding (shared space, average SL@50=0.416, 100% hit rate).

Key Insight: The comparability of the embedding space (whether a common coordinate system exists) is more fundamental than the quality of the embeddings; cross-slice tasks and single-slice clustering should use different encoders.

2. MIHD single-slice ARI lags behind SOTA (current 0.546 vs target 0.60+)#

Solution: A 4-phase ablation experiment plan was formulated (clustering ablation→batch effect analysis→retrieval probe→151676 special diagnosis), but not all have been executed yet.

Key Insight: Zero variance in 151676 embeddings caused mclust to fail and back to KMeans, which lowers the mean—the root cause remains unknown.

General Issues#

3. No ~/.config/gadget/sync.json on DCC, preventing sync.py execution#

Solution: AI read the existing summarize config to obtain rclone_remote configuration, manually created sync.json and verified the remote directory structure before executing pull.

Key Insight: Configuration files are not automatically migrated during new device initialization; they must be inferred from existing configs and rebuilt.

4. When using cp -r to copy cchelper directories, files are scattered instead of preserving subdirectory structures#

Solution: After identifying the issue, use mkdir -p ~/.claude/skills/cchelper to create subdirectories, then move the scattered files in.

Key Insight: cp -r directly expands the source directory content when the target exists—confirm the target path first.

Learnings#

Key Learnings#

  • In spatial transcriptome cross-slice tasks, the comparability of the embedding space (shared coordinate system) is more critical than the local quality of embeddings; Foundation Model (scGPT) is naturally suited for cross-slice retrieval due to its fixed output representation space, while PCA/STAIG independent processing leads to non-comparable coordinate systems.
  • The optimal method for single-slice clustering (STAIG) differs from that for cross-slice retrieval (scGPT); different encoders should be used based on task objectives, rather than pursuing a unified optimal solution.

Practical Learnings#

  • The scavenger-h200 partition in the DCC cluster provides H200×8 nodes (though抢占式), making it important for training tasks requiring large memory; the TRES limit of cpu=100/mem=500G is a hard constraint when submitting large assignments.
