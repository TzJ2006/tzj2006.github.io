Problems & Solutions#

1. Discrepancy between RecoverBench paper claims and actual training data used. [RecoverBench]#

Solution: Conducted a systematic agentic audit to map claims to actual files on the cluster; implemented a ‘Claims/Evidence’ ledger.

2. ResNet shortcut implementation used projection convolutions instead of identity requirement. [ECE661/ResNet]#

Solution: Refactored the ResNet class to implement Option A (identity shortcut) and re-trained the model.

3. OmniJev M2 execution was extremely slow due to Conv3d patch embedding bottleneck. [OmniJev]#

Solution: Replaced the slow torch implementation with an equivalent linear layer, reducing latency from 16s to 0.06ms per image.

4. W4A4 quantization led to severe performance degradation (0% success rate). [Quantization/VLA]#

Solution: Identified backbone activation as the error source and recommended moving to W8A8 to avoid non-functional quantization graphs.

5. SQLite WAL merge causing database corruption and ‘quick_check’ failures. [WeAgent]#

Solution: Replaced manual merging logic with a ‘SQLite Replay’ approach using the official engine to play back decrypted WAL files.

6. Inflated robot policy evaluation success rates due to hidden proprioceptive data usage. [OmniJev]#

Solution: Implemented DRAWN_MEMORY_VISUAL_ONLY/TRACK flags to force zero proprioception, correcting success rate to 65.0%.

Learnings#

Architecture (architecture)#

  • In multimodal agents, decomposing memory tasks—using code for temporal/sequence logic and VLM for perception—is superior to using the VLM for all reasoning.
  • For research-focused identity (CVs/PhD), a strategic narrative prioritizing problem-definition and research intuition is more effective than high-volume technical listing.

Debugging (debugging)#

  • GPU kernel autotuning (e.g., Triton GEMM/XLA) can introduce non-determinism that mimics code regressions; requires forced deterministic autotuning for benchmarks.

Domain Knowledge (domain)#

  • 4-bit simulations can be overly pessimistic and unreliable for predicting hardware accuracy due to hardware automatically utilizing FP16 for certain operations.
  • Reliable robot learning must distinguish between ‘arbitrary starting state’ and ‘state following an execution error’ to measure true error recovery.

Tools (tools)#

  • When dealing with complex database internals like SQLite WAL, it is safer to use the official engine to replay decrypted files than to implement custom manual merging.
