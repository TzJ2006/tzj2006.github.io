Problems & Solutions#

1. MIHD STAIG fusion results were byte-identical (silent failure) because raw HVG matrices bypassed gene encoder layers. [MIHD Research] (2026-06-02)#

Solution: Confirmed integrity loss via md5sums; modified pipeline_config.yaml to enforce encoder path; archived corrupted outputs and reran SLURM jobs with correct paths.

2. TokenMonitor auto-update failed with signing errors due to conflating minisign updater keys with Apple Developer ID requirements. [TokenMonitor] (2026-06-02)#

Solution: Generated new Tauri keypairs, corrected base64 secrets in CI, and decoupled minisign updater logic from Apple code-signing flags.

3. AI Companion workflows broke portability due to absolute path injection; parallel AI agents hit API rate limits (429). [AI Dev Companion] (2026-06-04)#

Solution: Designed Vendor-Tier-1 architecture to vendor relative paths and externalize heavy engines; switched fan-out to throttled sequential background workflow.

4. RecoverBench documentation listed cherry-picked metrics (48.6%) inconsistent with reproducible single-checkpoint results (45.7%). [RecoverBench] (2026-06-06)#

Solution: Mapped all sources across environments; created consolidated discrepancy report; aligned future reporting with actual baseline artifacts rather than idealized paper figures.

5. Git fork cleanup broke upstream synchronization due to broad history rewriting. [TokenMonitor] (2026-06-03)#

Solution: Identified specific offending commits and used targeted tip amending to preserve ancestor integrity while reclaiming ~302MB of artifacts.

Learnings#

Architecture (architecture)#

  • Root tsconfigs in monorepos should use pure references to prevent cascading ESM/CommonJS module conflicts. Automated pre-edit gates must anchor to immutable external signals (git history) rather than internal flags to prevent self-authorization risks.
  • Tauri updater signing (minisign) and code-signing are independent systems; conflating them breaks cross-platform release consistency. Production CLIs require vendorized relative paths or npx-style resolution for true environment portability.

Debugging (debugging)#

  • LLM wrappers often mask timeouts as JSON parse errors; payload size/concurrency dictates latency more than network speed. Identical inputs to downstream models can silently mask upstream data corruption, making empirical binary verification essential.
  • Orphan Vite dev server processes and improper shutdowns cause phantom white-screen blocks; cross-platform port locks must be synchronous and independent of the app event loop to prevent duplicate instance conflicts.

Tools (tools)#

  • Large-scale parallel LLM analysis quickly triggers rate limits; throttled sequential batching with human ground truth yields higher reliability. Git fork cleanup should prioritize selective tip amending over broad filtering tools to maintain upstream sync.

Domain Knowledge (domain)#

  • Scientific model equivalence must be validated via metric divergence (ARI/NMI) rather than bit-identical reproducibility due to RNG variance. Uncommitted HPC work is ephemeral; local trees require frequent commits or snapshot backups to prevent irreversible data loss.
