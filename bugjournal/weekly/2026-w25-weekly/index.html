Problems & Solutions#

1. Local HPC usage statistics showed no data for March/April; macOS DMG creation scripts failed repeatedly with ‘Resource busy’ errors due to Finder/QuickLook locking. [Desktop Video Wallpaper / HPC Tooling] (2026-06-15)#

Solution: For HPC, inspected metadata and found auto-deletion/frozen caches, concluding external API queries are needed. For macOS, used diskutil unmountDisk force, killed background services, and applied unique volume names to bypass locks.

2. TokenMonitor single-instance startup failure when lock port occupied by un-terminatable processes; duplicate device entries due to volatile slug metadata. [TokenMonitor / Sync Infrastructure] (2026-06-17)#

Solution: Implemented a Windows named mutex (Local\TokenMonitor-SingleInstance) as a robust fallback alongside TCP checks. Created deviceIdentityKey normalization helper stripping suffixes/hashes for deduplication.

3. Desktop Video app displayed two windows on startup and had CPU spikes during wallpaper navigation; mixing SwiftUI WindowScene and manual NSWindow management causes race conditions. [Desktop Video Wallpaper] (2026-06-18)#

Solution: Resolved double-window issue by removing WindowGroup and relying solely on AppDelegate. Fixed performance by limiting thumbnail instantiation to visible tiles and adding cache reuse.

4. Zero success rate in RoboCasa Error Recovery Benchmark despite adequate file counts; initial assumption of weak policy was incorrect. [RoboCasa / ErrorRecoveryBenchmark] (2026-06-19)#

Solution: Diagnosed root cause as incomplete training (5000/10000 steps) and unverified augmented data. Shifted strategy to regeneration, proving 0% rates indicate infrastructure/data bugs rather than model weakness.

5. Leiden clustering initially appeared inferior to mclust by ~8 ARI points due to default hyperparameters; silent pipeline failures from missing rclone binary/config paths. [MIHD / Spatial Transcriptomics / Sync Infrastructure] (2026-06-21)#

Solution: Conducted joint grid searches over n_neighbors, metric, and resolution to find optimal levers. Downloaded static rclone v1.74.3 binaries and updated config for reliable cross-drive sync.

Learnings#

Architecture (architecture)#

  • SwiftUI WindowGroup and manual AppDelegate window creation interfere silently; strictly adopt one management style per app for predictable lifecycle behavior.
  • For single-instance enforcement on Windows, combining TCP IPC with a named mutex provides robust redundancy against occupied or protected ports where taskkill fails.
  • When auditing scientific outputs where metadata is unreliable, direct content hashing (e.g., MD5) against known baselines is the only trustable verification method for provenance.

Debugging (debugging)#

  • Rolling time windows require dynamic cache keys with a time-bucket component; static keys permanently freeze temporal data and cause stale UI states.
  • On Windows with NVIDIA WDDM drivers, memory exhaustion is often masked by system fallback rather than throwing traditional OOMs; always enforce hard VRAM limits and token-budgeting instead of relying on exception catching.
  • Uniform 0% failure rates in benchmarks typically indicate pipeline, loading, or normalization infrastructure issues. Verify environment integrity before assuming model weakness.

Tools (tools)#

  • macOS automation for disk images requires unique volume names and explicit resource release (diskutil unmountDisk) to overcome aggressive OS-level file locking.
  • Headless HPC environments mandate explicit backend configuration (e.g., MUJOCO_GL=egl) to prevent silent GLFW/rendering failures in simulation workflows.
  • Automated GitHub CLI pushes frequently fail due to local token mismatches; scaffolds must anticipate auth limitations and fall back to generating code/text or using alternative connectors.

Domain Knowledge (domain)#

  • In spatial transcriptomics clustering, n_neighbors is the most critical hyperparameter for Leiden, often outweighing resolution or seed; optimal values are highly section-dependent.
  • True Original STAIG scores (~0.54 ARI) diverge significantly from published figures (~0.70 ARI), indicating unshared optimizations or environment-specific training runs in original papers.
  • NVIDIA’s RoboCasa ecosystem explicitly splits Predict 2.5 Policy (benchmark baseline) from Cosmos 3 (general world model). Always verify exact policy checkpoints for compatibility before deployment.
