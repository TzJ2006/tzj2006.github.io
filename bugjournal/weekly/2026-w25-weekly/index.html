Issues and Solutions#

1. Desktop Video application shows duplicate windows at startup, causing high CPU delay during background wallpaper navigation. [Desktop Video] (2026-06-19)#

Solution: Remove the conflicting WindowGroup from SwiftUI Scenes, centrally manage window lifecycle in AppDelegate, limit thumbnail instantiation to visible tiles and allow cache reuse.

2. TokenMonitor fails single-instance startup when the lock port is occupied by an unterminable background process. [TokenMonitor] (2026-06-17)#

Solution: Introduce Windows named mutex Local\TokenMonitor-SingleInstance as a reliable fallback mechanism, combined with existing TCP port check, to eliminate access denial contention.

3. Error recovery benchmark shows coffee task success rate is 0%, despite large file count; initially diagnosed as model capacity issue. [RoboCasa & Robotics Evaluation] (2026-06-19)#

Solution: Implement token budget-based VRAM allocation mechanism, start parallel regeneration process. Solution: Deep diagnosis shows half-trained checkpoints (5000/10000 steps) and unverified enhancement data. Switch to block-based parallel regeneration process.

4. Initial score of Leiden clustering algorithm is about 8 ARI points lower than mclust baseline due to default hyperparameters and evaluation bias. [MIHD Space Transcriptomics] (2026-06-19)#

Solution: Conduct joint grid search on n_neighbors, metrics, and resolution. n_neighbors is the main influencing factor; optimizing this factor makes Leiden performance equal to or exceed the baseline, while fixing k=7 reveals selection bias in real dataset comparison.

5. Silent daily export failure on HPC and Recovery model checkpoint mismatch stem from incorrect normalized statistical information loading. [Infrastructure & HPC Tools] (2026-06-21)#

Solution: Download static rclone binary to fix silent configuration issues; resolve statistical information mismatch by setting PI05_POLICY_DATASET_SUFFIX=merged_recovery_v2 environment variable, ensuring checkpoint consistency.

6. Original STAIG baseline in analysis was incorrectly labeled as BYOL, but actually used UNI2 embeddings, making ablation experiments invalid. [MIHD Space Transcriptomics] (2026-06-19)#

Solution: Review source path to locate true BYOL embeddings, re-evaluate with correct sources, and update charts to reflect the corrected approximately 0.54 ARI score, instead of the misleading approximately 0.70 score.

Lessons Learned#

Architecture#

  • There is conflict between SwiftUI WindowGroup and manually created AppDelegate windows, but architecture cleanup (choosing one management method) is more effective than state patch fixes in preventing race conditions. Glass effects create independent rendering contexts, requiring careful control of z-order via standard background extensions.
  • Strong single-instance enforcement cannot rely solely on TCP ports, as these ports are vulnerable to old/protected processes. Combining operating system-level named mutexes and traditional IPC provides necessary redundancy. Strict CLAUDE.md documentation is required for cross-device context switching to maintain architecture consistency between sessions.

Debugging#

  • Near-zero benchmark success rate in uniform environments almost always indicates process/infrastructure failures (e.g., incomplete training, normalization statistical errors) rather than model weaknesses. Always verify data source and environment configuration before retraining. Static backend cache keys permanently freeze time scrolling windows; time bucket dynamic keys are crucial for accuracy.
  • Windows NVIDIA drivers silently fallback to shared system RAM to hide OOM exceptions, causing severe unexplained delays. Strict token budget batching and torch.cuda.set_per_process_memory_fraction limits are needed to ensure stable VRAM allocation. ECL workflow planning output usually lacks executable architecture; manual verification/insertion of hooks is necessary to prevent downstream execution blocking.

Tools#

  • Headless HPC environment requires clear MUJOCO_GL=egl export during Slurm batch jobs and careful removal of interactive prompts in dependency installers. macOS automation often encounters aggressive Finder/QuickLook file locking, requiring diskutil unmountDisk force, unique volume names, and background service termination.

Domain Knowledge#

  • Gene base model (scGPT/TEDDY) performs better than standard encoders in cross-sample niche retrieval in space transcriptomics. The actual STAIG metric (approximately 0.54 ARI) is significantly lower than the released values (approximately 0.70), indicating lack of shared optimization and untrustworthy metadata tags; direct hashing of embeddings is the only reliable verification method.
