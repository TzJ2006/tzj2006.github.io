Problems & Solutions#

1. /doctor tool incorrectly reported invalid JSON for settings.json; actual cause was a schema violation in the SessionStart hook, not file corruption. [AI Dev Companion] (2026-05-25)#

Solution: Validated raw UTF-8 structure via Node.js parsers and identified the wildcard matcher mismatch as the root cause rather than a syntax error.

2. ECL verification mechanisms relied on trivial file existence checks (test -f), providing zero functional assurance for 12 critical features. [LifeCopilot] (2026-05-26)#

Solution: Replaced all placeholder checks with targeted pytest commands that execute actual code paths, restoring accurate feature validation.

3. Main Cost Display in TokenMonitor showed stale or missing data because disk cache was invalidated inconsistently during SSH sync loops. [TokenMonitor] (2026-05-28)#

Solution: Implemented synchronized clear_prefix calls for both memory and persistent disk caches, ensuring payload recalculation on every sync.

4. Windows CMD/PowerShell environment inconsistencies caused garbled text in startup scripts and silent stdio deadlocks when spawning child MCP processes. [LifeCopilot] (2026-05-27)#

Solution: Applied explicit UTF-8 BOMs, corrected CRLF formatting, sourced conda hooks directly, and enforced shell=False for subprocess isolation.

5. Migration to Claude Platform on AWS failed due to lingering CLAUDE_CODE_USE_BEDROCK=1 in shell profiles overriding JSON configurations. [AWS Billing & Provider Migration] (2026-05-31)#

Solution: Inspected active environment variables via CLI, removed the Bedrock override, injected the correct platform flag, and enforced clean session restarts.

6. Git .gitignore directory-level wildcards (website/static/pdfs/*) were masking file-level negation patterns required for resume uploads. [Portfolio Management] (2026-05-31)#

Solution: Refined .gitignore to use explicit wildcard matching on folder contents, allowing precise !resume.pdf whitelisting to bypass recursive rules.

Learnings#

Architecture (architecture)#

  • Strict separation of immutable planning outputs (ECL) and mutable execution logic is essential for deterministic agent workflows; hooks must enforce these boundaries to prevent coupling.
  • Configuration management across monorepos and cross-device setups requires a single executable source of truth (e.g., launcher.py or registry scripts) rather than distributed shell wrappers to eliminate drift.

Debugging (debugging)#

  • Testing quality is dictated by assertion strength (verifying specific business rules and state transitions) rather than raw coverage metrics; weak negative assertions routinely mask logical regressions.
  • Empirical isolation testing trumps hypothesis-driven debugging. On Windows, shell=True in subprocess calls silently deadlocks when child processes inherit pipe handles; direct variable testing is required to identify the vector.

Tools (tools)#

  • Desktop frameworks like Tauri maintain independent disk caches separate from in-memory stores. State changes must trigger dual-layer invalidation (memory + disk) to prevent stale visual data leaks during remote syncs.
  • Linting and doctor utilities often conflate parse failures with semantic/schema issues. Direct byte-level or AST-based validation must precede configuration troubleshooting to avoid chasing phantom syntax errors.

Domain Knowledge (domain)#

  • AWS Activate credits strictly exclude Marketplace SKUs unless explicitly enumerated as third-party Bedrock models. Scaling cloud API usage requires manual verification of credit terms and quota entitlements to prevent unexpected charges.

AI Usage Notes#

Effective Patterns:

  • ✓ Using explicit environment variable inspection before JSON migration to bypass persistent shell profile overrides
  • ✓ Applying tmp_path fixtures and strict session IDs for test isolation in stateful desktop applications
  • ✓ Prioritizing semantic and structural fidelity over visual recreation when programmatically generating complex documents

  • ✗ Initial failure to auto-detect culturally specific name discrepancies in PDF-to-DOCX conversion without direct user prompts
  • ✗ Delayed diagnosis of Windows shell encoding conflicts requiring extensive manual cross-referencing rather than automated detection
  • ✗ Over-reliance on string matching during early ECL YAML schema migrations, causing delayed hook compatibility fixes
