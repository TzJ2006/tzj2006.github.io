Problems & Solutions#

1. Background daemon spawning (‘collect-report-data.ts’) caused severe CPU thrashing and silent background overconsumption. [AI Companion Framework] (2026-06-24)#

Solution: Implemented file-lock singleton guard to prevent duplicate executions; traced process trees via CLI to isolate and terminate the root cause.

2. AI reported completing non-existent features based on context compression artifacts rather than actual filesystem state. [AI Companion Framework] (2026-06-25)#

Solution: Enforced direct CLI verification (‘git log’, ’ls’) to ground AI outputs in reality; reset operational context and established trust through audit trails.

3. Frozen VLM (Cosmos-Reason1) failed zero-shot spatial grounding, outputting static coordinates regardless of input text. [Robotics & Cosmos3-Nano Evaluation] (2026-06-27)#

Solution: Abandoned direct generation; pivoted to candidate-selection architecture and optimized inference parameters (normalized prompts, upsampled inputs, temperature=0).

4. GeneJEPA embeddings exhibited high anisotropy and library-size bias, underperforming PCA in spatial clustering. [MIHD Spatial Transcriptomics Analysis] (2026-06-23)#

Solution: Ran SVD/correlation diagnostics; concluded JEPA path was unfeasible for small-sample domains, reinforcing PCA and engineered baselines as superior for this regime.

5. Remote Cosmos3-Nano model weights were truncated, causing silent vLLM startup failures and stale evaluation data. [Robotics & Cosmos3-Nano Evaluation] (2026-06-24)#

Solution: Used Safetensors headers to identify corrupted shards; fetched replacements via cross-device sync and verified integrity before redeployment.

Learnings#

Architecture (architecture)#

  • Client-side encryption on static hosting combined with ’noindex’ directives offers a pragmatic security model for private tools without infrastructure fragmentation.
  • Monorepo background automation must enforce singleton locking or rate-limiting to prevent silent resource exhaustion from burst events or manual retries.

Debugging (debugging)#

  • Git merge titles are unreliable indicators of content inclusion; tree-level verification is required. Additionally, relying on AI summaries without external ground-truth checks introduces severe state divergence risks.
  • Remote model files can degrade silently; always verify file integrity (headers/sizes) before serving weights. Stale process tracking via network tools is mandatory before relaunching services to avoid port conflicts.

Tools (tools)#

  • Use non-interactive flags for automated testing pipelines to prevent process hanging. Numerical comparison logic is required for semantic versioning, and environment variables like PROXY_BYPASS must be set programmatically at startup.

Domain Knowledge (domain)#

  • Foundation models pretrained on cellular data often fail to transfer to spatial transcriptomics due to domain shift. Generic reasoning VLMs lack zero-shot robotics transfer capabilities, requiring fine-tuning or candidate-selection strategies.

AI Usage Notes#

Effective Patterns:

  • ✓ Multi-agent parallel auditing effectively isolates logical bugs across large codebases and accelerates remediation
  • ✓ Context compression artifacts are reliably mitigated by forcing direct system command verification before trusting task summaries
  • ✓ Parameterized inference (normalization, temperature control) successfully transforms unusable VLM outputs into viable evaluation tools

Limitations:

  • ✗ AI consistently underestimates the need for explicit state grounding, leading to phantom task hallucinations when context windows compress
  • ✗ Remote execution tooling struggles with SSH pattern matching and intermittent proxy tunnels, requiring iterative human intervention to stabilize
  • ✗ Automated script generation occasionally introduces subtle string formatting bugs (e.g., symlink paths) that bypass validation logic
