Problems and Solutions#

1. GTK bottom-up size negotiation causes FloatBall window to always be 400x400, Tauri set_size() is completely ineffective [TokenMonitor] (2026-04-04)#

Solution: Use the with_webview() callback to call widget.set_size_request() in the GTK main thread, breaking theWebKitGTK natural size constraint. Remove the set_resizable switch (with_webview is asynchronous, subsequent API calls will be queued before the callback execution, locking the old size). Keep resizable enabled permanently on Linux

2. Dynamic resize of Linux transparent borderless window causes systematic WM +305px/+113px position offset, probe/corrective mechanisms cause visible flickering, size inconsistency between WebView and native window [TokenMonitor] (2026-04-05)#

Solution: Architectural refactoring to a fixed expanded size window + GDK input_shape_combine_region: Only the ball area (56×56) accepts events when collapsed; the whole window accepts events during expansion and dragging. Completely eliminates resize operations. Remove 150 lines of patch code

3. On Linux/Wayland, Tauri main window set_position() is completely ignored by the compositor, causing the window to appear in the center of the screen [TokenMonitor] (2026-04-02)#

Solution: Detect WAYLAND_DISPLAY at the run() entry point and force GDK_BACKEND=x11, enabling the application to run via XWayland, bypassing the fundamental limitation of the Wayland protocol prohibiting client absolute position settings

4. In ssh_remote.rs, assert!() panics the entire program when path validation fails, provider parameters not validated allow path traversal attacks [TokenMonitor] (2026-04-02)#

Solution: Change the function signature to Result<PathBuf, String>, using? for error propagation;Add a whitelist function validate_provider() (only allowing ‘claude’ and ‘codex’).

5. sync_ssh_host blocks all readers when holding a RwLock read lock during an SSH I/O await point that lasts several seconds [TokenMonitor] (2026-04-02)#

Solution: Add #[derive(Clone)] to SshCacheManager to clone the manager before await and release the lock in advance.

6. The three-layer architecture of Life-Copilot MCP services is broken simultaneously: FastMCP does not call run(), mcp_servers.json is missing, and Butler commands are never passed to the Claude CLI child process [Life-Copilot] (2026-04-04)Solutions: Create main.py to start the stdio transport; create.claude/mcp_servers.json; ClaudeAdapter adds –append-system-prompt parameter; simultaneously create convention files (AGENTS.md/GEMINI.md) for Codex/Gemini, and all 19 MCP tools are restored.#

7. Discord Bot continues to reply with ‘OAuth authentication required’ when querying schedules, due to two overlapping issues: Claude -p does not load project-level MCP configurations + non-interactive mode permissions are silently denied [Life-Copilot] (2026-04-05)#

Solutions: Add –mcp-config .claude/mcp_servers.json and –permission-mode bypassPermissions in the command sequentially; the wildcard in –allowedTools is unreliable due to contention with MCP server initialization, and bypassPermissions is the correct pattern for backend service calls.

8. ClaudeCLIAdapter.is_available() lacks async and await synchronous methods cause TypeError, which is silently ignored by except Exception, resulting in Claude being silently downgraded to Codex and timeout [Life-Copilot] (2026-04-04)#

Solution: Add the async keyword, and Claude available: True returns to normal. Synchronous fix for context loss during multiple rounds of dialogue (_process_input never passes last_assistant_message and last_intent parameters).

9. The initial solution for Linux Screen Time Tracker uses xdotool, but the user’s Wayland environment (GNOME) is completely unavailable [Life-Copilot] (2026-04-04)#

Solution: Switch to GNOME Introspect D-Bus (org.gnome.Shell.Introspect.GetWindows()) as the main path, use xprop as a XWayland fallback, and use PID→cmdline as the final fallback. All subprocess calls add a 5-second timeout + proc.kill(). This issue was actively discovered by Critic subagent adversarial review.

Learning Insights#

Architecture#

  • The correct architecture for Linux transparent borderless Tauri/WebKitGTK floating windows is a fixed large-native window + internal pure CSS expansion/collapse, without relying on frequent resize of the outer window. GTK bottom-up negotiation takes max(window_requested, widget_natural_size); the with_webview() callback must call widget.set_size_request() to break theWebKitGTK natural size constraint; dimensions and positions of content areas in WM, GTK, and WebView do not sync automatically—this is platform constraint, not a bug.
  • The Wayland protocol prohibits client-controlled absolute window position at the design level; any set_position() retry strategy is ineffective. The correct solution is to detect WAYLAND_DISPLAY and force GDK_BACKEND=x11 to fallback to XWayland. X11 WM will force the undecorated window into the visible area, and the edge offset varies by platform (Linux edge_offset=0, macOS/Windows can be half-screen).
  • Aggressive simplification is often more effective than incremental fixes: the Thin Adapter+MCP Server+Skills three-layer model replaces the 3170-line proprietary routing logic, removing 2823 lines and achieving cross-CLI generality. Multi-CLI systems should use convention files (CLAUDE.md/AGENTS.md/GEMINI.md) rather than runtime injection; unifying the history ring buffer is more reliable than adapting to each CLI session mechanism.
  • The complete MCP configuration for Claude CLI -p non-interactive mode requires two steps: (1) explicitly pass –mcp-config to load project-level tools; (2) add –permission-mode bypassPermissions to bypass permission confirmation. The wildcard in –allowedTools is unreliable in this mode due to contention with MCP server initialization, and bypassPermissions is the correct pattern for backend service calls.

Debugging#

  • Runtime logs are the fundamental means of underlying system debugging: when underlying system behaviors such as GTK, WM, or OS occur, priority should be given to verification through logs/monitors (e.g., backend.log shows +305px systematic offset) rather than inference from code. After multiple failed fixes, identify the boundary where “continuing fixes cannot solve architectural issues” and stop local fixes to focus on root cause analysis.
  • “Parameters are implemented in code” does not mean “parameters are passed”: the integration layer is the most common connection break point; verify by checking the calling side rather than just the implementation side. In Python, synchronous await methods cause TypeError; if silently caught by except Exception, it leads to silent functionality downgrade instead of an error, making troubleshooting difficult.
  • When debugging nested process CLI tools (main process→Claude CLI→MCP server), record actual command-line parameters first and then isolate each parameter to verify its effect, which is more efficient than guessing parameter behavior directly. The skip_completed mechanism in the pipeline cannot detect files with invalid content (all gt_labels are -1); active verification of content validity is required.

Tools#

  • The divergent exploration of ccplan skills (multiple solutions) + Critic adversarial review + feasibility probing process can effectively transform complex platform architecture issues into executable plans. During this week’s Critic phase, high-value issues such as Wayland compatibility, lark-oapi thread blocking, ThoughtStore not being a singleton, and 4 hidden code dependencies were pre-discovered, offering high ROI and serving as key engineering practices for handling high uncertainty tasks.
  • GDK input_shape_combine_region intercepts events at the X11 layer; setPointerCapture cannot bypass it. In drag scenarios, input shape should be temporarily extended to the full window on the Rust side. GTK’s resizable(false) WM hint prevents both user dragging and programmatic set_size(), and dynamic size adjustment requires temporary unlocking.
  • assert!() and unwrap() in Rust production code are potential crash points when accepting external inputs; uniformly change to Result and use? for propagation. Lock cross-await points are common risks in asynchronous programming; the solution is to Clone the required data before await to release the lock in advance. Any user input concatenated into a file path must be validated via a whitelist (more reliable than a blacklist).
  • When wrapping stdlib logging with structlog, explicitly add ExtraAdder() processor; otherwise, the extra={} field silently disappears without error. git reset –soft is an efficient way to organize commit history, allowing any number of commits to be compressed into semantically clear commits, suitable for CI environments and automation tools.

Domain Knowledge#

  • Core MIHD experiment conclusion: High-quality embeddings are more important than clustering method selection (STAIG+mclust ARI=0.546 vs STAIG+Leiden=0.513); the STAIG fusion framework is highly robust to gene encoders (Teddy ARI=0.495 vs PCA ARI=0.497); the space graph contrast learning mechanism dominates clustering performance, and the impact of gene embedding quality is greatly diluted.
  • Foundation Models suffer from systematic transfer loss in cross-domain downstream tasks (Teddy gene-only ARI=0.186 is inferior to PCA=0.255; optimization goals do not match); HD dimension imbalance issues (concatenation of 1586d=50d PCA+1536d UNI2 is worse than single modality); data scale is a key variable (adaln is effective in DLPFC but completely fails in HD 17502 spots).
  • The narrative of multimodal fusion papers should equally emphasize negative and positive results. The paper setting should define research gaps (“no system study on zero-shot FM fusion currently exists”) rather than method performance; claiming single modality can also perform retrieval adds stronger argumentation by including this rebuttal (simple fusion is a trap→space graph learning is the bridge→correct fusion can surpass single modality).
  • NeurIPS D&B Track submission strategy: “domain correctors” (quantifying specific benchmark defects) are more accepted than “new method proposers”; reviewers value multi-dimensional evaluation, fair baseline comparisons, manual verification mechanisms (κ≥0.68), and counterintuitive negative findings. Nature Methods Analysis level requires each method to run 10 times with mean±std and 4-dimensional evaluation.
  • Modern Linux desktops (Ubuntu 22.04+) default to Wayland; cross-platform window tracking should use GNOME Introspect D-Bus as the main path, with xdotool/xprop only as XWayland fallback. Background sampling tasks should not rely on CronScheduler with a minimum tick of 60s; non-minute interval tasks require independent asyncio.Task loop.
