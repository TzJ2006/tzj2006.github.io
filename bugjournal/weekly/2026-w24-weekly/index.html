Solution: Executed intent-vs-code ledger proving Panorama is source of truth; abandoned divergent work and rebuilt evaluation pipeline to enforce SR + Bootstrap CI + Fisher exact testing.

2. Research module call_llm_raw allowed subprocess timeouts to escape, crashing the pipeline; failed LLM responses were permanently cached without TTL, causing persistent data poisoning. [Gadget Ecosystem & ccusage Migration] (2026-06-12)#

Solution: Wrapped all backend calls in uniform try/except blocks converting exceptions to RuntimeError per contract; added quality gates and TTL invalidation before cache persistence to distinguish transient failures from permanent states.

3. TokenMonitor triggered full-tree stats and expensive re-parses every 2 seconds on content-only appends due to overly broad cache invalidation; SSH/Cursor data was missing from exports. [TokenMonitor] (2026-06-13)#

Solution: Refactored parser logic to differentiate directory structure changes (full re-scan) from content appends (incremental update); added explicit remote flush and accepted source key routing for complete telemetry snapshots.

4. STAIg baseline ARI scores were non-reproducible; scGPT/TEDDY embeddings collapsed under spatial GCN fusion, contradicting published performance claims. [AI Research Strategy (JEPA/MIHD/STAIG)] (2026-06-14)#

5. Desktop Video gallery thumbnails displayed blank and tab-switches caused severe UI flicker due to async state resolution and scoped bookmark failures. [Desktop Video] (2026-06-14)#

Solution: Implemented dual-branch bookmark resolution with modification-date cache keys; forced synchronous NSCache lookups during SwiftUI view initialization to guarantee data availability before rendering.

6. NVIDIA RTX 5090 driver failed on Ubuntu with Secure Boot enabled due to self-signed DKMS module rejection, halting GPU compute. [Workstation & Dev Infrastructure] (2026-06-14)#

Solution: Removed custom nvidia-dkms packages and loaded Canonical’s pre-signed kernel modules via depmod, restoring full CUDA acceleration without compromising system security policy.

Learnings#

Architecture (architecture)#

  • Failure states in distributed or external-API workflows must never be cached without explicit TTL or validation gates; distinguishing transient errors from permanent state is critical for long-term data integrity.
  • Incremental invalidation over broad sweep patterns is essential for performance in file-based watchers and real-time statistics aggregators to prevent CPU bottlenecks on content-only changes.
  • Schema normalization layers are mandatory during CLI tool migrations (e.g., ccusage 20.x) to bridge incompatible output formats while preserving per-source granularity and backward compatibility.

Debugging (debugging)#

  • Stale dependency caches (Vite .vite-temp) on NTFS or FUSE-mounted drives frequently cause silent module graph desyncs; atomic rename failures require manual cache purges rather than dev-server restarts.
  • WHEA Event 17 ‘Correctable Errors’ on high-end GPUs are often benign software-induced PCIe config probing noise rather than hardware degradation; direct XML decoding of event logs is faster than binary parsing.
  • Public repository artifacts containing absolute local paths pose data leakage risks; installers and sync generators must dynamically adjust gitignore/config policy based on repository visibility (public vs private).

Tools (tools)#

  • Multi-agent auditing workflows significantly accelerate high-scale bug discovery but lack automated scope-completeness checks; manual verification of edge cases and unassigned items remains necessary.
  • Explicit local-first constraints must be established early in AI-assisted development to prevent agents from over-engineering hybrid cloud or external API architectures when internal struct suffices.

Domain Knowledge (domain)#

  • Internal project panoramas and executive summaries must override academic paper protocols as the source of truth for implementation alignment; dead code or legacy specs should never be assumed active.
  • mclust EM clustering is highly sensitive to initialization basins in complex datasets; single-run ARI/ARI benchmarks are statistically unreliable and require multi-seed validation to characterize variance.
  • General-purpose gene foundation models frequently lose spatial discriminative signal when fused with graph contrastive networks (GCN), favoring specialized embeddings like UNI2 for high-dimensional spatial transcriptomics clustering tasks.
