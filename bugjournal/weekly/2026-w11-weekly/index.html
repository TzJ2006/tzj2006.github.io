Issues and Solutions#

1. Drop skill: OSC controller actively maintains EEF position (impedance control) in env.step(). After the gripper opens, the object is held by a finger and cannot fall freely [ErrorRecoveryBenchmark] (2026-03-15)#

Solution: Bypass the controller and directly set MuJoCo qpos/qvel. Then call mujoco.mj_step() to run 15 physical steps for initial separation, before entering the standard control loop

2. MIHD cross-sample embedding comparison ineffective: per-section independent HVG selection + independent PCA fitting result in non-comparable feature space. The conclusion that ‘PCA is better than STAIG’ is a methodological error [MIHD] (2026-03-15)#

Solution: Use the shared HVG intersection (1137 genes) + unified raw_shared scheme as the correct baseline. Load directly from the original HDF5 instead of relying on per-section caching (there is a integerization bug in var_names)

3. Silent failure in parsing stack name: stack.yaml uses cubeA/cubeB, but MuJoCo actually has cubeA_main. _sim_body_name2id returns -1, causing Python negative index and all task phase detections to be misclassified as pre_reach [ErrorRecoveryBenchmark] (2026-03-15)#

Solution: Fix the body name segment. Add a main/_body0 suffix in _sim_body_name2id for fallback logic. Output WARNING instead of silently returning -1 on failure

4. pi05 training is 33% slower than openpi (20h vs 15h). Intuition points to hardware differences, but the root cause is unknown [VLA-RoboTwin/pi05] (2026-03-11)#

Solution: By comparing parallel sub-proxies and using pyproject.toml/uv.lock/wandb logs, identified the JAX version difference (0.5.0 vs 0.5.3) as the main cause. XLA compiler optimization accumulation; use uv override-dependencies to resolve the upper bound constraint conflict of lerobot torch

5. curobo pre-compiled.so is ABI incompatible with torch 2.7.1 (undefined symbol). JIT recompilation fails due to non-standard CUDA header path in conda [VLA-RoboTwin] (2026-03-12)#

Solution: Set CUDA_HOME to the root directory of the conda environment. Set CPATH to targets/x86_64-linux/include/. Install pip install -e. Recompile from source

6. Severe imbalance in online quota generation: premature_release naturally captures 7233 samples, but all 7 types are zero. The strategy behavior distribution is uneven and cannot be controlled [ErrorRecoveryBenchmark] (2026-03-09)#

Solution: Establish an offline injection architecture: first collect trajectories fully via rollout, then build an index of injectable points offline, and finally inject selectively according to the quota; types that are full are skipped

7. CalendarPro intent misclassification: no confidence threshold (0.52 also considered valid classification), time expressions misclassified by keyword routing, short confirmation words lack context understanding, Chinese token estimation偏差 is 3 times [CalendarPro] (2026-03-15)#

Solution: Add a per-route confidence threshold (0.40–0.60). Introduce a keyword scorer and 70/30 embedding hybrid routing. Split the system prompt into base + 11 fragments for按需 injection. Change Chinese token estimation to ×1.5

8. S2 co-author analysis completely fails for top experts (Levine/Abbeel/Finn, etc.) (depth-2 is completely empty). Xiaolong Wang/Shuran Song have serious name ambiguity [gadget] (2026-03-15)#

Solution: Reconstruct as a homepage-first strategy: prioritize extracting the student list from the professor’s personal homepage. Co-authorship is used only as a supplement. Multi-strategy URL discovery. Mark name ambiguity as WARNING and use S2 authorId for precise querying

9. Incorrect assumption in VLA context replay architecture: a complete N-1 frame replay mechanism was designed, but most VLA instances do not have a context window. This overhead is an unnecessary design [ErrorRecoveryBenchmark] (2026-03-15)#

Solution: Reconstruct ContextReplayEngine into InjectionEngine. Directly restore the injected frame sim state. Data source limited to the more controllable MimicGen demo data

10. RTX 2080 Ti + PyTorch 2.9.0 triggers cuBLAS CUBLAS_STATUS_EXECUTION_FAILED for N>3500 high-dimensional tensors [MIHD] (2026-03-09)#

Solution: First use a Linear projection to hidden_dim(128) and then index neighbors (to avoid high-dimensional large tensors entering cuBLAS). Replace InfoNCE with a mini-batch contrast loss (batch_size=512)

11. MCP Server tool writes file return path, AI cannot directly consume the content [gadget] (2026-03-09)#

Solution: Reconstruct the tool to bypass the cmd_* wrapper and directly call the underlying function to return the full content (markdown/JSON). Control file writing via save parameters

12. pi0.py has incorrect assumption about LeRobot internal behavior: inferred shape=(1,) feature maintains a(b,1) shape and the code was modified. In reality, LeRobot DataLoader will squeeze it to (b,), causing shape mismatch during training [VLA-RoboTwin/pi05] (2026-03-15)#

Solution: By actually running training and observing logs (‘aux_targets[…]: (32,)@float32’), confirm the true shape. Restore original[:, None] and jnp.stack operations

Learning Insights#

Architecture (architecture)- A necessary prerequisite for comparing cross-sample embeddings is shared feature space: independent HVG selection per section + independent PCA fitting = dual irrelevance. A valid baseline must use the intersection of shared HVG + joint processing, or a fixed pre-trained weight foundation model#

  • Direct state operations in MuJoCo and feedback controllers (OSC) have a fundamental conflict: sim.forward() only updates kinematics, while mujoco.mj_step() advances dynamics and bypasses the controller. Simulation injection design must explicitly select a path
  • Error type semantics should be split based on ‘whether the recovery strategy is the same’ rather than ‘whether the injection mechanism is the same’: detection conditions and recovery logic for drop_in_transit/drop_at_wrong_place/drop_with_interaction are completely different, and they must be modeled separately even if the injection action is the same
  • Structural flaw in semantic router architecture: embedding nearest neighbors always produce results and cannot express ‘uncertainty’. A combination of confidence thresholds + alternative LLM + keyword scorer is the most practical fix and can be generalized to all vector retrieval-based classification systems (RAG routing, tool selection, etc.)
  • MCP tools should prioritize AI consumption as their primary goal: returning full content, file writing being an optional side effect. General benchmarks should not assume the model has a context window; direct recovery of sim state by InjectionEngine is more general than context replay
  • For top scholars (500+ papers), frequency analysis of S2 co-authors cannot identify students—the first-author signal is diluted by many collaborators. Professors’ homepages explicitly list students, which is one order of magnitude more reliable. Citation graphs (forward + backward) are core features of research toolchains; ‘relevance’ and ‘citations/ popularity’ should be decoupled
  • Offline injection architectures are better suited for building balanced error scenario datasets than online quota systems: separating ‘exploring injectability’ from ‘executing injection’ allows precise control over the number of each error type; online injection is highly influenced by strategy behavior distribution and cannot control type balance

Debugging#

  • JAX minor version upgrade (0.5.0→0.5.3) can bring about ~33% training speedup, and the accumulation effect of XLA compiler optimizations cannot be ignored. uv override-dependencies can force ignoring transitive dependency version constraints; it is an effective tool for resolving third-party library version conflicts
  • Compiling CUDA extensions in a conda environment: CUDA_HOME = root directory of the conda environment, CPATH = envs//targets/x86_64-linux/include/ (not /usr/local/cuda/include/); after a major torch version upgrade, all .so files that depend on torch C++ ABI must be recompiled
  • Assumptions about internal behavior of third-party frameworks must be verified through actual running: LeRobot automatically squeezes shape=(1,) single scalar features into (batch_size,) during DataLoader, and code inference is unreliable. The actual effective value of training configuration must be verified from wandb logs; code default values may be overridden by CLI parameters
  • GPU monitoring within K8s containers: scanning /proc//fd/ for dev/nvidia* device links + prioritizing reading CUDA_VISIBLE_DEVICES can bypass PID namespace isolation; processes that open all GPUs but do not occupy memory are usually monitoring tools, which can be filtered accordingly
  • Silent failures are the most dangerous bug mode: body_xpos[-1] negative index always returns the same position in two cubes; integerizing var_names causes zero intersection of gene names. Any parsing failure should immediately trigger WARNING instead of returning a sentinel value; a thorough integrity check is required before using cached data

Tools#

  • Prompt engineering injection strategy based on needs: splitting the system prompt into base (~50 lines) + intent-specific fragment (dynamic injection by category) can reduce token consumption by 40–60%. Chinese character token density is about 6 times that of English characters (1.5 tokens/character vs 0.25 tokens/character); without correction, the context length will be systematically underestimated
  • Output directories for multi-tool projects should be organized by ‘file type priority’ (outputs/reports/summarize/ instead of summarize/reports/); simplifying .gitignore to a single line outputs/; the Python re-export shim pattern (only containing from x import y; all=[…]) is a backward-compatible and elegant migration method
  • The two-step E-utilities API from PubMed esearch→efetch can index metadata of subscription journals such as Nature/Cell/Science for free; the bioRxiv API is also available, without any new dependencies (urllib.request); small-scale validation of pipeline feasibility is better than directly hitting full volume
