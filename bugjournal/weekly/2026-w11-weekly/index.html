Lessons Learned#

Architecture#

  • A hybrid data collection strategy combining deterministic injection and natural capture can avoid deployment randomness bias. Strict and early archiving of abandoned experimental paths eliminates developer confusion and forces a forward-looking architecture over backward compatibility burden.
  • Legacy serialized fields and cross-module dependencies must be audited with backward-compatible default settings; atomic import tracking is needed for automatic architecture migration to prevent silent runtime failures. Separating bibliometric metrics from core relevance scores maintains the objectivity of academic tools.

Debugging#

  • Modern ML frameworks require strict version coupling between C-extension and compiler; micro-config drift severely disrupts shared compilation cache. Data loading patterns must strictly conform to downstream tensor rank requirements to avoid silent batch training failures.
  • Virtualized/GPU environments separate hardware telemetry from process visibility; direct /proc fd detection is crucial for accurate device allocation. Configuration files often lag behind engine hard-coded settings, and direct file system and state checks are essential for robust simulation debugging.

Tools#

  • Analysis pipeline resilience requires explicit fallback chains for probability outputs; silent failures cause exponential downstream damage. Terminal TUI reliability needs dual fallback: os.get_terminal_size() for interactive sessions and explicit environment variable parsing for CI/test runners.
  • Strict isolation of stdout/stdin using a context manager under _logs prevents MCP protocol transmission damage without disrupting RPC streams. Tool logs and protocol transmission are independent, requiring precise capture mechanisms to ensure clean execution.

Domain Knowledge#

  • In VLA/Flow-Matching models, adjustment of auxiliary loss head weights requires explicit gradient scaling calculation based on the main head before application, preventing silent strategy degradation. Freezing intermediate VLM representations via stop_gradient during auxiliary backpropagation effectively separates feature learning from task-specific condition updates in multi-objective training pipelines.
