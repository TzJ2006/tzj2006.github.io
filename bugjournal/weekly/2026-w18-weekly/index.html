Issues and Solutions#

1. The bottom edge of the taskbar shifts when hovering over charts due to a feedback loop between adjustment events and browser state.#

Solution: A fixed 500px scroll threshold limit was introduced, combined with dynamic anchor detection for working area boundaries; the border radius was conditionally removed via the data-anchor property to achieve seamless alignment

2. Windows tray icons cannot focus the application on the first click due to Win32 foreground ownership restrictions.#

Solution: SetForegroundWindow was used instead of SetFocus (this function inherits implicit foreground permissions in tray contexts), and a Svelte fallback timeout mechanism was added to handle edge cases

3. Initial release failed due to hidden fmt/clippy violations, leading to tag loss after fixing.#

Solution: A strict pre-release workflow was established, requiring complete local CI suite execution before tagging; git tag delete/rebuild was enforced to maintain release integrity

4. Error recovery collection script targets completed sub-types, causing the critical stuck_no_progress_D1 to be unrestricted.#

Solution: List targets were cross-referenced with file system realities, correct target commands were recorded, and path expectations were verified before rsync transfer

5. TokenMonitor FloatBall shows N/A for Cursor users because extra_usage/spend_limit_usage data is missing.#

Solution: A fallback chain was introduced in the extraction logic; primary_window_utilization was used preferentially when the optional usage field is null

6. pi0.5 v2 exhibits severe regression in task scenarios (Clean Rollout average -5.6pp, pick_place average -24.1pp)#

Solution: Performance differences across tasks were structured and isolated per task; it was confirmed that the issue is architectural trade-off rather than uniform degradation, and a deep diagnostic review was initiated

7. Gadget deployment conda activation fails with the error “running conda init before conda activate”.#

Solution: A portable ‘source activate AI’ command was used instead of standard conda syntax to avoid Shell initialization conflicts
