Problems & Solutions#

1. Strict W4A4 quantization leads to near-zero success rates on LIBERO tasks. [Quantization & Model Analysis]#

Solution: 识别了 attention weight outliers，并假设有必要采用混合 floating-point ‘island’ 方法。

2. Mac (ARM) recordings drift on Linux (x86) due to floating-point sensitivity in contact-rich scenes. [RecoverBench/RoboHarness]#

Solution: 实现了 ‘X1=C’ state-synchronization 标准，其中有效性由物理一致性而非精确重放来判断。

3. Historical Google credentials found in Git history. [Personal Agent]#

Solution: 更新了 .gitignore，并建议立即撤销和重新签发所有识别出的 credentials。

4. $\pi$0.5 action expert bypassed quantization due to lazy-initialization. [Quantization & Model Analysis]#

Solution: 将 activation check 修改为基于 ONNX bundle 的存在性来触发量化。

5. VM unable to access local vision models or shared GPU registries. [Personal Agent]#

Solution: 修改了 model_access 以支持 multi-host tracking，并利用 directory junctions 来共享 JSON registries。

Learnings#

Architecture (architecture)#

  • 解耦不仅需要代码更改，还需要在 process boundaries 之间建立严格的资源 (GPU/Model) 发现策略；由于 PIDs 在 network shares 中不是唯一的，跟踪 ‘host’ 名称至关重要。
  • ‘Plan-once + JEV’ 架构的强度由其信息可用性约束定义，从而建立了独特的研究范围。

Domain Knowledge (domain)#

  • 单独的 success rate 对于比较 harness 方法是不充分的；‘Success Rate / Theoretical Ceiling’ 是衡量 memory precision 更稳健的指标。
  • 有效的研究陈述必须从 ‘what I did’ 过渡到 ‘what I realized (the gap)’，再到 ‘what I will solve’。

Debugging (debugging)#

  • 如果特定属性在 evaluation 期间从未被触发，量化模拟器的 lazy initialization 可能会静默地绕过量化路径。
