Problems & Solutions#

1. pi0.5 Libero goal suite reported 0% success rate. [pi0.5 VLA] (2026-09-17)#

Solution: 验证了 float baseline 达到了 100% 成功率，从而将问题隔离为 action head 中由量化引起的精度损失。通过消融实验确定 RMSNorm 是罪魁祸首。

2. 4-bit activation (W4A4) significantly slower/worse than FP16 on NPU. [pi0.5 VLA] (2026-09-14)#

Solution: 发现 NPU 中缺乏原生的 INT4 activation kernels，导致了 tensor expansion 带来的开销。建议使用 W4A8 作为最佳平衡点。

3. RoboMemory training loss reached 2e11 (astronomical). [RoboMemory] (2026-09-17)#

Solution: 发现 normalization stats 是在 gripper dimension 标准差为零的子集上计算的；已在完整的 16-task 数据集上重新计算了 stats。

4. AI Hub automation broke due to ‘qnn_context_binary’ deprecation. [AI Hub] (2026-09-14)#

Solution: 更新了提交脚本以显式传递 ‘–target_runtime qnn_dlc’，并更新了所有相关文档。

5. TokenMonitor fork merge failed due to 66+ conflicts from rewritten history. [TokenMonitor] (2026-09-17)#

Solution: 放弃直接 merge，改为将 10 个核心 feature commits cherry-pick 到 upstream base 上。

Learnings#

Architecture (architecture)#

  • 对于 VLA 模型，W4A8 是 ‘Sweet Spot’：weight 4-bit 是高度可接受的，而 A4 activation 会导致 backbone 发生灾难性的精度崩溃。
  • 视觉 prompts 必须优先考虑 ’training-robustness’（在裁剪/旋转下生存）和 ‘policy-utility’（场景锚定），而非美学清晰度。

Debugging (debugging)#

  • 训练子集中的零标准差会导致多任务 normalization statistics 发生灾难性失败。
  • 在高并发环境中，worker limits 必须考虑到 ‘grandchild’ 进程；优化遵循 U 型曲线。

Tools (tools)#

  • 当 fork history 被重写时，‘git merge’ 通常无法使用；cherry-picking 是一种更可靠的重建方法。

Domain Knowledge (domain)#

  • ‘Target Hit Rate’ 对于 memory 任务是一个危险的指标，因为它将 object detection 准确率与实际的历史 temporal memory 混为一谈。
