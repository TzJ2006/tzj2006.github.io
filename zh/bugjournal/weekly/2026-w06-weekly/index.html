问题与解决方案#

1. 文档中缺失约 0.45 ARI 的基准测试结果，输出文件分散在嵌套目录中，导致审计追踪失效。[MIHD 多模态空间流程]（2026-02-03）#

解决方案： 自动 CSV 解析以重建真实指标和可视化追踪，消除对异步 markdown 日志的依赖。

2. 低聚类精度（ARI 0.09–0.35）与基线预期显著不同，原因是静默默认参数覆盖和预处理不匹配。[MIHD 多模态空间流程]（2026-02-05）#

解决方案： 对原始实现进行详尽的 YAML/笔记本差异对比，修正 dropout 掩码、边缘权重归一化，并强制严格序列一致性。

3. 评估期间的运行时崩溃和可视化失败由上游零维张量及 Pandas-to-Plotly 序列化错误引起。[基础设施与自动化安全架构]（2026-02-06）#

解决方案： 实施早期张量形状验证，为已废弃属性提供防御性回退机制，对静态渲染库进行零值限制的数值强制转换。

4. Conda 激活和模拟后端之间的环境状态不一致导致在受限 HPC 节点上出现静默 CPU 回退和 EGL 渲染崩溃。[QueST 算法指标与基准测试]（2026-02-08）#

解决方案： 实施程序化运行时验证（torch.cuda.is_available()），硬编码后端禁用选项，以及明确的设备标志，替代隐式的环境假设。

5. “SameLabel@50” 指标返回恰好为 0.0，因为严格的空间排除掩码在基准测试期间将所有符合查询类型的候选 niches 移除。[QueST 算法指标与基准测试]（2026-02-08）#

解决方案： 修改检索逻辑以允许同类查询，同时严格隔离自匹配排他性，用于 Precision@K 结构排名比较。
