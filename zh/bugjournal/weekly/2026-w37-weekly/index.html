Problems & Solutions#

1. 4-bit activation conversion (W4A4) failing in the closed-source quantizer. [VLA Quantization Research]#

Solution: 进行了 boundary probes；确认成功的编译往往掩盖了 silent fallback 到 float 的现象。

2. AI Companion/Security guard was silently failing due to non-existent absolute paths. [AI Companion Engine]#

Solution: 迁移至使用 .companion 目录内 relative paths 的 bundled architecture。

3. Decision instability in RL due to pattern ID dependency and one-hot encoding. [Tile-Matching RL]#

Solution: 切换到受 Deep Sets 启发的架构，使用 numerical features 和 symmetric relation matrices。

4. VLM inaccuracy in distinguishing between arm motion and scene changes. [RoboMME/VLM]#

Solution: 引入 ‘Quad-Writer’ hierarchy，在进行 visual grounding 之前对 task context 进行分类。

5. Inefficient migration of 477k small pkl files via single-stream rsync. [Infrastructure]#

Solution: 通过按 name prefixes 切分文件，实现了 8-way parallel rsync 策略。

6. Security bypass by passing paths as quoted substrings after interpreter wall removal. [AI Companion Security]#

Solution: 实施了第三次 scanning pass，使用 ‘mentionedLedger’ 来检测作为 substrings 的敏感路径。

Learnings#

Architecture (architecture)#

  • 依赖 ’layering’ 的安全屏障可能会产生虚假的安全感；移除一层后可能会发现后续层之所以有效仅仅是因为第一层的存在。
  • 在无序集合（如 game tiles）中，symmetric aggregation (Deep Sets) 优于 one-hot encoding，因为它消除了任意的 ID dependency。

Debugging (debugging)#

  • 低 FPS 结合低 resource usage 通常指向 thread synchronization 或 display buffer blocking (glfwSwapBuffers)，而非 hardware capacity 问题。

Domain Knowledge (domain)#

  • VLA quantization 的复杂度在很大程度上取决于 GPU-level quantization 与 NPU-specific compilation rules 之间的差距。
  • 对于高风险写作 (SoP)，‘generic core’ 必须足够强大，能够连接多个不同的 ‘customized hooks’ 以防止 logical drift。

Tools (tools)#

  • 在 HPC clusters 上迁移大规模数据集时，使用 parallel rsync script 对于避免 single-stream bottlenecks 至关重要。
