问题与解决方案#

1. 上游合并冲突导致不同分支产生差异，需实现架构对齐，同时不丢失本地实现 [TokenMonitor]（2026-05-04）解决方案： 采用混合合并策略隔离冲突模块，通过合并集成点保留两个分支的价值，并手动恢复已撤销的文件。#

2. 学术论文中的关键 BC-RNN 指标差异（21% 对比实际 56%）及专业图表格式问题 [ErrorRecoveryBench / RecoverBench (NeurIPS 2026 E&D)] (2026-05-07)#

解决方案： 将所有表格数值与原始实验 JSON 进行交叉验证，修正策略行，并将 matplotlib 输出调整为科学配色方案，采用统一的排版方式。

3. FloatBall 因激进的窗口过滤导致关键约束被隐藏而无法显示速率限制 [TokenMonitor] (2026-05-06)#

解决方案： 将所有窗口的选择改为最大利用率策略，确保无论会话状态如何，最关键约束始终能够被呈现。

4. RTX 5090 在空闲/启动过程中出现间歇性 BSOD 和 WHEA PCIe AER 不支持请求错误 [Hardware Systems / Workstation Diagnostics] (2026-05-05)#

解决方案： 确定 NVIDIA 驱动程序链接状态下降为根本原因；通过调整驱动程序强制电源管理模式为“优先最大性能”来解决问题。

5. LeRobot DataLoader 中损坏的 MP4 文件导致的运行时失效与 JAX JIT 约束冲突 [LeRobot Data Pipeline & PairedDataset] (2026-05-09)#

解决方案： 创建诊断脚本从 HDF5 重新编码；实施动态 try-except 黑名单和损失掩码，以绕过静态图控制流限制。

6. CSS Grid 折叠动画导致填充/边框在多个 UI 部分间出现视觉泄漏 [TokenMonitor] (2026-05-04)#

解决方案： 将 grid-template-rows: 0fr 改为基于最大高度的动画，并在父容器上设置 overflow hidden，从而恢复跨浏览器的一致性行为。

经验教训#

system_architecture (system_architecture)#

  • 速率限制备用链应优先使用服务器权威/免费来源，而非付费/客户端侧估计。AI 在系统级架构评审和算法迭代兼容性方面存在困难，因此人工监督对于早期识别基本设计风险至关重要。

debugging_diagnostics (debugging_diagnostics)#

  • npm 全局安装产生双执行路径，需要在 Rust 进程启动时明确路径优先级。NVIDIA GPU 上的 PCIe AER 不支持请求标志通常源于驱动程序级别的 ASPM 链接状态转换，而非物理故障。与原始实验 JSON 进行事实核对至关重要；损坏的 MP4 文件在 PyAV 解码过程中失败，而非头信息检查问题，而 JAX JIT 需要独立于张量值的静态图控制流。

devops_tooling (devops_tooling)#

  • Tauri v2 强制 Rust 库和 npm 包之间严格符合 major.minor 规范；通过生命周期钩子自动化同步可防止构建碎片化。并行测试操纵环境变量需要单一全局互斥锁，以防止竞争条件。在受限 HPC 环境中，当现代工具失败时需要 POSIX fallback，而通过导出/重建迁移到 Conda 更简洁，无需文件夹复制。

academia_research_workflow (academia_research_workflow)#

  • NeurIPS 双盲投稿要求超出作者姓名范围的严格匿名化（路径、输出、硬编码基础设施标签），且出版图表需要零重叠布局的科学配色方案。学术声明必须严格反映实施实际情况；手动参考文献工作流在提交前通常提供协作灵活性，但按任务选择性检查点需要明确的评审者文档。

AI 使用注意事项#

有效模式：

  • ✓ 在明确指导下采用混合 git 合并策略以保留不同的功能集
  • ✓ 并行代理部署用于大规模代码库转换和批处理文件处理
  • ✓ 跨 IPC 边界和大型代码库的系统化管道追踪比仅读取配置更有效地明确复杂数据/奖励流动
  • ✓ 交叉验证原始实验输出可防止学术写作中的关键事实错误
  • ✓ 对现有文档的结构化审计可在重新生成前验证稳定性，节省大量时间

限制：

  • ✗ 倾向于过度设计解决方案或在不验证用户工作流约束的情况下提出不必要的架构变更
  • ✗ 在执行批处理编辑或撰写声明之前未确认目标文件路径和外部 API 单元
  • ✗ 在学术草稿中初期不愿挑战未实现的功能，或在没有明确范围指导的情况下预期整个分布的数据损坏
  • ✗ 在等待实证压力测试验证之前就对硬件日志进行过早诊断
  • ✗ 缺乏机器人操作管道调试和架构风险评估的领域直觉；默认工具在需要手动备用策略的受限 HPC 环境中失效
