Problems & Solutions#

1. RecoverBench paper claims 与实际使用的 training data 之间的差异。[RecoverBench]#

Solution: 进行了系统的 agentic audit，将 claims 映射到 cluster 上的实际文件；实现了 ‘Claims/Evidence’ ledger。

2. ResNet shortcut 实现使用了 projection convolutions 而不是 identity requirement。[ECE661/ResNet]#

Solution: 重构了 ResNet class 以实现 Option A (identity shortcut) 并重新训练了模型。

3. 由于 Conv3d patch embedding bottleneck，OmniJev M2 执行速度极慢。[OmniJev]#

Solution: 用等效的 linear layer 替换了缓慢的 torch 实现，将每张图像的 latency 从 16s 降低到 0.06ms。

4. W4A4 quantization 导致严重的性能下降 (0% 成功率)。[Quantization/VLA]#

Solution: 确定 backbone activation 是错误来源，并建议转向 W8A8 以避免 non-functional quantization graphs。

5. SQLite WAL merge 导致数据库损坏和 ‘quick_check’ 失败。[WeAgent]#

Solution: 使用官方 engine 的 ‘SQLite Replay’ 方法替换了手动 merging logic，以回放解密的 WAL files。

6. 由于隐藏的 proprioceptive data 使用，导致 robot policy evaluation 成功率虚高。[OmniJev]#

Solution: 实现 DRAWN_MEMORY_VISUAL_ONLY/TRACK flags 以强制实现 zero proprioception，将成功率修正为 65.0%。

Learnings#

Architecture (architecture)#

  • 在 multimodal agents 中，分解 memory tasks（使用 code 处理 temporal/sequence logic，使用 VLM 处理 perception）优于使用 VLM 进行所有 reasoning。
  • 对于研究导向的身份（CVs/PhD），优先考虑问题定义和 research intuition 的战略性叙述比单纯罗列技术细节更有效。

Debugging (debugging)#

  • GPU kernel autotuning（例如 Triton GEMM/XLA）可能会引入模拟 code regressions 的 non-determinism；在进行 benchmarks 时需要强制使用 deterministic autotuning。

Domain Knowledge (domain)#

  • 由于硬件会自动为某些操作使用 FP16，4-bit simulations 在预测硬件精度方面可能过于悲观且不可靠。
  • 可靠的 robot learning 必须区分 ‘arbitrary starting state’ 和 ‘state following an execution error’，以衡量真正的 error recovery。

Tools (tools)#

  • 在处理像 SQLite WAL 这样复杂的 database internals 时，使用官方 engine 来 replay 解密文件比实现自定义的 manual merging 更安全。

AI Usage Notes#

Effective Patterns:

  • ✓ 用于 ‘Claims/Evidence’ 审计的 Multi-agent workflows
  • ✓ 使用 writer/reviewer/adversarial loops 进行 Agentic manuscript drafting
  • ✓ 使用 AI 将 high-level scientific constraints 整合为 structured decision tablesLimitations:
  • ✗ AI 在研究推断中倾向于“过度确定性” (over-certainty)
  • ✗ 在没有显式提示的情况下，无法识别 policy evaluations 中的非视觉数据泄露
  • ✗ 在 multi-agent loops 中难以管理复杂的、高精度的数据结构 (AttributeError/KeyError)
