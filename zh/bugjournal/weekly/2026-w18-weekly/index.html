问题与解决方案#

1. 图表悬停时任务栏底部边缘因调整事件与浏览器状态之间的反馈循环而偏移。#

解决方案： 引入了固定的 500px 滚动阈值限制，结合使用工作区域边界的动态锚点检测；通过 data-anchor 属性条件性移除边框半径，实现无缝对齐

2. Windows 托盘图标首次点击无法聚焦应用，由于 Win32 前台所有权限制。#

解决方案： 用 SetForegroundWindow 替换 SetFocus（该函数在托盘上下文中继承隐式前台权限），并添加 Svelte 回退超时机制以应对边缘情况

3. 初始发布因隐藏的 fmt/clippy 违规导致 GitHub CI 失败，修复后引发标签流失。#

解决方案： 建立了严格的预发布工作流程，要求在标记前完成完整的本地 CI 套件执行；强制执行 git 标签删除/重建以维护发布完整性

4. 错误恢复收集脚本针对已完成的子类型，导致关键的 stuck_no_progress_D1 不受限制。#

解决方案： 将清单目标与文件系统现实进行交叉比对，记录正确的目标命令，并在 rsync 传输前验证路径预期

5. TokenMonitor FloatBall 为 Cursor 用户显示 N/A，因为缺少 extra_usage/spend_limit_usage 数据。#

解决方案： 在利用提取逻辑中引入回退链，当可选使用字段为 null 时优先使用 primary_window_utilization

6. pi0.5 v2 在任务场景中表现出严重回归（Clean Rollout 平均 -5.6pp，pick_place 平均 -24.1pp）#

解决方案： 通过结构化格式化为每个任务隔离性能差异，确认是架构权衡而非均匀退化，并升级进行深度诊断审查

7. Gadget 部署 conda 激活失败，出现“在 conda activate 前运行 conda init”错误#

解决方案： 使用可移植的 ‘source activate AI’ 命令替代标准 conda 语法，避免 Shell 初始化冲突
