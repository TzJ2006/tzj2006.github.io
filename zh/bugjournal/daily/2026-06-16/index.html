问题与解决方案#

关键问题#

1. 本地 HPC 使用统计数据显示 March/April 无数据；macOS DMG 创建脚本因 Finder/QuickLook 锁定而反复出现“资源繁忙”错误。#

解决方案： 对于 HPC，检查了元数据发现自动删除/缓存冻结现象；得出结论需要外部 API 查询。对于 macOS，使用了 diskutil unmountDisk force，终止后台服务，使用唯一卷名以绕过锁定。

关键见解： 本地工具日志通常具有严格的保留策略；macOS 自动化需要明确的资源释放策略，因为操作系统级别的文件锁定较为严格。

2. 在自动终端环境中使用凭证提示时，Git push 失败。#

解决方案： 将远程 origin 从 HTTPS 切换为 SSH 协议，依赖已安装的 SSH 密钥进行无缝认证。

关键见解： 对于非交互式/自动化 Git 工作流，SSH 通常比 HTTPS 更稳健，因为凭证辅助工具可能会失败。

一般问题#

3. 初始的检索结果空间可视化过于拥挤且难以理解；原生 SwiftUI 选择器无法在 macOS 上居中文本。#

解决方案： 将空间可视化从绝对相似度改为基于真实基准数据的百分比排序，以揭示结构。使用类似 CSS 的 HStack 操作创建自定义 CenteredMenuPicker 来实现所需的 UI 风格。

关键见解： 有效的科学可视化需要相对上下文（排名）而非原始数值；特定平台的 UI 限制通常需要开发自定义组件。

4. TokenMonitor 开发服务器在 Windows 上因缺少原生绑定而崩溃；本地 git 分支与远程分支严重 diverge。#

解决方案： 发现 npm 未能安装特定平台可选依赖，被迫进行彻底重新安装。通过 stash 本地工作并将 main 快速推进到 origin/main 来解决 git 差异问题，优先实现代码库统一。

关键见解： npm lockfile 可能在不同操作系统之间产生误导；在解决多设备冲突时，早期识别“真实来源”可避免复杂的合并历史。

关键学习点#
