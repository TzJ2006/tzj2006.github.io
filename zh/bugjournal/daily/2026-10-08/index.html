Problems & Solutions#

Critical Issues#

1. Cross-platform floating-point divergence causes Mac-recorded demonstrations to fail open-loop replay on Linux.#

Solution: 采用了 ‘recorded-state’ 标准 (X1=C)，即通过记录步骤的物理一致性而非精确的回放来判断有效性。

2. The π0.5 action expert’s forward method bypasses quantization because _quant_sim is only built lazily on first access, which doesn’t occur in the current loop.#

Solution: 确定需要更改 activation check，通过检查 onnx bundle 的存在性来确保正确触发 quantized path。

3. Initial research claims were statistically invalid or unsupported by sufficient data regarding the ‘Agent Harness’ advantage.#

Solution: 将叙述转向关注 memory precision (Success Rate / Theoretical Ceiling)，并将 Agent 重新定位为支持性基础设施工具，而非主要创新点。

4. Directly merging Codex-Cockpit code failed due to React/Svelte and backend structure incompatibilities.#

Solution: 在原生的 Svelte 5 和 Rust 架构内重新实现了特定逻辑 (project usage, reset forecasting)。

5. The right-click menu in WeChat 4.x lacks the ‘Add to Stickers’ option.#

Solution: 通过 Emoji Panel (Alt+E) 和 ‘Custom Stickers’ tab 实现了一条 automation route。

6. Modules/gadget still importing code from parent workspace via sys.path hacks.#

Solution: 重构为使用可安装的 ‘model_access’ package 和显式的 CLI entry points。

7. PermissionError during concurrent lock-file initialization in ResourceBoard.#

Solution: 实现了原子化的 lock-file creation，避免截断被其他进程持有的文件。

8. NCL performance degradation due to effective rank collapse when using scGPT inputs.#

Solution: 已记录为关键发现；正在调查 heavy smoothing 方法或不同的 reconstruction objectives 是否可以缓解此问题。

AI Limitations#

General Limitations#

  • AI 最初建议了在统计学上脆弱的断言，并且在没有明确提示的情况下，难以解释 social/UI 行为 (如 scrolling)。
  • AI 在 component performance 的过时数据方面偶尔出现问题，并误解了某些 modules 的实现状态。
  • AI 通过 shell redirection 写入或访问 system-level files 的尝试经常被项目特定的 security/safety guardrails 拦截。
  • 对 agent 生成的 survey 真实性的隐式依赖，需要人工对 links 和 repositories 进行手动验证。

Learnings#

Key Learnings#

  • Decoupling architectures 要求在跨 process boundaries 时，对于如何发现和申领 resources (GPU/Models) 制定严格的 policies，而不仅仅是代码变更。
  • 如果特定属性从未被触发，quantization simulators 的 lazy initialization 可能会在 evaluation pipelines 中悄无声息地绕过 quantization。
  • 单独的 success rate 对于比较 harness methods 是不充分的指标；‘Success Rate / Theoretical Ceiling’ 是衡量 memory precision 更稳健的指标。
  • Multimodal framework 的优势在于为 cross-slide comparison 提供一个 ‘shared coordinate frame’，这与针对每张 slide 训练的模型不同。
  • 在向现有的 aggregation pipelines 添加维度 (project/session) 时，对 data structures 进行迭代优化是必不可少的，以避免破坏 stats。
