Problems & Solutions#

Critical Issues#

1. W4A4 quantization results in zero success rate for VLA tasks due to backbone A4 activation errors.#

Solution: 验证了 W4A8 (4-bit Weight, 8-bit Activation) 可达到 100% 成功率；建议将 W4A8 作为最终交付标准。

2. RoboMemory training loss was astronomically high (2e11) due to division by zero in normalization.#

Solution: 确定 norm_stats 是基于一个子集，其中第 8 维 (gripper) 的 std 为零；已在完整的 16-task 数据集上重新计算了 stats。

3. Direct git merge between TokenMonitor fork and upstream caused 66+ ‘add/add’ conflicts due to rewritten history.#

Solution: 放弃 merge，改为将自 v0.14.2 以来提交的 10 个特定 commits cherry-pick 到 upstream 分支。

4. Cursor usage data was missing because the parser failed on empty JSON responses ‘{}’.#

Solution: 修改了 parser，将缺失的 ‘usageEvents’ 数组视为空列表而非致命错误。

5. npm ci in GitHub Actions failed due to lockfile format mismatches between local and CI Node versions.#

Solution: 将 CI Node 版本 pinning 至精确的 24.12.0，以匹配本地开发环境。

General Issues#

6. Seeking ways to salvage A4 precision via optimization or fine-grained quantization.#

Solution: 测试了 MSE clipping（效果不足），并确定 fine-grained/mixed-precision 目前受限于 QAIRT deployment 约束而无法支持。

7. TokenMonitor had Vitest vulnerabilities and fsevents install script warnings.#

Solution: 将 Vitest 更新至 4.1.11，并在 package.json 中显式阻止了 fsevents install scripts。

8. SSH connection instability to the tianhe3 cluster prevented continuous monitoring.#

Solution: 为 SSH 命令实现了 retry loop。

Learnings#

Key Learnings#

  • 对于 VLA models，W4A8 是 ‘Sweet Spot’：weight 4-bit 的容忍度极高且性能损失极小，而 A4 activation 会导致 backbone 发生灾难性的 precision collapse。
  • 务必确保 normalization statistics 是在完整的预期 dataset 上计算的；subset 中的 zero-std dimensions 会在 multi-task settings 中导致灾难性的 training failure。
  • 当 fork history 被重写时，由于不断的 ‘add/add’ 冲突，‘git merge’ 通常无法使用；cherry-picking 特定的 commits 是更可靠的 reconstruction method。
  • 顶尖 robotics programs 的 PhD admission 受 ‘prior connections’（例如 internal Master’s programs）和直接的 faculty contact 影响很大，而不仅仅是 GPA/publications。
  • Protobuf-JSON serialization 经常完全省略 empty arrays，这可能会破坏期望特定 field structures 的 parsers。
  • local 与 CI 之间 npm versions 的微小差异会导致由于 lockfile format drift 引起的灾难性 ’npm ci’ failures。
