Problems & Solutions#

Critical Issues#

1. 当前的 NCL 方法并非“真正的融合”，因为它仅修改基因 embeddings，而不是在预测阶段结合多种模态。#

Solution: 计划实现 ‘NCL + Concat’ 和 ‘NCL + Q-Former’，以提供全栈式的多模态对比。

2. DLPFC 中存在不一致的聚类行为，其中仅基因的方法可能会从 mclust 退化到 KMeans，从而导致结果偏差。#

Solution: 使用 ‘Concat + constant’（零化图像信息）作为仅基因的 baseline，以确保所有组都使用相同的聚类后端。

3. JEV ‘clamping’ 误判 (VideoRepick/BinFill)#

Solution: 部署 Probe 2 措辞（’lifted’, ’empty’, ‘gap’）以绕过 ‘clamping’ 的歧义。

4. 符号化路径准确性 (PatternLock/RouteStick)#

Solution: 通过 API 验证 one-shot 符号提取是否达到 >60% 的成功率。

General Issues#

5. 依赖冲突：transformers 4.57 要求 huggingface-hub < 1.0，但 datasets 5.1 要求 >= 1.31。#

Solution: 将 datasets 降级到 4.8.5 版本，以满足 huggingface-hub < 1.0 的约束。

6. Pandas 3.0 返回的 Arrow string arrays 与 scikit-learn indexing 不兼容。#

Solution: 使用 .to_numpy(dtype=object) 将 dataframe 列转换为 object dtype 的 numpy arrays。

7. 提供的辅助函数 ‘predict_sentiment’ 存在逻辑错误（将单词索引作为字符串进行搜索）。#

Solution: 绕过该辅助函数，直接使用 vocabulary mapping 进行预测。

8. PDF 中的 Type 3 font 警告#

Solution: 将图像重新渲染为 600dpi bitmaps，以确保符合 embedding 标准。

9. 潜在的数据泄露（JSON 中的用户路径）#

Solution: 决定保持现有的 HF training data 不变（名称是公开的），但清理了所有新的/发布的文档。

Learnings#

Key Learnings#

  • histology images 的有效性在很大程度上取决于数据集（DLPFC vs HD）和基因输入方法（例如 PCA vs HVG）。
  • 对于像 GPT-2 (124M) 这样的小模型，来自 LoRA 的加速效果微乎其微，因为通过 frozen layers 的 forward/backward passes 占据了总计算时间的主导地位。

  • Gemini 3.8 Flash 在 ButtonUnmaskSwap 中的成功部分归功于非视觉的 proprioception（manual oracle）。对于 C，我们必须依赖 JEV 的 visual swap detection。
