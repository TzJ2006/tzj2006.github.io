Problems & Solutions#

Critical Issues#

1. $\pi$0.5 VLA 的 W4A4 quantization 导致在 ’libero_goal’ 中的成功率为 0%，原因是 RMSNorm outputs 中的 quantization noise 超过了所需的 action distinction distance。#

Solution: 使用 TF-Enhanced range search 取代 min-max calibration，为 35 个 RMSNorm outputs 优化了 16 个 quantization levels。

2. 关于 fusion 提升性能的核心观点在 cell-lineage (GT-B) 粒度下似乎发生了反转，这可能会削弱论文的核心假设。#

Solution: 进行了详细审计，结果显示在固定 protocol 下，fusion 的收益是 scale-dependent 的，在 tissue level 提供 spatial context 可能会在更精细的 cell-lineage level 引入 noise。

Key Insight: NCL fusion 的收益高度依赖于 ground truth 的粒度。

3. 如果 $\pi$0.5 是进行 per-task training 而不是 multi-task，可能会出现潜在的 setting mismatch。#

Solution: 验证了 remote training scripts 并确认 official baseline 使用的是 multi-task training；调整了 local pipeline 以与之匹配。

4. 由于 duplicate records 和 mismatched provider tags，SSH sync 导致各设备间的 usage totals 不一致。#

Solution: 在 extractor 中实现了基于 message-ID 的 deduplication，并在 archive layer 中实现了 re-tagging mechanism，将 records 合并到 ‘all’ provider bucket 中。

5. Hugo build 失败，因为 translator 在没有 escaping 的情况下将原始 LaTeX math ($\pi$) 写入了 YAML frontmatter。#

Solution: 修改了 frontmatter.py，在写入时使用 json.loads 解码 values 并使用 json.dumps 进行 re-encode。

6. DLPFC clustering 结果（STAIG vs. NCL）在 single-run observations 与 100-seed means 之间存在差异。#

Solution: 确定 single-run observation 是一个 ‘unlucky draw’，而 100-seed mean 正确反映了方法的稳定性。

7. 从 mclust 到 KMeans 的 silent fallback 掩盖了潜在的 clustering algorithm biases。#

Solution: 开发并运行了 ‘fallback audit’ (mclust_fallback_audit.py) 以检查 clusterer 在不同 seeds 下的稳定性。

General Issues#

8. 通过单个 scp 传输 11.5GB checkpoint 时速度较慢（约 245 KB/s）。#

Solution: 实现了一个带有 automatic retries 和 MD5 verification 的三通道 parallel chunked transfer script。

9. Visual prompts (counting badges) 是不透明的，遮挡了画面中的关键物体。#

Solution: 修改了 oracle_v2.py，为 badge 实现 semi-transparent background，同时保持 text 不透明。

Learnings#

Key Learnings#

  • 在敏感层（如 RMSNorm）中对 quantization scales 进行精确控制至关重要；noise 必须显著低于 fine-grained actions 之间的 L2 distance。
  • Fusion 在 spatial omics 中的收益在不同 scale 下是非单调的：它们增强了 tissue-level organization，但可能会降低 fine-grained cell-type resolution。
  • 统一的 multitask VLA 结合 visual-memory prompting framework 比 task-specific VLAs 提供了更强大的研究主张。
  • TF-Enhanced calibration 可以显著提高 4-bit quantization 的有效范围，而无需增加 bit-width 或改变 graph structure。
  • 在跨设备同步数据时，‘provider’ tag 对于 bucket identity 至关重要；标签不匹配会导致错误的 aggregation。
