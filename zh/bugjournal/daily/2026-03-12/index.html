Problems & Solutions#

Critical Issues#

1. History media entries fail to open with ‘Operation not permitted’ due to missing sandbox entitlements and TCC permission expiration for long-term access.#

Solution: 在 entitlements 中启用了 com.apple.security.app-sandbox，更新 ensureFileAccess 以 fallback 到 non-scoped bookmark parsing，并添加了 automatic NSOpenPanel prompts 以在被拒绝时重新授予权限。

Key Insight: 在没有 active sandbox 的情况下，security-scoped bookmarks 会静默创建失败；需要一种结合显式 sandbox activation 与交互式 re-authorization 的 hybrid approach 来实现可靠的长期文件访问。

2. Runtime crash during evaluation due to torchvision::nms operator registration failure caused by PyTorch version drift.#

Solution: 验证了 environment versions，通过 official PyTorch index 将 torchvision 从 0.21.0 升级到 0.22.1+cu126，确认了 native operator 的可用性，并重新运行了 evaluation pipeline。

Key Insight: PyTorch ecosystem 中的 minor version mismatches 会在 module initialization 期间触发硬性的 C-ABI breaks；为了稳定的 inference training loops，精确的 release pairing 是强制性的。

3. Curobo JIT compilation fails with missing cuda_runtime.h and undefined symbols due to non-standard conda/pip CUDA path isolation.#

Solution: 在 pip-installed nvidia packages 中定位了 CUDA headers，显式配置了 CPATH 和 CUDA_HOME environment variables，移除了过时的 .so files，并通过 pip editable install 重建了 extension。

Key Insight: 混合使用 conda 和 pip environments 会掩盖标准的 toolkit paths；native extensions 需要显式的 include directory mapping，而不是依赖默认的 system symlinks 或 build isolation。
