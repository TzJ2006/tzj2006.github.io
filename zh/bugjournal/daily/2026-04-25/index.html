问题与解决方案#

关键问题#

1. 初始令牌统计缺乏缓存指标，而缓存指标占实际令牌消耗的 85%#

解决方案： 扩展 Node.js 聚合脚本以解析 JSONL 条目中的 cache_read 和 cache_write 字段

关键洞察： 提示缓存极大地改变了令牌经济模式——缓存读取（277M）是常规 I/O（5M）的 55 倍

一般问题#

2. PR 合并后 Git 分支与 main 不同步，导致上游状态混乱#

解决方案： 使用 git rebase origin/main 将功能分支快速同步到远程 main 版本

关键洞察： 当功能分支的更改被合并到上游时， rebase（而非 merge）是同步的最佳方式

3. 开发服务器因端口 1420 冲突和安装崩溃后缺少 plugin-opener 依赖而失败#

解决方案： 确认端口处于 TIME_WAIT 状态（自动释放），然后使用 npm 安装缺失的 Tauri 插件包

关键洞察： TIME_WAIT 连接不会阻塞新监听器；npm 安装崩溃可能导致依赖树不完整
