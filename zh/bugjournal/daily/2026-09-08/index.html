Problems & Solutions#

Critical Issues#

1. 由于 pattern ID 依赖和 one-hot encoding 限制导致的决策不稳定和碰撞。#

Solution: 切换到受 Deep Sets 启发的架构，使用数值特征和对称关系矩阵以确保 permutation invariance。

2. VLM 在区分 arm motion 和 scene changes 时存在不准确性。#

Solution: 引入 ‘Quad-Writer’ 层级结构，在进行 visual grounding 之前对任务上下文（subject 和 timing）进行分类。

3. Solver 在 tray capacity 以及未知 tiles/occlusions 方面的准确性问题。#

Solution: 更新了 simulator logic，将未识别的 patterns 视为占用了一个 slot，并完善了 occlusion unlocking rules。

4. 由高置信度 BC pre-training 导致的 RL policy saturation 和缺乏探索。#

Solution: 实施了 Logit Shrink (policy smoothing) 以在不改变 argmax 顺序的情况下增加 distribution entropy，同时增加了 entropy coefficients。

General Issues#

5. 由于多线程非确定性导致的 quad-writer 自测失败。#

Solution: 在自测中将 ‘workers=1’ 固定，以确保顺序数据传输。

6. 在狭窄间隙中检测 patterns 的精度较低。#

Solution: 实现了一种使用局部 pixel features 和 positional constraints 的 grid-aligned ‘gap matching’ 算法。

Learnings#

Key Learnings- 在无序集合（如 game tiles）中，symmetric aggregation (Deep Sets) 显著优于 one-hot encoding，因为它消除了对任意 ID 的依赖。#

  • 在高分辨率空间任务 (Visium HD) 中，在小尺寸 crops 中观察到的 foundation models 的 zero-shot 优势在扩展到 full-slide tiling 时往往会减弱。
  • Cross-section niche retrieval 需要在不同 slices 之间保持一致的坐标含义，以避免产生伪结果。
  • Behavior Cloning (BC) 是一种强大的 pre-training 工具，但如果 policy 变得过于 peaked，可能会导致“exploration dead-ends”；进行 temperature smoothing 或 entropy adjustment 是必不可少的。
  • 对于 discrete planning 问题，Feature engineering 的质量（如消除 ID 依赖、添加 action-effect states）比单纯增加 model parameter count 是更有效的杠杆。
