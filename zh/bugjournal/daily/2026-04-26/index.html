修复了 Linux 上的 Tauri 开发环境，并尝试将功能分支与上游 v0.11.1 同步，过程中遇到 29 次合并冲突

任务#

架构与策略#

  • ❌ 将 feat/fast-mode-support 分支同步到 v0.11.1 — 将 origin/main（v0.11.1）合并到功能分支，但在 Rust、TypeScript、Svelte 和配置文件中遇到 29 次合并冲突

实施与修复#

  • ✅ 修复 Linux 上的 Tauri 开发环境 — 解决了缺失 node_modules 和原生绑定问题，使 npm run tauri dev 能在 Linux 上运行

问题与解决方案#

关键问题#

1. 功能分支停留在 v0.10.6，而 main 已推进到 v0.11.1#

解决方案： 执行 git fetch origin && git stash && git merge origin/main，导致 29 次合并冲突需手动解决

关键洞察： 长期存在的功能分支会积累大量差异；定期 rebasing 可避免大量冲突

一般问题#

2. Linux x64 版本缺失 @tauri-apps/cli native binding（cli.linux-x64-gnu.node）#

解决方案： 删除 node_modules 和 package-lock.json，重新安装以获取正确的平台特定二进制文件

关键洞察： 在 NTFS 分区进行跨平台开发会导致 Windows 二进制文件被缓存；干净安装可获取正确的 Linux 原生模块

3. npm run tauri dev 失败，出现 “tauri: not found” 错误#

解决方案： 执行 npm install 以填充 node_modules 中的 Tauri CLI 依赖项

关键洞察： 缺少基本环境设置步骤——node_modules 目录不存在
