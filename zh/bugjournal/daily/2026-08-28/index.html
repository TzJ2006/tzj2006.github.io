经验教训#

关键经验#

  • 对于低位量化，‘激活部分的其余部分’环境（16位 vs 8位）是成功的关键决定因素；4-bit 投影仅在高精度邻居环境（16位）中能够存活。
  • SpinQuant 旋转对于模型精度并非必需，但在使用全图低位量化时，它是解决残差流中量化噪声的必要方法。
  • 将 VLM 输入分割成小的、经过验证的片段，可以将“推理标记”减少一个数量级（从 15-20k 减少到 <1k），同时不牺牲语义准确性。

实际经验#

  • DCC 登录节点使用 DNS 轮转机制，意味着必须为每个主机（01-05）显式执行脚本，而不是依赖单一的 SSH 连接。
  • Claude Code 在 Windows 上的 ProxyCommand 实现需要 PATH 中可用的 POSIX 风格 shell（sh），并且对远程 bash 脚本的 MSYS 路径转换非常敏感。
