Problems & Solutions#

Critical Issues#

1. RecoverBench 论文 claim 与实际使用的训练数据之间存在差异。#

Solution: 进行了系统的 agentic audit，将 claim 与 cluster 上的实际文件进行映射。

Key Insight: 发现 recovery corpus 和模型使用的 data subsets 与 v10 中声称的不符。

2. ResNet shortcut 实现使用了 projection convolutions 而非要求的 identity shortcut。#

Solution: 重构了 ResNet 类以实现 Option A (identity shortcut)，并重新训练模型达到了 92.00% 的 accuracy。

3. OmniJev M2 执行速度极慢（每个 episode 需要 35-80 分钟）。#

Solution: 发现 Conv3d patch embedding 使用了缓慢的 torch 实现；将其替换为等效的 linear layer。

Key Insight: 发现 97% 的时间都消耗在一个低效的 embedding layer 上，修复后将时间缩短至每个 episode 1-2 分钟。

4. L1 regularization 被应用到了错误的 model instance（训练的是旧模型而非经过 L1 修改的模型）。#

Solution: 修正了 notebook 代码，以确保在 training call 期间使用的是特定的 L1-modified model instance。

Learnings#

Key Learnings#

  • 在 multimodal agents 中，“Event Memory”（记住视频流中特定交互发生的时间）是一种与简单识别截然不同的、关键的 failure mode。
  • L1 regularization 促进了 weight sparsity（92.45% 接近于零），但在这种特定的 optimization regime 下，与 L2 相比可能会导致较低的 accuracy。

Practical Learnings#

  • 对于 CIFAR-10 上的 SimpleNN/ResNet-20 等小模型，CPU data loading bottlenecks 比 GPU compute throughput 更显著。
