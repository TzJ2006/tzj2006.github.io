关键问题#

1. STAIG 报告的 0.68 ARI 不可复制，依赖于 mclust 初始化种子；scGPT/TEDDY 嵌入在空间聚类中表现不佳。#

关键洞察： 发布的随机算法基准测试需要统计验证；通用基因编码器可能不适合空间领域的图对比学习。

2. ccusage 20.x 统一输出合并了所有代理源，丢失了双轨报告所需的按源粒度。#

解决方案： 发现 ccusage <source> daily 允许命名空间查询。通过元数据实现按源文件发现，并采用模式规范化进行单独获取，确保向后兼容和未来的可扩展性。

关键洞察： CLI 依赖升级往往会悄悄改变 JSON 模式；在架构变更前立即进行新输出格式的本地测试至关重要。

3. 桌面视频图库缩略图空白是由于沙箱书签范围不匹配和缓存键缺失所致。解决方案： 实现了双分支书签解析（范围限定 + 备用方案），并更新了缓存键以包含内容修改日期。在 SwiftUI 视图中添加了同步状态初始化，以防止导航过程中出现闪烁现象。#

关键洞察： 异步失败常常会破坏状态机；沙箱化的 macOS 应用需要明确的非范围限定备用方案，以确保旧数据的完整性。

4. NVIDIA RTX 5090 驱动程序因安全启动拒绝自签名 DKMS 模块而失败。#

解决方案： 移除 nvidia-dkms 包，加载 Canonical 预签核文件模块，在不禁用安全启动的情况下解决了“密钥被拒绝”错误。

关键洞察： 在启用安全启动的现代 Ubuntu 系统中，由发行版管理的签名模块比自定义 DKMS 构建更安全、更可靠。

5. Vite dev-server 在 NTFS 挂载驱动器上无法加载 FloatBall CSS 模块，原因是 .vite-temp 缓存失效。#

解决方案： 停止 dev 服务器，清除 node_modules/.vite 和 .vite-temp，然后重新启动。根本原因是 Vite 在不稳定的 FUSE 挂载上的原子重命名失败。

关键洞察： Vite 的依赖优化对文件系统稳定性非常敏感；失效的临时文件会导致懒加载组件中的模块图不同步。

6. 历史视图在不同屏幕上显示相同的列表，原因是全局过滤和缺少屏幕归属信息。#

解决方案： 重构数据模型，在 WallpaperHistoryEntry 中加入“播放过屏幕”映射。为没有屏幕 ID 的旧项目实现按屏幕划分的清理和迁移逻辑。

关键洞察： 全局数据结构无法支持多租户或多显示器环境；模式迁移必须明确处理向后兼容性和维度限制。

7. 安全漏洞：在 ccusage 迁移过程中，工作流钩子豁免检查和使用文件保存时可能存在路径遍历风险。#

解决方案： 在 check_spec.py 中标记豁免绕过行为（需要规范路径解析），并建议对 save_usage_file 文件名清理实施多重防御措施，尽管上游 ccusage 验证已经提供了缓解措施。

关键洞察： 基于字符串的路径检查 startswith 容易受到遍历攻击；外部工具的退出码不应成为文件系统操作的唯一安全屏障。
