问题与解决方案#

关键问题#

1. 由于包含无效配置（k!=GT），聚类指标中存在极端的 ARI 差异（最差约 0.01 对比最佳约 0.56）。#

解决方案： 仅保留 ‘hit_k=True’ 配置进行筛选，从而修正统计范围并稳定方差指标。

关键洞察： 严格遵循超参数约束（如 k=GT）对于聚类评估中的有效统计范围至关重要；包含无效状态会人为扩大方差。

2. mclust ARI 得分低于预期，原因是意外将 PCA-50 应用于低维嵌入。#

解决方案： 将 load_emb 改为默认 pca_dim=None，恢复真实信号，并显示当输入合理时 mclust 性能与 Leiden 相当。

关键洞察： 辅助函数中的隐含降维可能导致隐性 ARI 下降；输入维度必须与标准流程严格匹配。

3. Cosmos3-Nano 定位坐标在渲染叠加图中错位，原因是图像尺寸不匹配（模型期望 608x480，视频提供 256x256）。#

解决方案： 确定尺寸不匹配为根本原因，建议进行坐标归一化或输入放大以用于后续验证。

关键洞察： 多模态模型如果没有明确提供尺寸信息，可能会产生幻觉；仅依赖模型报告的大小而不进行验证会导致渲染错误。

一般问题#

4. 自动化的 git 钩子会提交生成的加密 HTML 文件，污染代码库历史记录。#

解决方案： 移除带有 git rm --cached 的跟踪文件，更新 .gitignore，修改提交信息以保持历史干净。

关键洞察： 必须明确忽略生成的资产，以防止文件膨胀和意外暴露临时配置。

5. SSH 登录失败尽管配置正确；本地公共密钥未在远程服务器上注册。#

解决方案： 确定缺少远程公共密钥为原因，任务被阻塞等待管理员干预。

关键洞察： 当基于密钥的认证失败时，在修改本地身份之前，请先验证服务器上的对应公共密钥是否存在。

经验教训#

关键经验#

  • 在聚合聚类指标时，始终过滤掉违反结构约束的配置（k=GT），然后再计算最坏情况，以防止人为方差膨胀。
  • Cosmos3-Nano 支持结构化的 2D/3D 点定位，但在低分辨率下缺乏像素级的空间精度，需要明确的图像尺寸上下文或放大处理。
  • 在设计异构代码库的迁移工具时，默认使用“模拟运行”输出迁移清单非常重要，因为跨生态系统的导入重写容易出错。

实际经验#

  • StatiCrypt 为 GitHub Pages 上的静态网站提供了强大的客户端 AES-256 加密，确保秘密信息不会泄露，同时允许公众访问。
  • 机器人领域的动态视觉指令需要时间上下文；静态单帧分析不足以保证轨迹生成的准确性。
