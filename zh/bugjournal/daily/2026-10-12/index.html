Learnings#

Key Learnings#

  • 在 camera-ready 修订中，将 ‘Changes since submission’ 作为正式章节比尝试将修正描述为 ‘improvements’ 更为稳妥。
  • 有效的学术社交在于提出一个定义明确的研究问题，从而邀请他人贡献其专业知识，而不仅仅是请求帮助。
  • 与 ‘pause’ 模式相比，’non-pause’（连续）机器人执行模式会显著降低成功率，这凸显了对快速、高精度 local judges (JEV) 的需求。
  • Rotation (SpinQuant) 有效降低了 VE outlier 的量级，但并未解决深层网络中 4-bit per-tensor weight quantization 的累积误差问题。
  • 与 launcher 的原始 token 估计相比，Gemini 3.1 Pro 的 ’thinking tokens’ 显著增加了实际的 proxy 成本。

Practical Learnings#

  • 路径规范化（例如 macOS 上的 /private/var 或 Windows 上的 8.3 names）对于项目管理工具中的跨平台分组逻辑至关重要。
