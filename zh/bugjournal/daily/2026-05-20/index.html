问题与解决方案#

关键问题#

1. AGENTS.md 声称钩子执行“验证 + 审查”，但 .claude/settings.json 仅触发验证，导致审查生成未被强制执行。#

2. 直接运行 python workflow/verify.py 导致导入错误，从兄弟仓库 D:\GitHub\gadget 而非 TokenMonitor 拉取代码。#

解决方案： 切换至 python -m workflow.verify，该版本能在 TokenMonitor 上下文中正确解析模块。

关键洞察： 如果未通过虚拟环境或严格的路径隔离管理，具有相同包结构的兄弟仓库存在隐蔽的导入劫持风险。

一般问题#

3. 文档声称 python workflow/active_spec.py 会生成规范，但它是个不会产生副作用的库文件。#
