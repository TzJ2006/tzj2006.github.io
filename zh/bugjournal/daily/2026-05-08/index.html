关键问题#

1. 在 AI 分析日志中发现了 AdaptVision README.md 中的硬编码 API 密钥。#

解决方案： 立即进行修复。AI 指出密钥在输出中可见，建议将其移除并替换为环境变量占位符或 .env 文件方式。

一般问题#

2. 在 ‘tianhe’ 设备上，命令 ‘rg’ (ripgrep) 因 ‘bwrap: Failed to make / slave: Permission denied’ 和环境限制而失败。#

解决方案： 放弃 ripgrep，改用 find、sed 和 grep 等标准 POSIX 工具。使用 sed 手动分割文件读取，以绕过输出令牌限制或命令失败问题。

关键洞察： AI 助手可能默认使用高效工具如 rg；在受限 HPC 环境中，人类必须引导回稳健但冗长的标准 Shell 工具。
