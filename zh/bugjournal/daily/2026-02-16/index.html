关键洞察： 架构压缩限制会悄悄引发表示失败；参数化的消融能力必须在战略融合扩展之前实施。

2. 标准流匹配架构在潜在多模态融合方面数学上不适用，因为缺乏固定的目标分布。#

解决方案： 得出结论，生成式映射在融合空间中缺乏必要的监督信号；转向基于关系的方法（AdaLN、对比学习）和基于配置的集成结构。

关键洞察： 融合需要关系对齐目标，而非生成式重建目标；理论上的不匹配决定了设计早期的架构策略调整。

3. 并发 GPU 工作负载导致 OOM 失败和静默缓存，掩盖了实时基准测试进展和资源竞争。#

解决方案： 使用 --override 标志强制顺序 GPU 执行，实现了延迟空间偏差评估以抑制内存峰值，并利用透明输出流实现可靠监控。

关键洞察： 在共享 HPC 环境中，资源隔离和明确的状态覆盖机制是必需的；静默的后台失败会降低验证完整性，需主动管理。

4. VLA 服务器初始化因 OpenPI API 不匹配和扁平/层次化键冲突而失败，导致图像管道无法到达策略模型。#

解决方案： 用 create_trained_policy 替换自定义 norm_stats 处理；在策略适配器中注入明确的 IMAGE_KEY_MAP 重映射，以使 robosuite 输出与 LiberoInputs 模式一致。
