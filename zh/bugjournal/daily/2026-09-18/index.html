Critical Issues#

1. W4A4 在 ‘open the middle drawer’ 任务中失败（成功率为 0/50），原因是任务混淆。#

Solution: 确定了 17-35 MLP-side RMSNorm outputs 中存在 4-bit quantization noise。对这些特定的 tensors 应用了 per-tensor optimal clipping，将成功率恢复至 98%，同时保持统一的 A4 bitwidth 以确保硬件兼容性。

Key Insight: 该错误是由 RMSNorm outputs 中宽动态范围驱动的，在 min-max quantization 中会浪费分辨率；optimal clipping 将 16 个 levels 重新集中在分布质量中心。

2. 如果 AI 生成完整解决方案或遗漏隐藏指令，可能会违反学术诚信。#

Solution: AI 通过识别政策限制主动拒绝生成完整解决方案；执行了针对 1pt font text 的程序化扫描以验证 PDF 安全性。

3. Gemini 在 memory 任务中输出冗余的 ‘rings’ 或 ‘phantom’ badges（在发生前进行计数）。#

Solution: 实现了一个带有严格时间指令的 ‘v4’ minimalist prompt，并开发了层次化评分脚本来隔离错误类型。

Key Insight: 通过移除 ‘action planning’ 指令来减轻认知负荷，使模型能够纯粹专注于 ‘state perception’。

4. ‘memory’ 机制可能会传播或 ‘锁定’ 错误的初始选择。#

Solution: 修改了 prompt，强调 memory 是引导而非 ground truth，明确允许模型根据新的视觉证据“纠正早期的错误”。

AI Limitations#

Critical Limitations#

  • “chained memory”方法容易受到“error cascades”的影响，即初始错误会被维持，因为模型缺乏重新评估完整历史的机制。
  • 模型在区分相似动作（push vs. hook）时的准确性严重依赖于 prompt 中 demonstration frames 的密度。
  • shared volumes 上的 Disk space volatility 要求对 11GB temporary buffers 进行仔细管理以防止崩溃。

General Limitations#

  • “Uniform-A4”候选方案在抓取 handle 时仍显示出一次失败，表明其 execution stability 略低于 float/W4A8。
  • 最初关于 W4A4 失败（command confusion）的 AI hypothesis 在 ablation studies 之前缺乏定量支持。
  • AI 对隐藏文本的 scan 仅限于 PDF 文件，未涵盖相关的 .ipynb 或 .zip 文件。

Learnings#

Key Learnings#

  • 在 quantization 中，“error”可以是 decision failure（错误的任务）或 precision failure（错误的动作）；必须分别进行测量。
  • Instructors 可能会使用 1pt font 的“invisible”文本向 AI agents 传达 policies 或 warnings。
  • 使用 chained memory 时，Stability（防止 flickering）与 Accuracy（纠正错误）之间存在直接的张力；“don’t change it”规则提高了 stability 但扼杀了 correction。
  • Error scoring 必须是细粒度的；如果 0% 的 success rate 实际上是被冗余 marking errors 掩盖的 100% localization accuracy，那么该指标会产生误导。
  • 在 memory 中传递 raw coordinates 会导致“stale”的指向；必须明确告知模型即使目标相同也要进行“re-locate”。
  • 任务切换（例如 Middle vs Top drawer）的“error threshold”大约为 1.0-1.5cm；将 quantization noise 降低到此阈值以下至关重要。
