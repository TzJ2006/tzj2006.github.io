问题与解决方案#

关键问题#

1. 桌面视频应用在启动时显示两个窗口，在壁纸导航期间出现 CPU 波动。#

解决方案： 通过从 SwiftUI Scenes 中移除 WindowGroup 并完全依赖 AppDelegate 解决了双窗口问题。通过限制缩略图实例化为可见 tiles 和添加缓存重用来优化性能。

关键洞察： 混合使用 SwiftUI WindowScene 和手动 NSWindow 管理会导致竞争条件。对于大型数据集，SwiftUI 的 ForEach 会创建所有视图；需要延迟加载或明确限制。

2. RoboCasa 错误恢复基准测试（咖啡任务）中 0% 成功率，尽管文件数量充足；最初认为策略较弱的假设是错误的。#

解决方案： 诊断出根本原因是训练不完整（5000/10000 步）和未验证的增强数据。得出结论：文件存在并不保证模拟有效性，需要重新生成高质量增强数据。

关键洞察： 均匀的 0% 失败率通常表明系统错误（加载/归一化）或基础设施问题，而非模型弱点；在重新训练前务必验证基础设施。

3. 由于默认超参数，Leiden 聚类最初比 mclust 低约 8 ARI 点。#

解决方案： 对 n_neighbors、度量标准和分辨率进行了联合网格搜索。确定 n_neighbors 是主要影响因素；优化后 Leiden 性能可与 mclust 相当或超越。

关键洞察： Leiden 对 n_neighbors 非常敏感；默认值很少最优。锁定 k=ground truth 可以公平比较，但引入预言选择偏差，导致 ARI 上升。

4. RoboCasa 检查点可用性和 OpenPI 评估脚本与现代包装器兼容性存在模糊性。#

解决方案： 确定 changyeon/pi05_robocasa_as50_jax 是一个可行的社区检查点。发现 OpenPI 客户端评估逻辑中存在结构错误，无法直接部署，需修补后测试。

关键洞察： 官方资源通常不足以进行基准测试；需要补充结构修复。部署策略必须包含指向第三方或自定义转换权重文件的路径。

常见问题#### 5. 被玻璃效果遮住的侧边栏控制项；初始的安全区域修复隐藏了内容。#

解决方案： 通过将 .background 与 .ignoresSafeArea 应用于容器视图而非内容，从而修正层叠问题，保持子视图的可见性。

关键洞察： glassEffect 可以创建独立的渲染上下文；标准的背景扩展方式更利于保持 z-顺序的完整性。

6. 在 CLI 烟雾测试期间，AWS 配置最初出现“未找到工作空间 ID”错误。#

解决方案： 在本地配置中添加了特定的 ANTHROPIC_AWS_WORKSPACE_ID，并通过 claude auth status 验证。提供程序模式与 Bedrock 不同，需要明确的工作空间范围。

关键洞察： AWS 提供程序需要明确的工作空间范围，这与标准的 Bedrock 或全局 Anthropic API 调用不同。

  • AI 最初假设“分辨率”是一个固定参数，没有意识到锁定 k 会导致平台内的分辨率变化，这严重影响了结果。
  • AI 根据部分代码检查错误将 ‘aug_*’ 文件视为弱验证，直到通过更深入的 grep 分析才纠正。
  • 针对双窗口错误的初步提案是“临时解决方案”，表明对 macOS 窗口用户体验细节缺乏深入理解，与用户的架构方法相比差距很大。

一般局限#

  • 在提供程序迁移过程中，诊断命令无限挂起以验证 AWS 连接性，表明在特定环境约束下工具执行存在超时死锁。
  • 沙箱限制阻止 AI 直接在 Athena/HPC 上执行必要的 SSH 环境探测，迫使进行服务器端工作。
  • 研究流程在读取多兆字节的后台任务记录时最初遇到输出截断问题，需要偏移读取才能获取完整结果。

经验教训#

关键经验#

  • 在空间转录组聚类中，‘n_neighbors’ 通常是 Leiden 最关键的超参数，比分辨率或种子更重要；最优值因部分而异。
  • MIHD 的 staig_fusion 模型崩溃是编码路径管道中的实现特定错误，而非底层 STAIG 算法的限制。
  • SwiftUI WindowGroup 和 AppDelegate 手动窗口创建存在冲突，最佳做法是为每个应用选择一种管理方式。
  • 比较 mclust 与 Leiden 需要严格控制 k 值。允许自由选择 k 更利于 Leiden 的灵活性；锁定 k=7 可以公平比较，但如果与真实值相比则引入预测选择偏差。
  • 在部署 GR00T 和 OpenPI 等复杂模型时，验证精确的版本标签（如 n1.6.1-release）非常重要，因为上游重构往往会破坏旧评估脚本。

实际经验#

  • 跨设备上下文切换需要严格记录项目状态； CLAUDE.md 是维持 AI 会话之间架构一致性的关键接口。
  • 在聚类循环之前使用 mKDTree 索引进行空间细化可以大幅减少迭代网格搜索的计算时间，减少 O(N²)。
