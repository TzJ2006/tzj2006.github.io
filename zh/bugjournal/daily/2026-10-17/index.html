Problems & Solutions#

Critical Issues#

1. WeChat Agent 中存在未经授权的 host 访问或身份冒用的风险。#

Solution: 通过稳定的内部 wxid 实施身份验证，对 cloud models 进行严格的 CLI 隔离，并设置了多层 command dispatch guards。

2. Arm C (27B) 在 RouteStick 和 VideoRepick 等协调任务中失败。#

Solution: 实施了 ‘one-shot’ opening calls 和 JEV (judge) 机制，仅在特定的视觉线索出现时才推进窗口。

3. 论文草案感觉更像是技术日志/自我审计，而不是高影响力的会议投稿。#

Solution: 应用 ‘Press-Release Principle’：围绕核心优势重构叙述，并删除了防御性、过度详细的语言。

4. 在没有显式 memory modules 的情况下理解 SimpleMemVLA 中的视觉记忆传递。#

Solution: 确定了文本 ‘sub-task’ 起到了语义瓶颈/桥梁的作用，允许 action head 使用 VLM hidden states 作为 conditioning signals。

5. NCL 100-seed 训练任务的 GPU 队列过长。#

Solution: 提交了一个带有自动化 ‘yield’ guard 的 ‘scavenger-gpu’ 阵列，在不重复工作的情况下将提前完成的机会增加了一倍。

6. WeChat 任务队列中的 race conditions 以及令人困惑的 UI 术语。#

Solution: 为状态转换添加了 10 多个 regression tests，并将所有技术后端状态映射为人类可读的对话式语言。

7. Figure 5 (a) ‘State Displacement’ 中由模拟器时间引起的统计偏差。#

Solution: 在排除时间分量后，重新计算了六个任务的 Spearman correlation；确认了显著的负相关（ρ = −0.264, p = 0.0019）并更新了论文。

General Issues#

8. 展示中关于 ‘Injected’ 与 ‘Measured’ latency 的混淆。#

Solution: 使用 ‘Pause/Play’ 类比进行澄清：Injected 是感知的模拟延迟；Measured 是实际的硬件延迟。

Difference Analysis: Human 专注于高层级的叙事、易用性和战略结果，而 AI 专注于细粒度、可辩护的技术报告。

AI Limitations#

Critical Limitations- AI 在实时 UI testing (WeChat) 中面临困难，并且在没有人工验证或更高级别 sandboxing 的情况下，难以证明 CLI/filesystem isolation。#

  • AI 在应对 Windows 特有的技术障碍时表现挣扎，例如由于 WDDM 行为导致无法解析未命名的 NVIDIA GPU PIDs。

General Limitations#

  • AI 难以维持“新闻发布会”式的语气，且在没有明确负面约束或 prompting 的情况下，难以弥合技术 backend 状态与人类可读 UI 之间的鸿沟。
  • AI 在预测实验结果（latency tests）或在没有人工引导审计的情况下自主识别特定的 media recognition 失败方面能力有限。

Learnings#

Key Learnings#

  • 基于 Concat 的 fusion 非常容易受到高方差模态（如 images）的“modality dominance”影响，即使这些模态对于特定任务并无信息量。
  • 在 robot learning 中，战略性的“分工”（VLM 用于 reasoning，Code 用于 execution）可以弥合 SOTA 与 ground-truth 性能之间的差距。
  • SimpleMemVLA 的成功源于利用了预训练 VLM 的 video-native 能力和基于 text 的 memory bridging 机制，而非新的 architecture。
  • 可靠的 automation 需要一个多层“guard”系统（UI prep、dispatch 和 execution）以及在 data-level receipt 与 UI-level response 之间进行清晰区分。
  • 双层配置（Global Mode + Individual Toggle）对于防止复杂消息处理系统中的意外操作至关重要。
