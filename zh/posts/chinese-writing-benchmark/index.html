同一条 prompt，58 个模型各写一遍，按调用工具分组。英文版是另一次独立实验，不是本页翻译。

请用中文写一个约500字的小说开头，以一位在战争爆炸中失去一条腿的芭蕾舞演员为主角，通过描写她在战后生活来侧面体现出她的挣扎。

条件：每个模型只跑 1 次，无 system prompt，数字按量级读。云端模型经各自的 Agent CLI （codex exec / claude -p / cursor-agent --print）在空目录中串行调用，耗时含 CLI 启动； 本地模型在 RTX 5090 上冷启动，速度为纯解码速度，两类速度不可互比。 Fable 5.1 显式 --effort high，其余 Claude 模型为默认 effort。 「直接点题的词」匹配 挣扎、痛苦不堪、内心的煎熬、无法接受——题目要求侧面体现，命中即正面点题。
