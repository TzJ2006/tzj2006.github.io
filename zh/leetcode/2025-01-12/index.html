LeetCode Daily Question 2025-01-12

2025年1月11日 · 2 分钟

Today’s Problem#

https://leetcode.com/problems/check-if-a-parentheses-string-can-be-valid/

Solution Approach#

为了构建一个有效的括号字符串，需要为每个 ‘)’ 在左侧找到一个对应的 ‘(’，并为每个 ‘(’ 在右侧找到一个对应的 ‘)’。 当我们从左向右遍历时，可以先满足第一个条件。

当遇到 ‘)’ 时，有三种方式将其与 ‘(’ 匹配：第一，使用一个现有的 ‘(’；第二，寻找一个 unlocked 的 ‘)’；或者第三，如果 ‘)’ 本身是 unlocked 的，它可以被转换为 ‘(’。

假设我们已经为所有的 ‘)’ 找到了匹配的 ‘(’，那么我们需要为剩余的 ‘(’ 找到对应的 ‘)’。此时，唯一的办法是寻找一个 unlocked 的括号，因为所有的 ‘)’ 都已经被匹配过了。

Solution Scheme#

首先，如果字符串长度为奇数，它永远无法形成有效的括号字符串，因此直接 return False。

维护两个数组：anyBracketanyBracket 存储所有 unlocked 括号的索引，openBracketopenBracket 存储所有 ‘(’ 的索引。

从左到右遍历整个字符串，会遇到以下情况：

  1. 当前字符是一个 unlocked 括号：将其索引压入 anyBracketanyBracket 栈中。
  2. 当前字符是 ‘(’：将其索引压入 openBracketopenBracket 栈中。
  3. 当前字符是 ‘)’：需要为其寻找一个 ‘(’。
    • 优先从 openBracketopenBracket 栈中弹出一个 ‘(’，这同时也完成了为该 ‘(’ 寻找 ‘)’ 的任务。
    • 如果 openBracketopenBracket 栈为空，则从 anyBracketanyBracket 栈中取出一个 unlocked 括号（作为 ‘(’ 使用）。
    • 如果两个栈都为空，那么 return False，因为无法为当前的 ‘)’ 找到匹配的 ‘(’。

遍历结束后，openBracketopenBracket 中可能仍有未匹配的 ‘(’。

此时，遍历 openBracketopenBracket 中的每个未匹配 ‘(’，并检查 anyBracketanyBracket 中是否存在索引更大的括号（即位于其右侧的 unlocked 括号）。

  • 如果存在，意味着已经成功为其找到了一个 ‘)’，匹配成功！
  • 否则，无法进行匹配，return False。

如果 anyBracketanyBracket 中剩余元素的数量为偶数（由于之前进行了奇偶校验，这里必然成立），那么 return True，任务完成！

Important Tips#

  • 为什么 openBracketopenBracket 和 anyBracketanyBracket 都使用 stacks？
  • 因为 ‘)’ 总是优先与左侧最近的 ‘(’ 进行匹配，因此需要一个 Last-In-First-Out (LIFO) 数据结构来获取“最近的元素”。

Complexity Analysis#

  • Time Complexity: O(N)O(N)，其中 N 是字符串的长度。

  • Space Complexity: O(N)O(N)，用于存储括号的索引。

Code#

class Solution:
    def canBeValid(self, s: str, locked: str) -> bool:
        if len(s) % 2 == 1:
            return False
        
        openBracket = []
        anyBracket = []

        for i in range(len(s)):
            if locked[i] == '0':
                anyBracket.append(i)
            else:
                if s[i] == '(':
                    openBracket.append(i)
                else:
                    if len(openBracket) > 0:
                        openBracket.pop()
                    elif len(anyBracket) > 0:
                        anyBracket.pop()
                    else:
                        return False
        
        if len(anyBracket) < len(openBracket):
            return False

        idx = len(anyBracket) - 1
        for i in range(len(openBracket) - 1, -1, -1):
            if anyBracket[idx] < openBracket[i]:
                return False
            idx -= 1
        
        return idx % 2 == 1
