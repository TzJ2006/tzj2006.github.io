3355. Zero Array Transformation I 的解法
2025年5月20日 · 1 分钟

Today’s problem#

https://leetcode.com/problems/zero-array-transformation-i/

Intuition#

这个问题意味着对于每个 query，需要将范围 (l, r) 内的一个元素减 1。 为了处理范围的变化，我们可以考虑 prefix sum。 注意题目中说的是 “Select a subset of indices”，这意味着我们并不一定需要将范围内的所有索引都减 1。 在这种情况下，因为我们只关心最终的 array 是否为 zero array，所以与其测试最终的 array 是否为零，不如测试最终的 array 是否小于或等于零，这是因为题目中提到的 subset。

Approach#

对于每个 query，我们可以在 difference array 的 l 位置加 1，在 r + 1 位置加 -1。 然后当我们计算最终答案时，可以使用 prefix sum 将它们累加起来，得到 array 的变化。 最后，当我们想要知道最终的 array 是否为 zero array 时，我们可以将 difference array 加到 original array 上，并测试每个索引是否小于或等于零，从而得到答案。

Complexity#

  • Time complexity:

O(N+M)O(N + M)，N 是 original array 的长度，M 是 query 的长度。

  • Space complexity:

O(N)O(N).

Code#

class Solution:
    def isZeroArray(self, nums: List[int], queries: List[List[int]]) -> bool:
        diff = [0] * (len(nums) + 1)
        for l, r in queries:  
            diff[l] -= 1
            diff[r + 1] += 1
        
        for i in range(len(nums)):
            if i > 0:
                diff[i] += diff[i-1]
            if nums[i] + diff[i] > 0:
                # print(i, nums[i], diff[i])
                return False
        
        return True
