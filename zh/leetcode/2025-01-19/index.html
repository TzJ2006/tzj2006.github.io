407. Trapping Rain Water II 的解题思路
2025年1月19日 · 1 分钟

Today’s Problem#

https://leetcode.com/problems/trapping-rain-water-ii/description/

Idea#

在 yesterday’s problem 中，我们讨论了在什么情况下应该考虑使用 graph theory 方法来解决问题。

现在我们可以将这一标准应用于本题：在本题中，水可以向四个方向流动，这意味着存在后效性（对后续状态的依赖）。

因此，我们需要采用 graph theory 方法。

每个 cell 可以储存多少水取决于它与其最低邻居之间的高度差（类似于心理学课上常见的“木桶效应”——木桶的容量由其最短的木板决定）。

需要注意的是，水墙本身也可以作为墙壁参与高度计算。

为了知道墙的高度，我们首先需要生成一堵墙。但墙在哪里呢？

最自然的思路是将网格的最外层边界作为初始墙（就像 Example 2 中的情况，使用最外层边界来储存水）。

然后我们找到墙上的最低点，并向内扩展新的墙。也就是说，如果一个内部邻居比当前墙上的点高，那么该邻居就成为新墙的一部分；否则，该内部点可以储存水，且水位高度将与当前墙上的点相同，从而形成一个水墙。

由于我们总是选择墙上的最低点，墙上所有其他部分的高度都不会低于该点，这意味着当前墙的高度是内部可以储存水的上限。

Method#

这里可以使用 priority queue 来高效地找到墙上的最低点。

然后按照上述算法执行：

  1. 创建初始墙

  2. 循环：

    1. 找到墙上的最低点

    2. 生成一个新的物理墙或水墙

  3. 结束循环

  4. 累加所有水墙的额外高度

Complexity#

  • Time complexity: O(NM×log(NM))O(NM\times log(NM))

  • Space complexity: O(NM)O(NM)

Code#

class Solution:
    def trapRainWater(self, heightMap: List[List[int]]) -> int:
        if len(heightMap) < 3 or len(heightMap[0]) < 3:
            return 0
        
        dx = [0,0,1,-1]
        dy = [1,-1,0,0]
        vis = []
        n, m = len(heightMap), len(heightMap[0])
        q = []
        for i in range(n):
            heappush(q, (heightMap[i][0], i, 0))
            heappush(q, (heightMap[i][-1], i, m - 1))
            vis.append((i, 0))
            vis.append((i, m-1))
        for i in range(1, m - 1):
            heappush(q, (heightMap[0][i], 0, i))
            heappush(q, (heightMap[-1][i], n - 1, i))
            vis.append((0, i))
            vis.append((n-1, i))
        
        vis = set(vis)
        ans = 0

        while len(q) > 0:
            h, x, y = heappop(q)
            for i in range(4):
                nx, ny = x + dx[i], y + dy[i]
                if nx < 0 or ny < 0 or nx >= n or ny >= m or (nx,ny) in vis:
                    continue
                if heightMap[nx][ny] < h:
                    ans += h - heightMap[nx][ny]
                heappush(q, (max(h, heightMap[nx][ny]), nx, ny))
                vis.add((nx, ny))
        return ans
