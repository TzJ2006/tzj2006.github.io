2429. Minimize XOR 的解法
2025年1月15日 · 1 分钟

Today’s problem#

https://leetcode.com/problems/minimize-xor/description/

XOR#

这是 XORXOR 的 True-False Diagram： 在这个 diagram 中，我们可以发现如果 A 和 B 相同，那么 A XOR B=0A\space XOR\space B = 0；否则，A XOR B=1A\space XOR\space B = 1。

Intuition#

  • 对于问题中的第一个要求，“same number of set bits” 意味着 “数字中 bit 1 的数量相同”。

  • 为什么？这是因为一个数字中 0 的数量可以是无穷的，而只有 bit 1 的数量是有限的。

  • 因此，我们需要统计 number2 中有多少个 1。

  • 现在，基于 XORXOR Diagram 我们知道，为了在进行 XORXOR 操作后得到一个数字，我们需要在 number1 拥有 1 的相同位置放置一个 1，这样我们就可以在进行 XORXOR 后将其减小为 0。

  • 在这种情况下，我们希望从上到下“减少” 1s 以使结果最小化。

  • 如果 number2 中的 1 比 number1 中的 1 更多，我们就必须在结果中“添加”新的 1s。

  • 在这种情况下，我们希望从下到上“添加” 1s 以使结果最小化。

Approach#

  1. 使用 bitcount()bit_count() 函数来统计 num2 中的 1s。
  2. 从上到下迭代以减少 1。
  3. 从下到上迭代以添加 1。

Complexity#

  • Time complexity: O(log2(N))O(log_2(N))，N 代表该数字。

  • Space complexity: O(1)O(1)，仅存储了一些变量。

Code#

class Solution:
    def minimizeXor(self, num1: int, num2: int) -> int:
        cnt,ans = num2.bit_count(), 0
        for i in range(31, -1, -1):
            if cnt > 0 and (num1 & (1 << i)) > 0:
                ans += (1 << i)
                cnt -= 1
        
        for i in range(31):
            if cnt > 0 and (ans & (1 << i)) == 0:
                ans += (1 << i)
                cnt -= 1
        
        return ans
