LeetCode Daily Question 2025-01-18

1368. Minimum Cost to Make at Least One Valid Path in a Grid 的解法
2025年1月18日 · 2 分钟

Today’s problem#

https://leetcode.com/problems/minimum-cost-to-make-at-least-one-valid-path-in-a-grid/

Intuition#

思考这样一个问题：

这里有一个 graph，每条 edge 的值均为 1 或 0，你需要从点 0 行进到点 N，请问最短路径是多少？

在这种情况下，你会迅速想到 Dijkstra、SPFA 甚至 BFS 等 graph 算法。

但如果我告诉你，上面的问题与我们当前正在解决的问题完全一致呢？你能迅速想到该问题设定与这个更简单版本设定之间的转换吗？

现在，你们中有些人可能会认为这是一个 DP 问题：我们有一个 grid，也许可以写出一个 DP 公式…

但等等，DP 最重要的前提是无后效性。为了运行 DP，你必须确保不存在后效性。在我们的情境中，因为我们可能需要从右向左、从下向上移动，所以存在后效性。因此，我们不能在这个问题中使用 DP。

Approach#

现在，为了将我们的问题转化为上述问题，我们只需要遍历 graph，并在一个点与其邻居之间创建一条 edge；如果该邻居是它所指向的邻居，则 edge 的值为 0，否则为 1。

你们中有些人可能会担心这个解法的正确性，因为还有一个限制条件是 “You can modify the sign on a cell one time only”。

然而，情况是，这个 graph 没有负权 edge，这意味着如果你经过更多的点，你的结果总会增加。因此，你甚至不会访问同一个点超过 1 次，所以你得到的解不可能对同一个 cell 的 sign 进行超过 1 次的修改。

现在，运行你的 Dijkstra（或其他 shortest path 算法），你就大功告成了！

Complexity#

  • Time complexity: O(N×M×log(N×M))O(N\times M\times log(N\times M))

  • Space complexity: O(N×M)O(N\times M)

Code#

class Solution:
    def minCost(self, grid: List[List[int]]) -> int:
        dx = [0,0,1,-1]
        dy = [1,-1,0,0]
        n,m = len(grid), len(grid[0])
        edges = [[] for i in range(n * m)]
        def cordinate2d21d(x,y):
            return x * m + y
        
        for i in range(len(grid)):
            for j in range(len(grid[0])):
                pos = cordinate2d21d(i, j)
                for idx in range(4):
                    nx = i + dx[idx]
                    ny = j + dy[idx]
                    if nx < 0 or ny < 0 or nx >= n or ny >= m:
                        continue
                    npos = cordinate2d21d(nx, ny)
                    if idx + 1 == grid[i][j]:
                        edges[pos].append([npos, 0])
                    else:
                        edges[pos].append([npos, 1])

        dis = [inf] * (n * m)
        dis[0] = 0
        q = [(0,0)]

        while q:
            d, x = heappop(q)
            for to, v in edges[x]:
                if d + v < dis[to]:
                    dis[to] = d + v
                    heappush(q, (dis[to], to))

        return dis[cordinate2d21d(n-1, m-1)]
