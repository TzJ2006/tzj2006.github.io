3068. Find the Maximum Sum of Node Values 的解法
2025年5月23日 · 4 分钟

Today’s problem#

3068. Find the Maximum Sum of Node Values

Important: 以下所有方法都基于这样一个事实：xor 偶数次等于 xor 零次。#

Method 1: Tree DP#

Intuition and Approach#

在这个问题中，如果我们只考虑一个方向，例如从 root 到 leaf，那么这个过程将不会有后效性（后续的决策不会影响之前的决策）。因此，我们可以使用 DP 来解决这个问题。

最困难的部分是 dp 的定义。由于我们有一个方向性的前提，定义 dp 公式的一个更好的方法是排除当前节点的影响。此外，对于每个节点，都有两种状态，如上所述，每个节点要么被 xor 奇数次，要么被 xor 偶数次。

因此，我们有了 DP 的定义。 dp[x][0/1]dp[x][0/1] 表示当节点 x 被改变 (1) 或未改变 (0) 时，x 的 children 所能达到的最大值。

现在，对于节点 x 的每个 child c，我们可以进行两种操作：要么对节点 x 和 c 都进行 xor，要么对 x 和 c 都不进行 xor。

这两种操作的 dp 公式将是： （注意：⊕\oplus 的优先级低于 ++，因此添加括号非常重要。）

  • 执行 xor 操作 dp[x][0]=max(dp[x][0]+dp[c][0]+nums[c],dp[x][0]+dp[c][1]+(nums[c]⊕k))dp[x][0] = max(dp[x][0] + dp[c][0] + nums[c], dp[x][0] + dp[c][1] + (nums[c] \oplus k)). dp[x][1]=max(dp[x][1]+dp[c][0]+nums[c],dp[x][1]+dp[c][1]+(nums[c]⊕k))dp[x][1] = max(dp[x][1] + dp[c][0] + nums[c], dp[x][1] + dp[c][1] + (nums[c] \oplus k)).
  • 不执行 xor 操作 dp[x][0]=max(dp[x][1]+dp[c][1]+nums[c],dp[x][1]+dp[c][0]+(nums[c]⊕k))dp[x][0] = max(dp[x][1] + dp[c][1] + nums[c], dp[x][1] + dp[c][0] + (nums[c] \oplus k)). dp[x][1]=max(dp[x][0]+dp[c][0]+nums[c],dp[x][0]+dp[c][0]+(nums[c]⊕k))dp[x][1] = max(dp[x][0] + dp[c][0] + nums[c], dp[x][0] + dp[c][0] + (nums[c] \oplus k)).

注意 dp[x][0] 和 dp[x][1] 应该同时更新。

此外，另一个重要的事情是 dp 数组的初始化。对于所有的 dp[x][1]dp[x][1]，我们会给它一个 −inf-inf 的值，这样可以避免当 c 是 leaf 节点且数字与 k 进行 ⊕\oplus 操作时对 dp[x]dp[x] 数组产生影响的情况。

最终结果将是 max((dp[0][0]+nums[0]),(dp[0][1]+(nums[0]k)))max((dp[0][0] + nums[0]), (dp[0][1] + (nums[0] ^ k)))

Complexity#

  • Time complexity: O(N)O(N)，N 是 nums 的长度。
  • Space complexity: O(N)O(N)，N 是 nums 的长度。

Code#

class Solution:
    def maximumValueSum(self, nums: List[int], k: int, edges: List[List[int]]) -> int:
        n = len(nums)
        dp = [[0 for _ in range(2)] for _ in range(n)]
        for i in range(n):
            dp[i][1] = -10_000_000_000
      
        edge = [[] for _ in range(n)]

        for x,y in edges:
            edge[x].append(y)
            edge[y].append(x)

        def dfs(x, fa):
            for to in edge[x]:
                if to == fa:
                    continue
                dfs(to, x)

                c0 = max(dp[to][0] + nums[to], dp[to][1] + (nums[to] ^ k))
                c1 = max(dp[to][0] + (nums[to] ^ k), dp[to][1] + nums[to])
                dp[x][0], dp[x][1] = max(dp[x][0] + c0, dp[x][1] + c1), max(dp[x][1] + c0, dp[x][0] + c1)
      
        dfs(0,-1)
        return max((dp[0][0] + nums[0]), (dp[0][1] + (nums[0] ^ k)))

Method 2: Tree DP with better memory#

Intuition and Approach#

在之前的代码中，我们发现 dp[x]dp[x] 只会被使用两次。一次是在计算 dp[x]dp[x] 的结果时，另一次是在计算 dp[fa]dp[fa] 的结果时。

因此，我们可以返回 dp[x][0]dp[x][0] 和 dp[x][1]dp[x][1] 的值，以避免 dp 数组带来的额外空间。

Complexity#

  • Time complexity: O(N)O(N)，N 是 nums 的长度。
  • Space complexity: O(1)O(1)。

Code#

class Solution:
    def maximumValueSum(self, nums: List[int], k: int, edges: List[List[int]]) -> int:
        n = len(nums)
        edge = [[] for _ in range(n)]

        for x,y in edges:
            edge[x].append(y)
            edge[y].append(x)

        def dfs(x, fa):
            dp0,dp1 = 0,-1e9
            for to in edge[x]:
                if to == fa:
                    continue
                c0, c1 = dfs(to, x)
                dp0, dp1 = max(dp0 + c0, dp1 + c1), max(dp0 + c1, dp1 + c0)
          
            return max(dp0 + nums[x], dp1 + (nums[x] ^ k)), max(dp0 + (nums[x] ^ k), dp1 + nums[x])
      
        return dfs(0,-1)[0]

Important: 以下所有方法都基于这样一个事实：在 tree 上两个节点之间总是有路径存在的。因此，我们可以 ⊕\oplus 这条路径上的所有节点，从而实现对 tree 上任意两个节点的 ⊕\oplus。#

Method 3: DP without tree#

Intuition and Approach#

对于每个节点，我们有两种状态，即是否 ⊕\oplus k。因此，DP 数组的定义为： dp[i][0/1]dp[i][0/1] 表示在遍历到第 i 个节点时，是否存在奇数 (1) 次或偶数 (0) 次 ⊕\oplus k 操作。

然后我们得到公式：

  • 当该节点 ⊕\oplus k 时： dp[i][0]=max(dp[i−1][0]+nums[i],dp[i−1][1]+(nums[i]k))dp[i][0] = max(dp[i-1][0] + nums[i], dp[i-1][1] + (nums[i] ^ k))
  • 当该节点不进行 ⊕\oplus k 时： dp[i][1]=max(dp[i−1][1]+nums[i],dp[i−1][0]+(nums[i]k))dp[i][1] = max(dp[i-1][1] + nums[i], dp[i-1][0] + (nums[i] ^ k))

注意，总会存在偶数次 ⊕\oplus 操作，所以答案将是 dp[n−1][0]dp[n-1][0]。

Complexity#

  • Time complexity: O(N)O(N)，N 是 nums 的长度。
  • Space complexity: O(N)O(N)，N 是 nums 的长度。

Code#

class Solution:
    def maximumValueSum(self, nums: List[int], k: int, edges: List[List[int]]) -> int:
        n = len(nums)
        dp = [[0 for _ in range(2)] for _ in range(n)]
        dp[0][0] = nums[0]
        dp[0][1] = (nums[0] ^ k)
        for i in range(1, n):
            dp[i][0] = max(dp[i-1][0] + nums[i], dp[i-1][1] + (nums[i] ^ k))
            dp[i][1] = max(dp[i-1][0] + (nums[i] ^ k), dp[i-1][1] + nums[i])
        return dp[-1][0]

Method 4: DP without tree with better memory#

Intuition and Approach#

与 Method 2 相同，我们也发现 dp[i] 公式只被使用两次。在这种情况下，我们可以使用两个变量而不是整个数组，以获得更好的内存利用率。

此外，python 中的 maxmax 操作太慢了，所以更好的方法是使用 if else 语句而不是 max。

Complexity#

  • Time complexity: O(N)O(N)，N 是 nums 的长度。
  • Space complexity: O(1)O(1)。

Code#

class Solution:
    def maximumValueSum(self, nums: List[int], k: int, edges: List[List[int]]) -> int:
        n = len(nums)
        dp0, dp1 = 0, -10_000_000_000
        for i in range(n):
            a = nums[i]
            b = a ^ k
            new_dp0 = dp0 + a if dp0 + a > dp1 + b else dp1 + b
            new_dp1 = dp0 + b if dp0 + b > dp1 + a else dp1 + a
            dp0, dp1 = new_dp0, new_dp1
        return dp0

Method 5: Greedy algorithm#

Intuition and Approach#

看待这种不使用 tree 的方法的另一种方式是使用 greedy algorithm。因为我们知道只要能找到一对节点，我们就可以 ⊕\oplus k，所以我们可以使用 greedy algorithm 来寻找在 ⊕\oplus k 后差异最大的那些对。

也就是说，我们可以先将每个元素与 k 进行 ⊕\oplus，计算新数组与原数组之间的差异，然后找到所有差异大于零的对，最后得到答案。

Complexity#

  • Time complexity: O(N)O(N)，N 是 nums 的长度。
  • Space complexity: O(N)O(N)，N 是 nums 的长度。

Code#

class Solution:
    def maximumValueSum(self, nums: List[int], k: int, edges: List[List[int]]) -> int:
        ans = sum(nums)
        diff = [(x ^ k) - x for x in nums]
        cnt,l,r = 0,inf,-inf
        for x in diff:
            if x > 0:
                cnt += 1
                if x < l:
                    l = x
                ans += x
            else:
                if r < x:
                    r = x
      
        if cnt % 2 == 1:
            ans += max(-l, r)
      
        return ans
