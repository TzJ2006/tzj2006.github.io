2375. Constructing the Smallest Number From a DI String 的解题思路
2025年5月21日 · 2 分钟

Today’s Problem#

https://leetcode.com/problems/construct-smallest-number-from-di-string/

Idea#

这个问题要求我们在特定约束下找到一个数字序列。

首先，观察到序列长度 N 非常小，因此我们可以使用 DFS 枚举所有可能的情况并得出结果。

另一个想法是使用 stack。当序列递增时，构建有效序列的最佳策略是一个接一个地填入当前最小的可用数字。当序列递减时，由于我们仍希望整个序列尽可能小，我们需要填入最小的、且大于后续位置数字的可用数字。因此，当前位置可以填入的最小数字等于当前索引加上其后连续 ‘D’ 的数量。 基于此，可以使用 stack 来临时存储正在遍历的数字。每当遇到 ‘I’ 或到达序列末尾时，将 stack 中的元素按相反顺序追加到结果数组中。

Method#

对于 Solution 1 (DFS)，只需枚举所有方案并返回第一个满足条件的结果。

对于 Solution 2 (Stack)，当遇到 ‘I’ 时，将 idx + 1 添加到结果数组，然后按相反顺序从 stack 中弹出所有元素并追加到结果数组，最后清空 stack；当遇到 ‘D’ 时，将 idx + 1 推入 stack 以备后续处理。

Tips#

  • DFS: 由于问题要求找到最小的有效序列，因此第一个非 None 的结果即为答案。这意味着一旦找到有效结果，可以立即返回，无需进一步搜索。

  • Stack: 在这里，我特意在序列末尾添加了一个 ‘D’。 直观上，序列的最后一个元素是整个序列中最大的数字。为了将其放入结果数组，需要执行一次 ‘D’ 操作。 这样一来，如果原序列的最后一个字符是 ‘I’，则可以将最大的数字直接追加到结果末尾，这等同于执行了一次 ‘D’ 操作——因为 ‘I’ 操作会清空 stack，使 stack 中只剩一个元素，因此正序或倒序追加得到的结果相同。 如果原序列的最后一个字符是 ‘D’，则最大的数字应该放在连续 ‘D’ 序列的开头，这需要通过 ‘D’ 操作将其放在正确的位置。 这个技巧使代码更加简洁优雅，但牺牲了可读性；不建议在实际中使用。

Complexity#

  • DFS solution time complexity: O(N!)O(N!)，其中 N 是序列长度。

  • Stack solution time complexity: O(N)O(N)，其中 N 是序列长度。

  • DFS solution space complexity: O(N)O(N)，其中 N 是序列长度。

  • Stack solution space complexity: O(N)O(N)，其中 N 是序列长度。

Code#

class Solution:
    def smallestNumber(self, pattern: str) -> str:
        arr = []
        n = len(pattern) + 2
        def dfs(arr):
            if len(arr) == n - 1:
                return arr
            now = len(arr) - 1
            res = None
            if pattern[now] == 'I':
                for i in range(arr[now] + 1, n):
                    if i not in arr:
                        res = dfs(arr + [i])
                        if res is not None:
                            return res
            else:
                for i in range(1, arr[now]):
                    if i not in arr:
                        res = dfs(arr + [i])
                        if res is not None:
                            return res
            
            return res


        for i in range(1, n):
            ans = dfs([i])
            if ans is not None:
                return ''.join(map(str, ans))
                # return ans
        
        return None
