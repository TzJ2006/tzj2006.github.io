A Competition of Models' Chinese Capabilities

August 26, 2026 · 37 min

The same prompt, written once by 4 local Ollama models + 12 cloud models from three Agent CLIs. Below are all the original outputs, along with the speed, VRAM, latency, and token data recorded for each run.

The English version is not a translation of this page, but rather another experiment conducted under the same settings but using an English prompt and requiring the writing of an English novel opening.

Topic#

请用中文写一个约500字的小说开头，以一位在战争爆炸中失去一条腿的芭蕾舞演员为主角，通过描写她在战后生活来侧面体现出她的挣扎。

Running Conditions#

All 16 models received the exact same single prompt, with no prefix or system prompt.

Local (Ollama) — RTX 5090 / 32 GB. POST 127.0.0.1:11434/api/chat, stream: false. No sampling parameters specified; temperature, num_predict, and context all follow the model Modelfile and Ollama defaults (ollama ps shows that the context for all four models is 65536, and the KV cache in VRAM is allocated according to this size). Before each model runs, ollama stop clears the VRAM, so the loading time is a cold start. VRAM is taken as nvidia-smi peak minus the desktop baseline (2.5–3.3 GB). Speed is read directly from the eval_count / eval_duration of the response body, excluding HTTP and Python overhead.

Cloud (Agent CLI) — codex exec, claude -p, cursor-agent --print, all running serially, --output-format json, with the working directory being an empty temporary folder. Total duration is measured by perf_counter for the entire process; token counts and API latency are read from the usage field in each provider’s JSON.

Each model runs 1 time. Sampling involves randomness, so single-run results and speed figures will fluctuate; the tables below are read by order of magnitude.

Three Facts Affecting the Readings#

  1. The two speed tables are not comparable. For local models, the input is the prompt itself (50–59 tokens); for cloud models using coding agent CLIs, the input also includes their respective system prompts and tool definitions, so the input tokens in Table 2 range between 15,000 and 20,000.

  2. Claude Code’s JSON reports a single-digit value in the input_tokens field, which is not the actual context length, so that column is empty for it. Codex and Cursor report the full input.

  3. The running conditions for the Fable 5.1 row are different from the other Claude Code rows. It was a late addition: --effort high is explicitly specified, while the other three Claude Code models use the CLI default effort.
