I. Project Summary

Gadgets (repository directory name is gadget/) is a set of practical tools accumulated during the development process, containing five independently usable tools:

Tool Purpose Main Features
Summarize Generates daily, weekly, and monthly reports from AI conversations Supports multi-device aggregation, multiple conversation sources, and token usage/cost statistics
Research Discovers papers, provides in-depth interpretations, and analyzes researcher/citation relationships Integrates arXiv, bioRxiv, PubMed, Semantic Scholar, and LLM
Benchmark Measures CPU/GPU floating-point performance Supports various hardware and precisions; results are appended to CSV and can generate interactive leaderboards
Website Builds and publishes Hugo blogs Includes bilingual translation, incremental image/video compression, automatic build, and push
Translator Translates text and documents via web translation Local model inference, supports multiple file formats, and protects Markdown special snippets

They all collectively depend on the common/ Python package in the root directory. The development workflow and Claude Code skills come from the independent ai-companion repository.

The repository structure is as follows:

gadget/
├── tools/
│   ├── summarize/      # AI 对话日报、周报、月报
│   ├── research/       # 论文发现、研究者分析、引用图
│   ├── benchmark/      # CPU/GPU 性能测试
│   ├── website/        # Hugo 博客
│   └── translator/     # Gradio 文档翻译器
├── common/             # LLM、缓存、读写、翻译、Hugo 部署等共享能力
├── scripts/            # 同步、机器初始化、检查和维护脚本
├── docs/               # 设计文档、计划、审计报告、历史归档
├── outputs/            # 生成结果，已被 Git 忽略

├── CLAUDE.md           # Claude Code 仓库指南
└── pyproject.toml      # Python 打包和安装配置

V. Summarize: Generating Reports from AI Conversations

Supports reading Claude Code, Codex, Cursor Agent, ChatGPT, and generic JSON conversation records.

It employs two stages: first exporting from each device, then aggregating and merging to generate daily reports; after accumulating daily reports, weekly and monthly reports can be generated.

Step 1: On each device where conversation records need to be collected, export all dates that have not yet been exported:

python -m summarize daily export

Step 2: Synchronize or manually copy the aggregated exported records via cloud drive, then synchronize all dates and merge them day by day:

python -m summarize daily merge --sync-all

Step 3: Generate weekly or monthly reports based on existing daily reports. The following uses example dates from the README and includes deployment operations:

python -m summarize weekly generate --week 2026-W12 --deploy

python -m summarize monthly generate --month 2026-02 --deploy

You can also run the full pipeline, executing export, merge, weekly report, monthly report, and deployment in sequence:

python -m summarize auto --deploy

Usage Tips:

  • --deploy will trigger deployment; relevant website configurations should be prepared before use.
  • Token usage and cost statistics are completed via various source commands in ccusage 20.x.
  • Old daily_summary.py, weekly_summary.py, and monthly_summary.py entry points are still compatible, but using the above module entry points is recommended.
  • The README does not provide path configurations for each conversation source, generic JSON formats, or ccusage installation commands.

Further details are located in TUTORIAL.md and tools/summarize/tutorial.md, but their main text is not included in the provided materials.

VI. Research: Paper Discovery and Scholar Analysis

The unified entry point is tools/research/research_scout.py.

Typical Usage 1: Generate a research report around a project, performing search, three-stage evaluation, and report generation:

python tools/research/research_scout.py report --project my-project
