2894. Problem-solving approach for the difference between divisible and non-divisible numbers
May 27, 2025 · 2 min

Today’s Problem#

2894. Divisible and Non-divisible Sums Difference

Solution Idea#

Given integers n and divisor m, we need to calculate the difference between the following two:

  1. The sum of numbers from 1 to n that cannot be divided by m.
  2. The sum of numbers from 1 to n that can be divided by m.

In other words, divide the numbers from 1 to n into two groups based on whether they are divisible by m], calculate their sums respectively, and return the difference.

Solution Methods#

This problem can be solved using two methods:

Method 1: Formula Method#

  • Use the sum formula for the first n natural numbers: n * (n + 1) // 2 to find the total sum.
  • Calculate the count of numbers from 1 to n that are divisible by m]: k = n // m.
  • The divisible numbers are: m, 2m, ..., km, and their sum is m * (1 + 2 + ... + k) = m * (k * (k + 1) // 2)].
  • Subtract the sum of the divisible part from the total sum to get the sum of the non-divisible part, then find the difference.

Method 2: Brute Force Enumeration#

  • Traverse each number from 1 to n.
  • If the number is divisible by m], add it to num2].
  • Otherwise, add it to num1].
  • Return the difference num1 - num2].

Complexity Analysis#

  • Time Complexity:

    • Method 1: O(1)O(1) (using formulas, constant time)
    • Method 2: O(n)O(n) (linear traversal)

  • Space Complexity:

    • Both methods are O(1)O(1) (only a few variables used)

Code#

class Solution:
    def differenceOfSums(self, n: int, m: int) -> int:
        # Method 1: Formula-Based
        total_sum = n * (n + 1) // 2
        k = n // m
        divisible_sum = m * (k * (k + 1) // 2)
        return total_sum - divisible_sum

class Solution:
    def differenceOfSums(self, n: int, m: int) -> int:
        # Method 2: Brute-Force Iteration
        num1, num2 = 0, 0
        for i in range(1, n + 1):
            if i % m == 0:
                num2 += i
            else:
                num1 += i
        return num1 - num2
