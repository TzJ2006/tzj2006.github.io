LeetCode Daily Question 2025-01-05

January 5, 2025 · 2 min

Today’s Problem#

https://leetcode.com/problems/shifting-letters-ii/description/

Solution Idea#

We need to construct a data structure that supports multiple interval addition operations and a single query. Therefore, we can use difference array and prefix sums to solve it.

Solution Method#

In a difference array, we only record the differences at the boundaries of the change intervals. For example, to add kk to the entire interval [l,r][l,r], we only need to focus on the two endpoints ll and rr: add kk to the difference array diff[l]diff[l], and then add −k-k to diff[r+1]diff[r+1]. In this way, after calculating the prefix sum ss of the difference array, the effect of adding kk will only be reflected within the range [l,r][l,r]. Therefore, by utilizing difference array and prefix sums, the time complexity for each interval modification is O(1)O(1).

When handling character offsets, we first convert the character to its ASCII code, subtract the ASCII code of the character ‘a’, and then take modulo 26 to achieve the “cyclic shift” effect of characters.

Complexity Analysis#

  • Time Complexity: O(N+C)O(N + C), where N is the length of the string and C is the number of operations.

  • Space Complexity: O(N)O(N), because we need to store the difference array.

Code#

class Solution:
    def shiftingLetters(self, s: str, shifts: List[List[int]]) -> str:
        dif = [0] * (len(s) + 1)
        for l,r,delta in shifts:
            if delta == 0:
                dif[l] -= 1
                dif[r + 1] += 1
            else:
                dif[l] += 1
                dif[r + 1] -= 1
        
        a = ord('a')
        cnt = 0
        ans = ""
        
        for i in range(len(s)):
            cnt += dif[i]
            ans += chr((ord(s[i]) - a + cnt) % 26 + a)

        return ans
