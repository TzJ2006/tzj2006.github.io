2493. A solution method for partitioning nodes into as many groups as possible
February 1, 2025 · 2 min

Today’s Problem#

https://leetcode.com/problems/divide-nodes-into-the-maximum-number-of-groups/description/

Solution Approach#

The key to this problem lies in the condition ∣y−x∣=1|y - x| = 1. With every step taken, the parity must change. Therefore, when we encounter a parity conflict (for example, a cycle containing three nodes and three edges), we should return -1. Otherwise, we only need to enumerate the starting points of the graph to find the optimal starting node.

Therefore, the solution method is as follows:

  1. Use DFS to determine if there is a parity conflict in the graph.
  2. Use BFS to find the optimal starting point.

Question: Why use BFS to find the starting point?

Because we need to add the nodes connected to the current node via edges into the next grouping.

Algorithm Steps#

  1. Use DFS to determine if there is a parity conflict in the graph.
  2. Use BFS to find the optimal starting point.

Complexity Analysis#

  • Time Complexity: O(N2)O(N^2)

  • Space Complexity: O(N2)O(N^2)

Code#

class Solution:
    def magnificentSets(self, n: int, edges: List[List[int]]) -> int:
        vis = [0] * (n + 1)
        bvis = [0] * (n + 1)
        e = [[] for _ in range(n + 1)]

        for x,y in edges:
            e[x].append(y)
            e[y].append(x)

        ans = 0
        clock = 0

        def bfs(x):
            nonlocal clock
            clock += 1
            bvis[x] = clock
            q = deque([(x,1)])
            res = 1
            while(len(q) > 0):
                now, dis = q.popleft()
                res = max(res, dis)
                for to in e[now]:
                    if bvis[to] == clock:
                        continue
                    bvis[to] = clock
                    q.append((to, dis + 1))
                    
            return res

        cur = 0                    

        def dfs(x):
            nonlocal cur
            cur = max(cur, bfs(x))
            # print(cur)
            tmp = 0
            for to in e[x]:
                if vis[to] == 0:
                    if vis[x] == 0:
                        print("Warning!", x)
                    vis[to] = -vis[x]
                    tmp += dfs(to)
                else:
                    if vis[to] != -vis[x]:
                        return -1
            return tmp

        for i in range(1, n + 1):
            if vis[i] == 0:
                cur = 0
                vis[i] = 1
                if dfs(i) < 0:
                    return -1
                # print("out: ", cur)
                ans += cur
        
        # print(bfs(5))

        return ans
