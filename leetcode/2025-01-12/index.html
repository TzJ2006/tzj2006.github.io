LeetCode Daily Question 2025-01-12

January 11, 2025 · 3 min

Today’s Problem#

https://leetcode.com/problems/check-if-a-parentheses-string-can-be-valid/

Solution Approach#

To construct a valid parenthesis string, one needs to find a corresponding ‘(’ to the left of each ‘)’ and a corresponding ‘)’ to the right of each ‘(’. When traversing from left to right, we can satisfy the first condition first.

When encountering a ‘)’, there are three ways to match it with a ‘(’: first, an existing ‘(’, second, finding an unlocked ‘)’, or third, if the ‘)’ itself is unlocked, it can be converted into a ‘(’.

Assuming we have found a matching ‘(’ for all ‘)’, we then need to find a corresponding ‘)’ for the remaining ‘(’. At this point, the only way is to find an unlocked bracket, because all ‘)’ have already been matched.

Solution Scheme#

First, if the string length is odd, it can never form a valid parenthesis string, so directly return False.

Maintain two arrays: anyBracketanyBracket stores the indices of all unlocked brackets, and openBracketopenBracket stores the indices of all ‘(’.

Traversing the entire string from left to right, the following situations will be encountered:

  1. The current character is an unlocked bracket: push its index into the anyBracketanyBracket stack.
  2. The current character is ‘(’: push its index into the openBracketopenBracket stack.
  3. The current character is ‘)’: a ‘(’ needs to be found for it.
    • Prioritize popping a ‘(’ from the openBracketopenBracket stack, which simultaneously completes the task of finding a ‘)’ for that ‘(’.
    • If the openBracketopenBracket stack is empty, take an unlocked bracket from the anyBracketanyBracket stack (to act as ‘(’).
    • If both stacks are empty, then return False, because no matching ‘(’ can be found for the current ‘)’.

After the traversal, there may still be unmatched ‘(’ left in openBracketopenBracket.

At this point, traverse each unmatched ‘(’ in openBracketopenBracket and check if there exists a bracket with a larger index in anyBracketanyBracket (i.e., an unlocked bracket located to its right).

  • If it exists, it means a ‘)’ has been successfully found for it, matching successful!
  • Otherwise, it cannot be matched, return False.

If the number of remaining elements in anyBracketanyBracket is even (which must hold true here due to the parity check performed earlier), then return True, mission accomplished!

Important Tips#

  • Why use stacks for both openBracketopenBracket and anyBracketanyBracket?
  • Because a ‘)’ always prioritizes matching with the nearest ‘(’ to its left, therefore a Last-In-First-Out (LIFO) data structure is needed to retrieve the “nearest element”.

Complexity Analysis#

  • Time Complexity: O(N)O(N), where N is the length of the string.

  • Space Complexity: O(N)O(N), to store the indices of the brackets.

Code#

class Solution:
    def canBeValid(self, s: str, locked: str) -> bool:
        if len(s) % 2 == 1:
            return False
        
        openBracket = []
        anyBracket = []

        for i in range(len(s)):
            if locked[i] == '0':
                anyBracket.append(i)
            else:
                if s[i] == '(':
                    openBracket.append(i)
                else:
                    if len(openBracket) > 0:
                        openBracket.pop()
                    elif len(anyBracket) > 0:
                        anyBracket.pop()
                    else:
                        return False
        
        if len(anyBracket) < len(openBracket):
            return False

        idx = len(anyBracket) - 1
        for i in range(len(openBracket) - 1, -1, -1):
            if anyBracket[idx] < openBracket[i]:
                return False
            idx -= 1
        
        return idx % 2 == 1
