Problem-solving approach for 2375. Constructing the Smallest Number From a DI String
May 21, 2025 · 4 min

Today’s Problem#

https://leetcode.com/problems/construct-smallest-number-from-di-string/

Idea#

This problem requires us to find a sequence of numbers under specific constraints.

First, it is observed that the sequence length N is very small, so we can use DFS to enumerate all possible cases and derive the result.

Another idea is to use a stack. When the sequence is increasing, the best strategy for constructing a valid sequence is to fill in the current smallest available number one by one. When the sequence is decreasing, since we still want the entire sequence to be as small as possible, we need to fill in the smallest available number that is greater than the numbers in subsequent positions. Therefore, the smallest number that can be filled at the current position equals the current index plus the number of consecutive ‘D’s following it. Based on this, a stack can be used to temporarily store the numbers being traversed. Whenever an ‘I’ is encountered or the end of the sequence is reached, append the elements in the stack to the result array in reverse order.

Method#

For Solution 1 (DFS), simply enumerate all schemes and return the first result that satisfies the conditions.

For Solution 2 (Stack), when an ‘I’ is encountered, add idx + 1 to the result array, then pop all elements from the stack in reverse order and append them to the result array, finally clearing the stack; when a ‘D’ is encountered, push idx + 1 into the stack for subsequent processing.

Tips#

  • DFS: Since the problem requires finding the smallest valid sequence, the first non-None result is the answer. This means once a valid result is found, it can be returned immediately without further searching.

  • Stack: Here, I intentionally added a ‘D’ at the end of the sequence. Intuitively, the last element of the sequence is the largest number in the entire sequence. To put it into the result array, a ‘D’ operation needs to be performed. In this way, if the last character of the original sequence is ‘I’, the largest number can be directly appended to the end of the result, which is equivalent to performing a ‘D’ operation—because an ‘I’ operation clears the stack, leaving only one element in the stack, so appending in forward or reverse order yields the same result. If the last character of the original sequence is ‘D’, the largest number should be placed at the beginning of the consecutive ‘D’ sequence, which requires placing it in the correct position through a ‘D’ operation. This trick makes the code more concise and elegant, but sacrifices readability; it is not recommended for actual use.

Complexity#

  • DFS solution time complexity: O(N!)O(N!), where N is the sequence length.

  • Stack solution time complexity: O(N)O(N), where N is the sequence length.

  • DFS solution space complexity: O(N)O(N), where N is the sequence length.

  • Stack solution space complexity: O(N)O(N), where N is the sequence length.

Code#

class Solution:
    def smallestNumber(self, pattern: str) -> str:
        arr = []
        n = len(pattern) + 2
        def dfs(arr):
            if len(arr) == n - 1:
                return arr
            now = len(arr) - 1
            res = None
            if pattern[now] == 'I':
                for i in range(arr[now] + 1, n):
                    if i not in arr:
                        res = dfs(arr + [i])
                        if res is not None:
                            return res
            else:
                for i in range(1, arr[now]):
                    if i not in arr:
                        res = dfs(arr + [i])
                        if res is not None:
                            return res
            
            return res


        for i in range(1, n):
            ans = dfs([i])
            if ans is not None:
                return ''.join(map(str, ans))
                # return ans
        
        return None
